# PADEL CLUB: full development briefing (for another AI to read)

## 1. What the project is

PADEL CLUB is a real-time **online multiplayer padel game** (2 vs 2, also 1 vs 1) that runs in the browser.

- **Server**: Node.js 20+/24, ES modules, `ws` WebSocket library. Authoritative: the server runs the simulation at **60 Hz** and broadcasts snapshots every tick.
- **Client**: plain JavaScript modules, **Three.js 0.170** (no build step, no bundler, no framework). The same Node server serves the static client.
- **Shared code** (`shared/`): the game rules, physics, scoring and bot AI. The identical files run on the server, in the browser (solo matches run entirely in the browser, zero latency) and in the unit tests.
- **Deployment**: Dockerfile and `render.yaml` for Render (region Frankfurt). Source on GitHub (`gonzalooocanovas/PadelClub`).
- **Size**: about 10,000 lines of JavaScript, **123 automated tests** (`node --test`), no TypeScript.
- **Tooling constraints of the environment where it is built**: Windows 11, no Python, no Blender (so no GLB 3D models: all characters, rackets and venues are procedural Three.js geometry), Node only.

## 2. Coordinate system and court

Metres. `x` across the court (-5..5), `z` along it (-10..10), `y` up. The net is the plane `z = 0`.
Team 0 defends `z < 0` and attacks toward `+z`; team 1 the opposite.

- Court 10 m x 20 m. Net height 0.88 m at the centre, 0.92 m at the posts (it sags).
- Service line 6.95 m from the net. Back walls: 3 m glass + 1 m mesh (anything above 4 m is "out").
- Side walls: **glass in the back 4 m (|z| >= 6), fence/verja (mesh) through the middle**. In 1v1 the court narrows to 7 m and the side walls are glass all along.
- **Access doors** (doubles only): in each side wall, 1.2 m to 3.2 m from the net, 2 m high. Outside each wall there is a fenced strip 1.8 m wide, 18.4 m long. A ball that has bounced once may leave through a door; the receiving team can follow it outside (players may walk out only through the doors) and must return it along the strip, round the net post and in through the other door so it lands in the opponents' court.
- Four venues: Premium Indoor Club, Mediterranean Court (outdoor), Night Arena, Sunset Rooftop. Each has its own turf bounce constants, lighting, crowd and ambience.

## 3. Physics (the part I most want improved by someone who knows the sport)

`shared/physics.js`, fixed step 1/60 s. All units SI.

**Ball (`stepBall`)**
- Gravity 9.81. Drag: linear 0.06 x 0.6 plus quadratic `0.0035 * speed` per second (fast balls slow more).
- Magnus effect: backspin `sb > 0` lifts, topspin `sb < 0` dives (`MAGNUS = 0.012`); sidespin `ss` curves left/right of the travel direction. Spin decays `exp(-0.35 dt)`.
- Floor bounce: vertical restitution per court (0.83 to 0.85) reduced by backspin and slightly by impact speed; horizontal speed kept 0.84 to 0.86 (also spin dependent); backspin halves, sidespin x0.75 per bounce.
- **Two wall materials**: glass restitution 0.82 (minus 1% per m/s up to 20 m/s), tangential friction 0.97; fence/mesh restitution 0.34, friction 0.84. Wall spin: topspin climbs the glass (`vy += -sb * 0.11 * min(1, vn/12)`), backspin drops the ball; the wall strips part of the spin; sidespin kicks the ball along the glass (0.14).
- Net: the ball hitting the net band stops (0.22 rebound); clipping the tape within 4.5 cm may pop it over ("cord") with lost pace.
- Doors/strip: described above; ball inside the strip bounces off its fences.
- Events emitted: `floor`, `wall` (axis, material), `net`, `cord`, `door`, `out`.

**Shot solver (`solveLaunch`, `simulateShot`, `planShot` in `game.js`)**
For every shot the game picks a landing point, a target flight time T and a spin, solves the launch velocity ballistically, then **simulates the real physics** (drag, spin, walls) and iteratively corrects the launch so the ball really lands there, while forcing net clearance for well-struck balls. A poor contact does not get that help.

**Racket contact (`contact()` in `game.js`)**
- Contact is deferred until the ball is within 1.2 m of the player (the "sweet spot") or the swing window is closing.
- Quality `q` (0.3..1) comes from: distance to the sweet spot (0.95 m), ball height, whether the ball is in front, running speed, running away from the ball, then a forgiving remap.
- **Fatigue**: below 45 stamina, `q` drops up to 0.25.
- **Pressure**: reaching the ball at full stretch (including a last-gasp lunge), a ball hit with great pace (>14 m/s) and being on the run reduce `q` (up to about 0.5 in total). So a good volley or a placed ball actually wins the exchange.
- Face angle from swing timing: an open face (early) gives higher, slower balls with backspin; a closed face (late) is flatter with topspin.
- Edge hits lose pace and scatter. Labels: perfect / clean / early / late / off-centre / stretched / poor.
- Bot mishits ("slip"): 60% dive into the net/floor in front, 40% go long.

**Shots**: serve, forehand, backhand, volley, lob (globo), smash (remate), bandeja, vibora, chiquita, drop shot (dejada), block, slice. Each has its own speed, depth range and spin.
- **Lob quality depends on contact**: a clean lob climbs high and lands deep (hard to smash); a poor one is low and short (easy to smash).
- **"Por 4"** (just added): a clean smash (`q >= 0.8`) from near the net, ball above 2.2 m, aimed short (depth <= 4.8 m) comes down steeply (flight time floor 0.13 s) with heavy topspin and bounces out of the court over the fence: a winner. Credited as "¡Por 4!". Bots use it with probability tied to their smash skill.
- **Serve**: the ball bounces in the server's hand (period 1.1 s). Quality depends on the ball height 0.05 s after the press (best at waist height 0.62 m, narrow window). Holding the key charges power for 0.9 s (a tap = normal; full charge = +22% pace, less accurate, **tends to fly long** past the service line). Fault rules, double fault, let-less (a net cord on the serve is a fault).
- The server stays **planted on the line** until the serve is hit; the others are frozen. After a fault everybody returns to their starting place.

**Player movement (`stepPlayer`, shared with the client for prediction)**: run 6 m/s, sprint 8 m/s, acceleration 30, deceleration 38, braking before reversing. Planted while swinging (30% speed). Stamina 100: sprint costs 24/s, **the rally itself drains 1.5/s even standing still** and only recovers between points (13/s); below 45 stamina the player is up to 18% slower. Applies to humans and bots.

## 4. Rules and scoring (`shared/scoring.js`, `game.js`)

Padel scoring: points 0-15-30-40, optional golden point, games to 6 (or configurable), sets, tiebreak, best of 1/3. Serve rotates among all four players (each team alternates its two servers). Server alternates sides. Service box diagonal. Ball must bounce once in the box. Wall before bounce = point lost for the hitter. Ball bounced and then out over the fence = point to the hitter. Second bounce = point to the hitter. Doors rules in section 2.

## 5. Multiplayer (`server/`)

- Rooms with 5-letter codes; host, ready check, team seats, AI fill, public/private, public room list, chat, quick chat, emotes, reconnection (a bot covers a dropped player; the seat is reclaimed on reconnect).
- **Quick match** (`server/quick.js`): queue; four players are matched into a doubles game; after 10 s anyone still waiting plays with bots filling the seats. The home screen shows how many players are online and the queue size.
- **Authoritative server + client prediction**: the client predicts its own player with the same `stepPlayer`, reconciles from snapshots (60 Hz), and interpolates others (0.07 s online, 0.03 s local).
- **Online pause by agreement**: a player requests a pause, every other human must accept (10 s), then the game freezes for at most 30 s or until every human presses Resume; two pauses per player; a disconnected player does not block it.
- Rate limiting, input sanitising, input queue cap, server-side validation of all settings; the client cannot submit results.
- Guest profiles (token in the browser, stored server side): XP, level, match stats.

## 6. Bot AI (`shared/ai.js`) and how it was analysed

Bots produce exactly the same inputs a human client would send (so they obey every rule). Four levels (Rookie, Club, Pro, Legend) with parameters: speed, reaction time, aim noise, reach, flub chance, timing error, aggression, lob/slice/smash mix, serve spin/timing window/pace/risk, planning interval. Six playing **styles** modify these (net player, retriever, power, all-rounder, wild, counter-puncher) and 16 named career characters use them.

Key behaviours:
- **Ball reading**: `predictBall` (full physics incl. walls) every few ticks; the bot goes to **the first point of the flight it can actually reach**, including after a wall rebound. Overheads before the bounce for players who dare.
- **Shot choice**: target x from a score of open space (net players weigh more), change of direction and avoidance of the dead centre; then lob / dejada / chiquita / slice / drive / smash / bandeja / vibora by situation; occasional "por 4" attempts.
- **Doubles positioning model (rebuilt after measuring)**: a team is in mode `D` (both defend from the baseline) or `A` (both at the net), decided once per tick from shared information (incoming lob or deep ball -> D; short ball -> A; our deep lob or short low ball -> A; a poor lob -> D), with hysteresis. One-up-one-back only at the serve and return. Side by side, shifting with the ball. **With a human partner the bot mirrors the human's line** and does not steal balls (needs a 0.9 m advantage).
- Serve: waits for the same narrow bounce window (tighter at higher levels), 2+ s before serving, softer than full pace, avoids the extreme corners.
- Bots tire like humans and save their sprint (>30 stamina).

**Analysis harness results (simulation, bot vs bot)**

| metric | before | after |
|---|---|---|
| pair split one-up-one-back | 58-62% | about 19% |
| both at the net | 6% | about 27% |
| long points with a player glued to the baseline | 15-31% | 0-3% (Pro/Legend) |
| points lost where nobody even swung | 95% | ~15% |
| average rally (Rookie/Club/Pro/Legend) | 4 / 7 / 11 / 31 | about 7 / 8 / 11 / 14 |
| aces (bot vs bot) | 13-26% | 0-3% |
| "por 4" winners per 100 points (Legend / Pro / Club) | n/a | 9 / 5 / 1 |

Level separation over 20 matches each: Legend beat Pro 14/20, Pro beat Club 18/20, Club beat Rookie 17/20.

Bugs found by that analysis (worth knowing about because similar ones may remain): bots lost the target they chose when starting a swing (later inputs were blank) so every shot went to the centre; slices clipped the net because net-clearance and landing correction were solved separately; players never recovered stamina between points; a "flub" meant the bot watched the ball go by and its partner never took over.

## 7. Game modes and meta

- **Quick match** (matchmaking), **private rooms** with friends, **practice 2v2 / 1v1** against bots (solo matches run in the browser, no network).
- **Career v2** (`shared/career2.js`): 3 seasons, 12 events (knockout draws of 4/8, group + final), real brackets (the matches the player does not play are simulated headlessly with the same engine and bots), 16 named characters, ranking points vs roster points, objectives (unlock two rackets), versioned save that migrates the old save, a short story scene before and after each event.
- **Training drills** (5): serve, forehand corner, lob, volley, smash; 3 stars; they run on the real game.
- **Player upgrades**: 10 attributes (speed, power, stamina, groundstroke, volley, smash, lob, reaction, defence, variety), up to level 10 (about +15%). Earned by wins (career, practice vs Club/Pro/Legend), drills and objectives. Apply to every solo match, **never online** (online everyone is equal).
- **Match history** stored in the browser (last 100 matches) with win rate, streak, best rally.
- Equipment: 4 archetypes, 7 hairs, 5 skins, 8 cosmetic rackets (two unlocked by objectives).

## 10. Known weaknesses and honest limits

- Nothing here has been judged by a human on **real hardware**: gamepad, audio listening (music is synthesised, the owner said an earlier version was "very bad"; it was rewritten but not re-judged), mobile, low-end GPUs, a real 4-human session, the feel of the off-court doors.
- The in-app browser used for checking throttles `requestAnimationFrame` to about 1 fps, so visual checks were done with manual frame stepping and screenshots; real-time smoothness was never measured.
- No real 3D models (procedural only); animation is keyframe/IK-light, not motion capture; no cloth/hair.
- Bots are rule-based, not learned. The owner said bots "se colocan mal", "hacen cosas mal". The positioning was rebuilt from simulation metrics, but only measured bot-vs-bot, not against human playing styles.
- The "wall play" is physical (spin kick, two materials) but bots do not deliberately **play shots off the walls** (bajada de pared, doble pared, contrapared, chiquita to the glass), only react to rebounds. A defending bot does not choose wall plays.
- Doors/strip are narrow (1.8 m) and bots rarely produce door exits.
- The calibration constants (restitutions, friction, Magnus, drag, pace) were tuned by feel and simulation, not against measured ball data. I would like them reviewed against real padel ball physics (Penn/Head padel balls: pressure and bounce height standards, glass restitution, turf friction).
- The career has no cutscenes; story is text only. The career economy (coins) has nothing to buy yet.
- No accounts: history, career and upgrades live in the browser's local storage (per device); only profile XP is on the server.
- Online anti-cheat is basic (the server validates inputs, but a client could send maximum serve charge every time).

# PADEL CLUB

Browser-based 4-player online padel. A Node server runs the match (authoritative physics, rules and scoring);
browsers are thin clients that render with Three.js and send inputs.

## Run it

```bash
npm install
npm start            # http://localhost:3000
npm test             # 30 tests: scoring, rules, physics, and 4 real WebSocket clients
```

Requires Node 20+. No build step: the client is plain ES modules served by the same Node process.

## Play with three friends

1. One person opens the game, clicks **Play with friends**. A room code and invite link appear.
2. Friends open the link (or type the code under *Join room*). Everyone lands in a seat; click **Sit here** or let the host **Move** people between Team A and Team B.
3. Non-hosts press **I am ready**; the host presses **Start match**.
4. For friends on other networks the server must be reachable by them: see *Deployment*, or tunnel your local port (e.g. `cloudflared tunnel --url http://localhost:3000`).

**1 vs 1**: in the lobby set *Mode* to *1 vs 1* (host). Two seats on a narrower 7 m court closed by glass walls on all sides (the ball plays off the glass like in doubles); bots fill the free seat.

**Career**: three seasons of tournaments (knockout draws and group stages, singles and doubles) against 16 named characters with their own playing styles. The matches you do not play are simulated with the same engine, so brackets and the world ranking are real. Earn ranking points, coins and development points; complete objectives to unlock rackets; use the Training tab for drills and the Development tab to improve nine attributes (small bonuses, solo only). Progress is saved in your browser.

**Off-court play (2v2)**: each side wall has two access doors near the net. If the ball bounces and then leaves through a door, chase it outside and return it along the strip and in through the other door.

**Match history**: every finished match is remembered in your browser (History button on the home screen).

**Bot levels**: Rookie, Club, Pro, Legend (pick them on the home screen, in the lobby, or via the career stage). Higher levels react faster, cover more ground, aim for open space and the lines, and mix globos, dejadas, slices and spin serves.

**Public rooms**: the host can set *Room visibility → Public* in the lobby; open lobbies appear under *Rooms* on the home screen for one-click joining.

**Courts and equipment**: three environments (Premium Indoor Club, Mediterranean Court, Night Arena), chosen by the host in the lobby or on the home screen for solo play; the turf differs slightly (outdoor is a few percent slower). *Equipment* lets you pick one of 4 player archetypes, hair, skin and one of 8 cosmetic rackets, with a live 3D preview. Your look is shown to the other players. See DEV_CHECKLIST.md for what is and is not done.

**Cameras**: Settings has four presets (player, broadcast, tactical, custom). **Racket contact**: the face angle comes from swing timing and the strike point from the distance to the sweet spot, so timing and positioning change the arc, spin, pace and accuracy of each shot. **Audio**: distinct shot sounds, court-specific rooms and ambience, optional announcer.

**Practice vs AI** starts a room with you and three bots. Empty seats are only ever filled by clearly labelled AI.

### Controls
Open **Settings → Controls → Configure** to pick a scheme (Classic keyboard, Keyboard + mouse aim, Gamepad, Custom), rebind every action (keyboard, mouse or gamepad), tune the stick, and test your inputs live. Defaults:

| Input | Action |
|---|---|
| W A S D | Move (camera-relative; W = toward the net) |
| Space | Hit / serve (press just before the ball reaches the ring around your feet) |
| Arrow keys | Move (same as WASD). You are planted while swinging, and the direction you hold at contact is where the ball goes (left/right, up = deep, down = short); the mouse does not aim (left click hits, right click = globo) |
| G / Enter | Globo (lob) |
| R | Slice: backspin, skids low and slow |
| Q | Chiquita (near net) / dejada (from deep) / **víbora** on overheads |
| E | Block on low balls / **bandeja** on overheads |
| X / Shift | Jump / sprint (stamina) |
| Tab / Esc / 1–4 | Stats / menu / quick chat |

Shot type is chosen from context (ball height, distance to the net, ball side, modifiers): forehand (topspin), backhand, slice, volley, globo, remate (smash), bandeja, víbora, chiquita, dejada, block, serve.

### Ball physics
The ball has real spin: Magnus lift/dive (backspin floats, topspin dives), sidespin curves, air drag, and spin-dependent bounces. Backspin gives a low, slow bounce; topspin kicks forward; víbora sidespin kicks sideways off the glass. The shot solver simulates the real physics and corrects the launch, so the landing spot you aim at stays accurate whatever the spin. Mishit balls carry less spin.

## Architecture

```
shared/    Pure simulation, imported by BOTH server and client
  constants.js  court/physics/player tuning
  physics.js    stepPlayer (also used for client prediction), stepBall, ballistic shot solver
  scoring.js    explicit scoring state machine (points, deuce/advantage/golden point, games, sets, tiebreaks, service order)
  game.js       PadelGame: players, shots, contact quality, padel rules (bounces, glass, net, serve box, faults), stats
  ai.js         doubles bot: predicts the ball, covers its half, picks lobs/smashes/bandejas
server/
  index.js      HTTP static + WebSocket server, fixed 60 Hz loop, rate limiting
  rooms.js      Room lifecycle (lobby → ready → match → results → rematch), reconnect, bot takeover
  store.js      File-backed persistence (guest profiles, XP, match history)
client/
  js/net.js     WebSocket + auto-reconnect, guest token
  js/game.js    input, prediction + reconciliation, snapshot interpolation, camera, event feedback
  js/scene.js   court, glass/mesh, net, procedural player models and animation, ball
  js/ui.js      menus, lobby, HUD, results, settings
  js/audio.js   synthesised sound (no audio files)
```

### Networking model
- Server ticks at 60 Hz and broadcasts compact snapshots at 30 Hz (ball, 4 players); discrete events (hit, bounce, fault, point) are sent reliably.
- Clients send timestamped inputs (`seq`, move axes, aim point, swing/lob/jump/modifier flags). The server validates and clamps everything. It decides every contact, bounce and point; a client cannot submit scores, ball positions or results (unknown messages are ignored; covered by a test).
- The local player is predicted with the same `stepPlayer` and reconciled against the server's acked `seq`. Other players and the ball are interpolated ~100 ms behind.
- Disconnects: a **bot takes over the seat instantly** (the point continues, nobody is stuck waiting); reconnecting with the same guest token returns control. In the lobby a seat is held for 60 s. Rooms with no connected players are removed after 10 minutes.
- Persistence: when the server's own simulation ends a match it records the result, grants XP, and updates profiles.

Working and covered by tests or verified in a browser:

- Authoritative doubles match with real padel rules and scoring (see `test/`), serve box, faults/double faults, glass rebounds after the first bounce, net, out calls.
- Practice mode vs bots; bots cover for disconnected players.
- Guest profiles with level/XP/win-loss/history (file store); real stats (winners, errors, aces, smashes, volleys, longest rally) from match events.

- Not yet load-tested; the game loop is single-process, one Node process hosts all rooms.

// Used for practice, career mode, and to cover for players who disconnect mid-match.
//
// Four levels (the ids are what rooms and the career use):
//   easy = Rookie   normal = Club   hard = Pro   expert = Legend

import { clamp, COURT } from './constants.js';
import { predictBall, serveBallHeight } from './physics.js';
import { STYLE_MODS } from './roster.js';

export const BOT_LEVELS = ['easy', 'normal', 'hard', 'expert'];
export const BOT_LABELS = { easy: 'Rookie', normal: 'Club', hard: 'Pro', expert: 'Legend' };

const SKILL = {
  // speed: top speed factor · react: seconds before reacting · noise: aim scatter · reach: swing distance
  // flub: chance to miss a ball outright · aggr: willingness to attack · lob/slice/smash: shot mix
  // serveSpin: chance of a spin serve · serveTiming: waits for the ideal bounce height · plan: replanning interval
  easy: { speed: 0.9, sprint: true, react: 0.3, noise: 2.0, reach: 1.9, flub: 0.3, timingErr: 0.24, aggr: 0.12, lob: 0.35, slice: 0.08, smash: 0.35, serveSpin: 0, serveTiming: false, serveWindow: 0.45, servePace: 0.68, serveRisk: 0.0, plan: 0.12 },
  normal: { speed: 0.96, sprint: true, react: 0.18, noise: 1.4, reach: 1.95, flub: 0.24, timingErr: 0.14, aggr: 0.3, lob: 0.45, slice: 0.18, smash: 0.5, serveSpin: 0.15, serveTiming: false, serveWindow: 0.25, servePace: 0.72, serveRisk: 0.3, plan: 0.1 },
  hard: { speed: 0.95, sprint: true, react: 0.09, noise: 0.5, reach: 2.2, flub: 0.18, timingErr: 0.07, aggr: 0.5, lob: 0.5, slice: 0.25, smash: 0.7, serveSpin: 0.4, serveTiming: true, serveWindow: 0.12, servePace: 0.76, serveRisk: 0.6, plan: 0.07 },
  expert: { speed: 1.1, sprint: true, react: 0.03, noise: 0.15, reach: 2.4, flub: 0.15, timingErr: 0.03, aggr: 0.45, lob: 0.55, slice: 0.3, smash: 0.85, serveSpin: 0.6, serveTiming: true, serveWindow: 0.05, servePace: 0.8, serveRisk: 0.85, plan: 0.05 },
};

const skillCache = new Map();
/**
 * A bot is a level ('easy'..'expert') optionally with a style ({level, style}). The style shifts the level's tendencies:
 * where the bot stands (netZ/backZ) and how often it attacks, lobs, slices and smashes.
 */
export function skillFor(d) {
  const level = typeof d === 'object' && d ? d.level : d;
  const style = typeof d === 'object' && d ? d.style : null;
  const key = level + '|' + style;
  if (skillCache.has(key)) return skillCache.get(key);
  const base = { ...(SKILL[level] || SKILL.normal) };
  const m = STYLE_MODS[style] || {};
  for (const [k, v] of Object.entries(m)) {
    if (k === 'netZ' || k === 'backZ') base[k] = v;
    else base[k] = (base[k] ?? 0) + v;
  }
  for (const k of ['aggr', 'lob', 'slice', 'smash', 'flub']) base[k] = Math.max(0, Math.min(1, base[k]));
  base.speed = Math.max(0.8, Math.min(1.1, base.speed));
  base.noise = Math.max(0.1, base.noise);
  skillCache.set(key, base);
  return base;
}

export function makeBotMemory() {
  return { serveT: 0, plan: null, planAge: 99, react: 0, lastTeam: -1, flub: false };
}

const blank = () => ({ mx: 0, mz: 0, sprint: false, swing: false, jump: false, ax: 0, az: 0, mod: 0, lob: false, keep: true });

function moveTo(inp, p, tx, tz, skill, allowSprint) {
  const dx = tx - p.x, dz = tz - p.z;
  const d = Math.hypot(dx, dz);
  if (d < 0.08) return d;
  const k = Math.min(1, d / 0.5) * skill.speed;
  inp.mx = (dx / d) * k;
  inp.mz = (dz / d) * k;
  inp.sprint = allowSprint && skill.sprint && d > 2.5 && p.stamina > 30; // bots save their legs too
  return d;
}

export function botInput(game, slot, mem, difficulty = 'normal', dt = 1 / 60) {
  const skill = skillFor(difficulty);
  const p = game.players[slot];
  const inp = blank();
  const os = p.team === 0 ? 1 : -1;
  const r = game.rally;
  const b = game.ball;
  const rnd = game.rng;

  if (game.phase === 'serve') {
    if (game.serverSlot === slot) serve(inp, game, p, os, skill, mem, dt);
    mem.plan = null; mem.react = 0; mem.lastTeam = -1;
    mem.role = Math.abs(p.z) < 5 ? 'net' : 'back'; // the server and the receiver start at the back, their partners at the net
    if (game.aiTeam) game.aiTeam[p.team] = { mode: 'D', since: game.time, tick: -1 };
    return inp;
  }
  if (game.phase !== 'rally') return inp;

  const incoming = r.lastTeam !== p.team;
  if (r.lastTeam !== mem.lastTeam) {
    mem.lastTeam = r.lastTeam; mem.planAge = 99;
    mem.react = r.serving ? skill.react * 0.6 : skill.react; // receivers do not anticipate: they react to the serve, not before it
    mem.flub = rnd() < skill.flub * (r.serving ? 0.35 : 1);
    mem.jit = (rnd() - 0.5) * skill.timingErr; // each level presses a little earlier or later
  }
  mem.react = Math.max(0, mem.react - dt);

  if (incoming && (b.ex || Math.abs(b.x) > COURT.HALF_W) && game.openings) {
    outsideBall(inp, game, p, os, skill, mem);
    return inp;
  }

  if (incoming) {
    mem.planAge += dt;
    if (mem.planAge > skill.plan) {
      mem.planAge = 0;
      const samples = predictBall(b, 3.0);
      let pick = null;
      let bounced = r.bounces >= 1;
      let first = null; // earliest playable point, used when nothing is reachable in time
      const canReach = (s) => Math.hypot(s.x - p.x, s.z - p.z) <= 0.6 + skill.speed * 6.4 * Math.max(0, s.t - mem.react);
      for (const s of samples) {
        if (s.floor) bounced = true;
        const mine = p.team === 0 ? s.z < -0.4 : s.z > 0.4;
        // overhead: a high ball falling in my half before it bounces is attacked (smash / bandeja) by players who dare
        const overhead = mine && !bounced && s.vy < 0 && s.y < 2.45 && s.y > 1.95 && Math.abs(s.z) < 7 && rnd() < 0.25 + skill.smash * 0.75;
        // groundstrokes after the bounce (also off the back wall); volleys only in the net zone
        const ground = mine && s.y < 1.7 && s.vy <= (bounced ? 2.0 : 0.5) && (bounced || Math.abs(s.z) < 4.2);
        if (!overhead && !ground) continue;
        first = first || s;
        if (canReach(s)) { pick = s; break; } // anticipation: go to the first point that can actually be reached, even after a wall rebound
      }
      pick = pick || first;
      mem.plan = pick || null;
    }
    const partner = game.players[slot ^ 1];
    const plan = mem.plan;
    let responsible = true;
    if (plan && partner.active) {
      const me = Math.hypot(plan.x - p.x, plan.z - p.z);
      const pa = Math.hypot(plan.x - partner.x, plan.z - partner.z);
      // the player on the side of the ball takes it; the middle goes to the nearer one
      const side = (plan.x - (p.x + partner.x) / 2) * (p.x < partner.x ? -1 : 1) > 0 ? -0.5 : 0.5;
      const margin = partner.human ? 0.9 : 0.3; // with a person as partner: do not steal their balls
      responsible = me + side < pa - margin || (!partner.human && Math.abs(me + side - pa) <= 0.3 && slot < partner.slot);
    }
    if (plan && responsible) {
      if (mem.react <= 0) moveTo(inp, p, plan.x, plan.z - os * (plan.y > 1.8 ? 0.3 : 0.75), skill, true);
    } else {
      formation(inp, game, p, os, skill, mem);
    }
    // swing when the ball is close enough and on the way
    const dx = b.x - p.x, dz = b.z - p.z;
    const dist = Math.hypot(dx, dz);
    const onMySide = p.team === 0 ? b.z < 0.2 : b.z > -0.2;
    if (responsible && onMySide && !p.swing && p.cd <= 0 && !r.serving
        && dist < skill.reach && b.y < 2.9 && b.y > 0.1 && mem.react <= 0 && swingNow(b, dx, dz, dist, mem)) {
      chooseShot(inp, game, p, os, skill);
      inp.swing = true;
      inp.slip = !!mem.flub; // a mishit: the bot still goes for the ball (it used to just watch it go by) but strikes it badly
    }
  } else {
    formation(inp, game, p, os, skill, mem);
  }
  return inp;
}

/** The ball left through a door: the nearer player of the receiving team follows it outside and returns it round the net post. */
function outsideBall(inp, game, p, os, skill, mem) {
  const b = game.ball;
  const partner = game.players[p.slot ^ 1];
  const mine = Math.hypot(b.x - p.x, b.z - p.z), theirs = partner.active ? Math.hypot(b.x - partner.x, b.z - partner.z) : Infinity;
  if (theirs < mine - 0.3 || (Math.abs(theirs - mine) <= 0.3 && partner.slot < p.slot)) { formation(inp, game, p, os, skill, mem); return; }
  const s = Math.sign(b.x) || 1;
  const doorZ = -os * (COURT.DOOR.z0 + COURT.DOOR.z1) / 2;
  if (Math.abs(p.x) <= COURT.HALF_W - 0.05) { // still inside: walk to the door first
    moveTo(inp, p, Math.abs(p.z - doorZ) > 0.5 ? s * 4.2 : s * 5.6, doorZ, skill, true);
    return;
  }
  moveTo(inp, p, b.x - s * 0.5, b.z - os * 0.3, skill, true);
  const d = Math.hypot(b.x - p.x, b.z - p.z);
  if (!p.swing && p.cd <= 0 && d < 1.3 && b.y > 0.1 && b.y < 2.2 && mem.react <= 0) inp.swing = true;
}

/** Press so the ball reaches the sweet spot about 0.17 s into the swing (where the racket face is square). */
function swingNow(b, dx, dz, dist, mem) {
  const closing = -(dx * b.vx + dz * b.vz) / (dist || 1);
  const ttc = Math.max(0, dist - 0.95) / Math.max(closing, 1.5);
  return dist < 1.25 || ttc <= 0.17 + (mem.jit || 0);
}

/** Serve: stronger levels wait for the ball at waist height, aim for the corners and add spin. */
function serve(inp, game, p, os, skill, mem, dt) {
  const rnd = game.rng;
  mem.serveT += dt;
  if (mem.serveWaitExtra === undefined) mem.serveWaitExtra = rnd() * 0.9;
  if (mem.serveT < 2.0 + skill.react * 2 + mem.serveWaitExtra || game.serveWait > 0) return; // give the receivers time to get set: no rushed serves
  const y = game.ball.y;
  // the racket meets the ball about 0.05 s after the press: judge the height then. Better levels wait for a tighter window.
  const yHit = serveBallHeight(game.time + 0.05);
  const win = skill.serveWindow ?? 0.5;
  if (Math.abs(yHit - 0.62) > win && mem.serveT < 4) return;
  void y;
  const boxSign = -game.rally.serveXSign;
  const edge = game.singles ? 3.2 : 4.4;
  // risk = how close to the lines the bot aims; the box is [0.3 .. edge] wide and 6.9 m deep
  const lateral = 1.4 + (edge - 2.6) * skill.serveRisk * rnd() + rnd() * 0.6; // bots no longer pick the extreme corners every time
  inp.ax = boxSign * Math.min(edge - 0.9, lateral);
  inp.az = os * (3.9 + 1.4 * skill.serveRisk * rnd());
  inp.mod = rnd() < skill.serveSpin ? (rnd() < 0.5 ? 3 : 1) : 0;
  inp.pace = (skill.servePace ?? 0.9) - rnd() * 0.06; // bots do not serve at full pace every time
  inp.swing = true;
  mem.serveT = 0;
  mem.serveWaitExtra = undefined;
}

/**
 * Doubles tactics, modelled on how real pairs move. A pair is almost always on the same line: both defending from the
 * baseline ('D') or both attacking at the net ('A'); the one-up-one-back split only exists briefly (the serve, the return,
 * a transition). The mode is decided ONCE per tick per team from shared information and stored on the game, so both
 * team-mates always agree without talking:
 *   incoming ball:  a lob or a deep ball → retreat (D); a short ball → go up (A)
 *   our own shot:   a good (deep, high) lob or a short low ball → go up (A); a poor lob or a drive → stay back (D)
 * A mode is held for a moment so the pair never flickers.
 */
function flightInfo(game) {
  const c = game._flight;
  if (c && c.tick === game.tickNo) return c;
  if (c && game.tickNo - c.tick < 4) return c; // recomputed every few ticks: it is only a tactical read
  const samples = predictBall(game.ball, 2.6);
  let apex = game.ball.y, firstFloor = null, netY = null, prevZ = game.ball.z;
  for (const s of samples) {
    apex = Math.max(apex, s.y);
    if (netY === null && (prevZ < 0) !== (s.z < 0)) netY = s.y;
    prevZ = s.z;
    if (!firstFloor && s.floor) firstFloor = s;
  }
  game._flight = { tick: game.tickNo, apex, firstFloor, netY };
  return game._flight;
}

function teamMode(game, p, skill) {
  const T = game.aiTeam || (game.aiTeam = [{ mode: 'D', since: 0, tick: -1 }, { mode: 'D', since: 0, tick: -1 }]);
  const S = T[p.team];
  if (S.tick === game.tickNo) return S.mode;
  S.tick = game.tickNo;
  const r = game.rally, b = game.ball;
  const f = flightInfo(game);
  const dFloor = f.firstFloor ? Math.abs(f.firstFloor.z) : 6; // distance from the net of the first bounce
  const lobby = f.apex > 3.2 && (f.netY === null || f.netY > 2.4);
  let want = null;
  const mate = game.players[p.slot ^ 1];
  if (mate.human) {
    // playing with a person: follow THEIR line (up when they are up, back when they are back) so the pair stays together; a
    // lob coming over still sends us back to cover it
    const incoming = r.lastTeam !== p.team;
    const lobIn = incoming && f.apex > 3.2 && (f.netY === null || f.netY > 2.4);
    if (lobIn) want = 'D';
    else if (Math.abs(mate.z) < 4.4) want = 'A';
    else if (Math.abs(mate.z) > 5.8) want = 'D';
    if (want && want !== S.mode && game.time - S.since >= 0.6) { S.mode = want; S.since = game.time; }
    return S.mode;
  }
  if (r.lastTeam !== p.team) { // the ball is coming to us
    const onMySide = p.team === 0 ? b.z < 0.5 : b.z > -0.5;
    if (lobby || dFloor > 6.2) want = 'D';
    else if (dFloor < 4.3 && b.y < 2.4 && skill.aggr >= 0.1) want = 'A';
    else if (!onMySide) want = null;
  } else { // we hit it
    if (lobby) want = dFloor > 7.2 ? 'A' : 'D'; // a deep lob wins the net, a poor one gets smashed
    else if (dFloor < 3.6 && f.apex < 2.0) want = 'A'; // a short low ball: they have to lift it
    else if (skill.aggr >= 0.1 && f.apex < 2.2 && game.players.filter((o) => o.team !== p.team && o.active).every((o) => Math.abs(o.z) > 6)) want = 'A';
  }
  if (want && want !== S.mode && game.time - S.since >= 0.8) { S.mode = want; S.since = game.time; }
  return S.mode;
}

function formation(inp, game, p, os, skill, mem) {
  const b = game.ball;
  if (game.singles) { moveTo(inp, p, clamp(b.x * 0.45, -2.4, 2.4), -os * ((skill.backZ ?? 7.6) - 0.1), skill, false); return; }
  const partner = game.players[p.slot ^ 1];
  const dp = Math.abs(p.z), dq = Math.abs(partner.z);
  const r = game.rally;
  if (r.serving || r.hits <= 1) {
    // the serve and the return keep the starting roles: server and receiver at the baseline, their partners at the net
    let net = dp < dq || (dp === dq && p.slot % 2 === 0);
    if (mem?.role) net = mem.role === 'net';
    const tz = -os * (net ? (skill.netZ ?? 3.4) : (skill.backZ ?? 7.6));
    const off = net ? (p.team === 0 ? -1.3 : 1.3) : (p.team === 0 ? 1.3 : -1.3);
    moveTo(inp, p, clamp(b.x * 0.45 + off, -3.6, 3.6), tz, skill, false);
    return;
  }
  // From the first return on, the pair moves as a unit: same line, side by side, shifting with the ball
  const mode = teamMode(game, p, skill);
  const lower = p.x < partner.x || (p.x === partner.x && p.slot < partner.slot); // each keeps their own side
  const att = mode === 'A';
  const centre = clamp(b.x * (att ? 0.5 : 0.55), -1.7, 1.7);
  const half = att ? 1.2 : 1.55; // the net pair is tighter; defenders cover more ground
  const tx = clamp(centre + (lower ? -half : half), -3.9, 3.9);
  const tz = -os * (att ? (skill.netZ ?? 3.4) - 0.5 : (skill.backZ ?? 7.6) - 0.4);
  if (mem) mem.role = Math.abs(p.z) < Math.abs(partner.z) ? 'net' : 'back';
  moveTo(inp, p, tx, tz, skill, false);
}

/** Pick the target and the shot: find the open space, then choose between lob, drop, smash, slice, drive. */
function chooseShot(inp, game, p, os, skill) {
  const rnd = game.rng;
  const b = game.ball;
  const opp = game.players.filter((o) => o.team !== p.team && o.active);
  const netOpp = opp.filter((o) => Math.abs(o.z) < 4.5).length;
  const deepOpp = opp.filter((o) => Math.abs(o.z) > 6.5).length;
  // Where to send it: weigh the open space (away from the opponents, the net player most of all) against changing the
  // direction of the ball (cross-court or down the line instead of always straight back) and keep away from the very
  // lines unless the bot is good enough to risk it.
  const lim = (game.singles ? 2.6 : 3.0) + 1.0 * skill.aggr;
  let bestX = 0, bestScore = -Infinity;
  const steps = game.singles ? [-2.6, -1.3, 0, 1.3, 2.6] : [-3.8, -2.5, -1.2, 0, 1.2, 2.5, 3.8];
  for (const x of steps) {
    if (Math.abs(x) > lim) continue;
    let space = Infinity;
    for (const o of opp) {
      const w = Math.abs(o.z) < 4.5 ? 1.35 : 1.0; // a player at the net covers less ground sideways but punishes a weak ball
      space = Math.min(space, Math.abs(o.x - x) * w + 0.12 * Math.abs(Math.abs(o.z) - 6));
    }
    const change = Math.abs(x - b.x) * 0.32; // send it somewhere else than where it came from
    const centre = Math.abs(x) < 0.7 ? -0.9 : 0; // the middle is the default of a weak player, not a plan
    const score = space + change + centre + rnd() * (1.6 - skill.aggr);
    if (score > bestScore) { bestScore = score; bestX = x; }
  }
  inp.ax = bestX + (rnd() - 0.5) * skill.noise;
  inp.az = os * (6 + rnd() * 2.6);
  inp.mod = 0;
  inp.lob = false;

  if (b.y > 2.1) { // overhead: remate when they are exposed, otherwise a placed bandeja or a víbora
    const r = rnd();
    if (r < skill.smash * (netOpp === 0 ? 1.0 : 0.6)) inp.mod = 0;
    else inp.mod = rnd() < 0.5 ? 2 : 1;
    if (inp.mod === 0) {
      inp.az = os * (netOpp ? 5 : 8);
      if (rnd() < skill.smash * 0.45 * (1 - skill.noise * 0.3)) inp.az = os * 3.4; // go for the kill: "por 4" (needs a clean contact)
    }
    return;
  }
  if (netOpp >= 1 && rnd() < skill.lob * 0.55) { // globo over the net players (not every time: it is a change of pace, not a habit)
    inp.lob = true; inp.az = os * 8.5;
  } else if (deepOpp === opp.length && rnd() < skill.aggr * 0.5) { // dejada against deep opponents
    inp.mod = 1; inp.az = os * 1.6;
  } else if (Math.abs(p.z) < 3.8 && rnd() < 0.25) { // chiquita at their feet
    inp.mod = 1; inp.az = os * 3;
  } else if (rnd() < skill.slice) { // slice to change the pace
    inp.mod = 3;
  }
}

/** Stars for a finished match from the human team's point of view. 0 = lost. */
export function starsFor(results) {
  if (results.winner !== 0) return 0;
  let mine = 0, theirs = 0;
  for (const [a, b] of results.score.sets) { mine += a; theirs += b; }
  const total = mine + theirs || 1;
  const share = theirs / total;
  return share <= 0.15 ? 3 : share <= 0.4 ? 2 : 1;
}

/** Ladder view from a {stageId: stars} map: stars per stage and which stages are unlocked. */
export function careerViewFrom(done = {}) {
  const stages = CAREER.map((s) => ({ ...s, stars: done[s.id] || 0, unlocked: s.id === 1 || (done[s.id - 1] || 0) >= 1 }));
  return { stages, stars: stages.reduce((a, s) => a + s.stars, 0), max: CAREER.length * 3 };
}

/** Apply a result to the stars map. Bonus XP is paid only for improving your best stars on a stage. */
export function applyCareerResult(done, stageId, stars) {
  const stage = CAREER.find((s) => s.id === stageId);
  const prev = done[stageId] || 0;
  const next = { ...done };
  let bonusXp = 0, unlocked = null;
  if (stage && stars > prev) {
    next[stageId] = stars;
    bonusXp = stage.xp * (stars - prev);
    if (prev === 0 && CAREER.some((s) => s.id === stageId + 1)) unlocked = stageId + 1;
  }
  return { done: next, stars, prev, bonusXp, unlocked };
}

/**
 * Bring any saved career to the current version without losing progress.
 * Accepts: nothing, a v1 save ({done: {stageId: stars}, xp}), or a v2 save (validated and clamped).
 */
export function migrateCareer(raw) {
  const s = defaultSave();
  if (!raw || typeof raw !== 'object') return s;
  if (raw.v === CAREER_VERSION) {
    const n = (v, d = 0) => (Number.isFinite(v) && v >= 0 ? v : d);
    s.season = Math.min(3, Math.max(1, Math.floor(n(raw.season, 1))));
    for (const k of ['coins', 'xp', 'points', 'devPoints', 'seed']) s[k] = Math.floor(n(raw[k], s[k]));
    for (const a of ATTRS) s.attrs[a] = Math.min(ATTR_MAX, Math.floor(n(raw.attrs?.[a], 0)));
    for (const k of Object.keys(s.stats)) s.stats[k] = Math.floor(n(raw.stats?.[k], 0));
    if (raw.done && typeof raw.done === 'object') for (const [id, d] of Object.entries(raw.done)) if (EVENT_BY_ID[id] && d && typeof d.result === 'string') s.done[id] = { result: d.result, points: Math.floor(n(d.points)) };
    if (Array.isArray(raw.history)) s.history = raw.history.slice(0, 40).filter((h) => h && typeof h.event === 'string');
    if (raw.drills && typeof raw.drills === 'object') for (const [id, st] of Object.entries(raw.drills)) if (DRILL_IDS.has(id) && st >= 0 && st <= 3) s.drills[id] = Math.floor(st);
    if (raw.objectives && typeof raw.objectives === 'object') for (const [id, v] of Object.entries(raw.objectives)) if (OBJECTIVE_IDS.has(id) && v) s.objectives[id] = true;
    if (Array.isArray(raw.unlockedRackets)) s.unlockedRackets = [...new Set([...s.unlockedRackets, ...raw.unlockedRackets.filter((i) => Number.isInteger(i) && i >= 0 && i < 8)])];
    if (raw.active && EVENT_BY_ID[raw.active.eventId] && Array.isArray(raw.active.rounds)) s.active = raw.active;
    return s;
  }
  // v1: {done: {stageId: stars}, xp}
  const done = raw.done && typeof raw.done === 'object' ? raw.done : {};
  let cleared = 0;
  for (const [stage, stars] of Object.entries(done)) {
    const ev = EVENT_BY_ID[LEGACY[stage]];
    if (!ev || !(stars >= 1)) continue;
    s.done[ev.id] = { result: 'champion', points: ev.points };
    s.points += ev.points; cleared++;
  }
  s.xp = Number.isFinite(raw.xp) && raw.xp > 0 ? Math.floor(raw.xp) : 0;
  s.stats.matches = s.stats.wins = cleared * 2; s.stats.titles = cleared;
  s.coins = cleared * 50; s.devPoints = cleared * 3; // a thank-you for progress made before the rewrite
  s.season = seasonOf(s);
  return s;
}

const STORAGE_KEY = 'padel.career2';

export function loadCareer(storage) {
  try {
    const raw = storage.getItem(STORAGE_KEY);
    if (raw) return migrateCareer(JSON.parse(raw));
    const old = storage.getItem(LEGACY_KEY); // never deleted: the old save stays as a backup
    return old ? migrateCareer(JSON.parse(old)) : defaultSave();
  } catch { return defaultSave(); }
}
export function saveCareer(storage, s) {
  try { storage.setItem(STORAGE_KEY, JSON.stringify(s)); return true; } catch { return false; }
}

export const levelFor = (xp) => Math.floor(Math.sqrt(xp / 100)) + 1;

export function seasonOf(s) {
  const done = (n) => EVENTS.filter((e) => e.season === n).every((e) => s.done[e.id]);
  return done(1) ? (done(2) ? 3 : 2) : 1;
}

/** Calendar status of every event: done / available / locked (with the reason). */
export function calendar(s) {
  const season = seasonOf(s);
  return EVENTS.map((e, i) => {
    const d = s.done[e.id];
    let locked = null;
    if (e.season > season) locked = `Finish season ${e.season - 1} first`;
    else if (e.requires?.points && s.points < e.requires.points) locked = `Needs ${e.requires.points} ranking points (you have ${s.points})`;
    else if (i > 0 && EVENTS[i - 1].season === e.season && !s.done[EVENTS[i - 1].id] && !d) locked = `Play ${EVENTS[i - 1].name} first`;
    return { event: e, done: d || null, locked: d ? null : locked, active: s.active?.eventId === e.id };
  });
}

function seeded(seed) {
  let s = (seed >>> 0) || 1;
  return () => { s = (s * 1664525 + 1013904223) >>> 0; return s / 4294967296; };
}

const levelRank = { easy: 0, normal: 1, hard: 2, expert: 3 };

/**
 * Build the draw. teams[0] is always the player (with their partner in doubles). Opponents come from the event's pool,
 * strongest last so later rounds are tougher.
 */
export function createTournament(event, seed) {
  const rng = seeded(seed);
  const per = event.mode === 'doubles' ? 2 : 1;
  const need = (event.size - 1) * per;
  // opponents: the event's own pool first (shuffled), then the closest-level characters from the rest of the roster,
  // so nobody ever appears twice in the same draw
  const preferred = [...new Set(event.pool.filter((id) => id !== event.partner))].map((id) => ({ id, k: rng() })).sort((x, y) => x.k - y.k).map((x) => x.id);
  const median = preferred.reduce((s, id) => s + levelRank[ROSTER_BY_ID[id].level], 0) / (preferred.length || 1);
  const others = ROSTER.map((r) => r.id).filter((id) => !preferred.includes(id) && id !== event.partner)
    .sort((x, y) => Math.abs(levelRank[ROSTER_BY_ID[x].level] - median) - Math.abs(levelRank[ROSTER_BY_ID[y].level] - median));
  const picked = [...preferred, ...others].slice(0, need);
  const byStrength = picked.sort((x, y) => levelRank[ROSTER_BY_ID[x].level] - levelRank[ROSTER_BY_ID[y].level] || ROSTER_BY_ID[x].points - ROSTER_BY_ID[y].points);
  const teams = [{ ids: event.mode === 'doubles' ? ['you', event.partner] : ['you'], player: true }];
  for (let i = 0; i < event.size - 1; i++) teams.push({ ids: byStrength.slice(i * per, i * per + per), player: false });

  const state = { eventId: event.id, format: event.format, mode: event.mode, teams, rounds: [], round: 0, status: 'playing', result: null, games: teams.map(() => ({ w: 0, l: 0, gf: 0, ga: 0 })) };
  if (event.format === 'group') {
    state.rounds = [
      { name: 'Group match 1', matches: [{ a: 0, b: 1 }, { a: 2, b: 3 }] },
      { name: 'Group match 2', matches: [{ a: 0, b: 2 }, { a: 1, b: 3 }] },
      { name: 'Group match 3', matches: [{ a: 0, b: 3 }, { a: 1, b: 2 }] },
    ];
  } else {
    // seed the player into a random slot, the others in strength order (weakest first), so the player meets the strongest last
    const slots = [...Array(event.size).keys()];
    const at = Math.floor(rng() * event.size);
    const order = slots.map((i) => (i === at ? 0 : null));
    let t = 1;
    for (let i = 0; i < event.size; i++) if (order[i] === null) order[i] = t++;
    const names = KO_ROUNDS[event.size];
    const first = { name: names[0], matches: [] };
    for (let i = 0; i < event.size; i += 2) first.matches.push({ a: order[i], b: order[i + 1] });
    state.rounds = [first];
    state.koNames = names;
  }
  return state;
}

/** The player's next match: {round, match, name, opponentTeam, opponents (roster ids)} or null when the event is over. */
export function nextPlayerMatch(state) {
  if (state.status !== 'playing') return null;
  const r = state.rounds[state.round];
  if (!r) return null;
  const m = r.matches.find((x) => (x.a === 0 || x.b === 0) && x.winner === undefined);
  if (!m) return null;
  const opp = m.a === 0 ? m.b : m.a;
  return { round: state.round, name: r.name, opponentTeam: opp, opponents: state.teams[opp].ids };
}

/**
 * Record the player's match and advance the event.
 * @param simulate (idsA, idsB) => {winner: 0|1, gamesA, gamesB} used for every match the player is not in
 */
export function reportPlayerMatch(state, won, gamesFor, gamesAgainst, simulate) {
  const r = state.rounds[state.round];
  const pm = r.matches.find((x) => (x.a === 0 || x.b === 0) && x.winner === undefined);
  const youA = pm.a === 0;
  pm.winner = won ? 0 : (youA ? pm.b : pm.a);
  pm.score = `${gamesFor}-${gamesAgainst}`;
  const book = (a, b, winner, gA, gB) => {
    const g = state.games;
    g[a].gf += gA; g[a].ga += gB; g[b].gf += gB; g[b].ga += gA;
    g[winner].w++; g[winner === a ? b : a].l++;
  };
  book(pm.a, pm.b, pm.winner, youA ? gamesFor : gamesAgainst, youA ? gamesAgainst : gamesFor);
  for (const m of r.matches) {
    if (m.winner !== undefined) continue;
    const sim = simulate(state.teams[m.a].ids, state.teams[m.b].ids);
    m.winner = sim.winner === 0 ? m.a : m.b;
    m.score = `${sim.gamesA}-${sim.gamesB}`;
    book(m.a, m.b, m.winner, sim.gamesA, sim.gamesB);
  }
  advance(state, won);
  return state;
}

function advance(state, playerWon) {
  const r = state.rounds[state.round];
  if (state.format === 'knockout') {
    if (!playerWon) { state.status = 'done'; state.result = r.name === 'Final' ? 'finalist' : r.name === 'Semi-final' ? 'semi' : 'quarter'; return; }
    if (state.round === state.rounds.length - 1 && r.name === 'Final') { state.status = 'done'; state.result = 'champion'; return; }
    const winners = r.matches.map((m) => m.winner);
    const next = { name: state.koNames[state.round + 1], matches: [] };
    for (let i = 0; i < winners.length; i += 2) next.matches.push({ a: winners[i], b: winners[i + 1] });
    state.rounds.push(next); state.round++;
    return;
  }
  // group: after 3 matches the top two play the final
  if (state.round < 2) { state.round++; return; }
  if (state.round === 2) {
    const order = standings(state);
    const pos = order.indexOf(0);
    if (pos > 1) { state.status = 'done'; state.result = pos === 2 ? 'third' : 'fourth'; return; }
    state.rounds.push({ name: 'Final', matches: [{ a: order[0], b: order[1] }] });
    state.round = 3; return;
  }
  state.status = 'done';
  state.result = playerWon ? 'champion' : 'finalist';
}

/** Group table: wins, then game difference. Returns team indexes best first. */
export function standings(state) {
  return state.teams.map((_, i) => i).sort((a, b) => state.games[b].w - state.games[a].w || (state.games[b].gf - state.games[b].ga) - (state.games[a].gf - state.games[a].ga) || a - b);
}

/** Run a real headless match between two rostered teams. Deterministic for a given seed. */
export function simulateMatch(idsA, idsB, event, seed) {
  const rng = seeded(seed);
  const singles = event.mode === 'singles';
  const g = new PadelGame({ rng, settings: { mode: singles ? 'singles' : 'doubles', sets: 1, gamesPerSet: 3, goldenPoint: !!event.golden } });
  const slots = singles ? [[0, idsA[0]], [2, idsB[0]]] : [[0, idsA[0]], [1, idsA[1]], [2, idsB[0]], [3, idsB[1]]];
  const bots = {};
  for (const [slot, id] of slots) { const c = ROSTER_BY_ID[id] || ROSTER_BY_ID.marta; bots[slot] = { level: c.level, style: c.style }; }
  const mem = [0, 1, 2, 3].map(makeBotMemory);
  let done = null;
  for (let i = 0; i < 60 * 60 * 10 && !done; i++) {
    for (const [slot] of slots) g.applyInput(slot, botInput(g, slot, mem[slot], bots[slot], 1 / 60));
    g.tick(1 / 60);
    done = g.drainEvents().find((e) => e.e === 'match');
  }
  if (!done) { // too long: the team with more points wins
    const tp = g.match.totalPoints;
    return { winner: tp[0] >= tp[1] ? 0 : 1, gamesA: g.match.games[0], gamesB: g.match.games[1] };
  }
  let ga = 0, gb = 0;
  for (const [a, b] of done.results.score.sets) { ga += a; gb += b; }
  return { winner: done.winner, gamesA: ga, gamesB: gb };
}

// ------------------------------------------------------------------ applying results

export function commentary(won, gf, ga, opponentNote) {
  const total = gf + ga || 1;
  if (won && ga === 0) return 'A perfect match. Not a single game dropped.';
  if (won && ga / total <= 0.25) return 'Dominant. You controlled the rally from the first ball.';
  if (won && ga / total >= 0.45) return 'A fight to the end, and you found the extra point when it mattered.';
  if (won) return 'A solid win. You kept the errors down and made them hurry.';
  if (ga / total >= 0.7) return 'Outplayed today. Read the scouting notes and change the pattern next time.';
  return `Close, but not enough. ${opponentNote || ''}`.trim();
}

/** Apply the result of one played match to the save: stats, history, XP, development points. Returns what changed. */
export function applyMatch(save, event, roundName, won, res) {
  save.stats.matches++;
  const out = { devPoints: 0, xp: 20 };
  if (won) { save.stats.wins++; out.devPoints += 2; out.xp += 20; if (res.gamesAgainst === 0) save.stats.shutouts++; }
  save.stats.smashes += res.smashes || 0;
  save.stats.aces += res.aces || 0;
  if (res.upset) save.stats.upsets++;
  save.devPoints += out.devPoints; save.xp += out.xp;
  save.history.unshift({ at: res.at ?? 0, event: event.id, round: roundName, won, score: `${res.gamesFor}-${res.gamesAgainst}`, opp: res.opp });
  save.history.length = Math.min(save.history.length, 30);
  return out;
}

/** The event is over: pay the finish rewards and mark it done. */
export function completeEvent(save, event, result) {
  const r = finishRewards(event, result);
  save.points += r.points; save.coins += r.coins; save.xp += r.xp;
  if (result === 'champion') { save.stats.titles++; save.devPoints += 5; r.devPoints = 5; }
  save.done[event.id] = { result, points: r.points };
  save.active = null;
  save.season = seasonOf(save);
  return r;
}

// ------------------------------------------------------------------ player development

export const attrCost = (level) => level + 1;

export function buyAttr(save, attr) {
  if (!ATTRS.includes(attr)) return { ok: false, reason: 'Unknown attribute' };
  const lv = save.attrs[attr];
  if (lv >= ATTR_MAX) return { ok: false, reason: 'Already at maximum' };
  const cost = attrCost(lv);
  if (save.devPoints < cost) return { ok: false, reason: `Needs ${cost} development points` };
  save.devPoints -= cost; save.attrs[attr]++;
  return { ok: true };
}

/**
 * Gameplay modifiers from the attributes. Noticeable but bounded (about +15% speed and pace at the maximum), so a developed player is better, not a different species.
 * Only ever applied to local single-player matches: online everybody is equal.
 */
export function attrMods(a) {
  const x = (k) => Math.min(ATTR_MAX, a?.[k] || 0);
  return {
    runMul: 1 + 0.015 * x('movement'), power: 1 + 0.015 * x('power'), regenMul: 1 + 0.04 * x('stamina'), drainMul: 1 - 0.04 * x('stamina'), spin: 1 + 0.03 * x('variety'),
    window: 1 + 0.01 * x('reaction'),
    q: { ground: 0.01 * x('groundstroke'), volley: 0.01 * x('volley'), smash: 0.01 * x('smash'), lob: 0.01 * x('lob'), defense: 0.01 * x('defense') },
  };
}

/** Record a finished drill: keeps the best stars, pays development points only for improvement. */
export function applyDrill(save, drill, score) {
  const stars = drillStars(drill, score);
  const prev = save.drills[drill.id] || 0;

  if (stars > prev) { dev = stars - prev; save.drills[drill.id] = stars; save.devPoints += dev; save.xp += 15 * dev; }
  return { stars, prev, devPoints: dev };
}

// Authoritative match simulation: players, ball, shots, padel rules and scoring flow.
// Runs on the server; the client only reuses stepPlayer for prediction.

import {
  COURT, PLAYER, POINT_PAUSE, DEFAULT_SETTINGS, SHOT_IDS, clamp,
} from './constants.js';
import {
  stepPlayer, stepBall, makeBall, serveBallHeight, solveLaunch, simulateShot, serveLimit,
} from './physics.js';
import { COURTS } from './looks.js';
import {
  createMatch, pointWon, currentServer, serveSide, scoreView,
} from './scoring.js';

const NET_CLEAR = COURT.NET_H + 0.14;

const blankInput = () => ({ mx: 0, mz: 0, sprint: false, ax: 0, az: 0, mod: 0, lob: false });

export class PadelGame {
  /**
   * @param opts.settings  match settings (see DEFAULT_SETTINGS)
   * @param opts.rng       () => [0,1) random source (injectable for tests)
   */
  constructor({ settings = {}, rng = Math.random } = {}) {
    this.settings = { ...DEFAULT_SETTINGS, ...settings };
    this.rng = rng;
    this.match = createMatch({
      sets: this.settings.sets,
      gamesPerSet: this.settings.gamesPerSet,
      goldenPoint: this.settings.goldenPoint,
      singles: this.settings.mode === 'singles',
    });
    this.singles = this.settings.mode === 'singles';
    this.mods = this.settings.attrMods || null; // player development (local matches only): small modifiers for slot 0
    this.xLim = this.singles ? 3.25 : PLAYER.MAX_X; // 1v1 is played on a narrower, fully walled court
    this.players = [0, 1, 2, 3].map((slot) => ({
      slot, team: slot >> 1,
      x: 0, z: 0, vx: 0, vz: 0, stamina: PLAYER.STAMINA_MAX,
      input: blankInput(), wantSwing: null, wantJump: false,
      swing: null, cd: 0, jumpT: 0, kind: 0, ack: 0,
      active: !(this.settings.mode === 'singles' && (slot === 1 || slot === 3)),
      xLim: this.settings.mode === 'singles' ? 3.25 : PLAYER.MAX_X,
    }));
    if (this.mods) { this.players[0].speedMul = this.mods.runMul; this.players[0].regenMul = this.mods.regenMul; this.players[0].drainMul = this.mods.drainMul || 1; }
    this.ball = makeBall();
    this.ball.hw = this.singles ? 3.5 : COURT.HALF_W;
    this.openings = !this.singles && this.settings.openings !== false; // access doors in the side walls (doubles)
    this.ball.doors = this.openings;
    for (const pl of this.players) pl.pit = this.openings;
    const surf = (COURTS[this.settings.court] || COURTS.indoor).surface; // each court has its own turf
    this.ball.fe = surf.floorE;
    this.ball.ff = surf.floorFric;
    this.events = [];
    this.time = 0;
    this.tickNo = 0;
    this.pauseT = 0;
    this.serveWait = 0;
    this.serveIdle = 0;
    this.stats = {
      players: this.players.map(() => ({
        hits: 0, winners: 0, errors: 0, smashes: 0, volleys: 0, aces: 0, doubleFaults: 0, bandejas: 0, viboras: 0,
      })),
      longestRally: 0,
      rallies: 0,
    };
    this.startPoint();
  }

  get phase() { return this._phase; }
  set phase(v) { this._phase = v; }

  // ---------------------------------------------------------------- point setup

  startPoint() {
    const srv = currentServer(this.match);
    const side = serveSide(this.match);
    const os = srv.team === 0 ? 1 : -1; // direction the server attacks
    const sx = side === 0 ? 2.4 : -2.4;
    const serverSlot = srv.team * 2 + srv.idx;
    const recvTeam = 1 - srv.team;
    const recvSlot = recvTeam * 2 + (this.singles ? 0 : side === 0 ? 0 : 1);
    const place = (slot, x, z) => {
      const p = this.players[slot];
      p.x = x; p.z = z; p.vx = 0; p.vz = 0; p.swing = null; p.cd = 0; p.jumpT = 0; p.kind = 0;
      p.input = blankInput(); p.wantSwing = null; p.wantJump = false;
    };
    place(serverSlot, sx, -os * 8.2);
    place(recvSlot, -sx, os * 7.6);
    if (this.singles) {
      for (const s of [1, 3]) place(s, 40, 0); // parked off-court, inactive
    } else {
      place(serverSlot ^ 1, -sx, -os * 2.3);
      place(recvSlot ^ 1, sx, os * 2.3);
    }
    this.serverSlot = serverSlot;
    this.startPos = this.players.map((p) => [p.x, p.z]); // where everybody stands for this point (restored after a fault)
    this.rally = {
      serving: true, faults: 0, lastTeam: srv.team, lastSlot: serverSlot,
      bounces: 0, hits: 0, netTouched: false, serveXSign: Math.sign(sx),
    };
    this.phase = 'serve';
    this.serveWait = 0.9;
    this.serveIdle = 0;
    this.holdBall();
    this.events.push({ e: 'serve', slot: serverSlot, side, score: scoreView(this.match) });
  }

  holdBall() {
    const p = this.players[this.serverSlot];
    const os = p.team === 0 ? 1 : -1;
    const b = this.ball;
    // the ball is bounced by hand until the serve is hit (hit below the waist after a bounce)
    b.x = p.x + os * 0.22; b.y = serveBallHeight(this.time); b.z = p.z + os * 0.4;
    b.vx = b.vy = b.vz = 0; b.sb = 0; b.ss = 0; b.ex = false;
  }

  // ---------------------------------------------------------------- input

  applyInput(slot, inp) {
    const p = this.players[slot];
    if (!p || !inp) return;
    p.input = {
      mx: clamp(+inp.mx || 0, -1, 1), mz: clamp(+inp.mz || 0, -1, 1),
      sprint: !!inp.sprint, steer: !!inp.steer,
      ax: clamp(+inp.ax || 0, -20, 20), az: clamp(+inp.az || 0, -20, 20),
      mod: inp.mod === 1 || inp.mod === 2 || inp.mod === 3 ? inp.mod : 0, lob: !!inp.lob,
      keep: !!inp.keep, // bots decide their target when they start the swing and keep it until contact
    };
    if (inp.swing) p.wantSwing = { ax: p.input.ax, az: p.input.az, mod: p.input.mod, lob: p.input.lob, pace: clamp(+inp.pace || 0.9, 0.6, 1.15), slip: !!inp.slip };
    if (inp.jump) p.wantJump = true;
  }

  // ---------------------------------------------------------------- main step

  tick(dt) {
    this.time += dt;
    this.tickNo++;
    const live = this.phase === 'serve' || this.phase === 'rally';

    for (const p of this.players) {
      if (!p.active) continue;
      p.inRally = this.phase === 'rally';
      if (live) {
        const mul = p.swing ? PLAYER.SWING_MOVE : 1; // planted while swinging
        if (this.phase !== 'serve') stepPlayer(p, p.input, dt, undefined, mul);
        else { p.vx = 0; p.vz = 0; this.rest(p, dt); } // the server stays planted on the line, everyone else waits too (and catches their breath)
      } else this.rest(p, dt); // between points everybody recovers
      p.jumpT = Math.max(0, p.jumpT - dt);
      p.cd = Math.max(0, p.cd - dt);
      if (live && p.wantJump && p.jumpT <= 0) p.jumpT = PLAYER.JUMP_TIME;
      p.wantJump = false;
      if (live && p.wantSwing && this.phase === 'serve' && this.serveWait > 0) {
        // a click just before the serve opens is buffered rather than lost
      } else {
        if (live && p.wantSwing && !p.swing && p.cd <= 0) this.startSwing(p, p.wantSwing);
        p.wantSwing = null;
      }
    }
    this.separateTeammates();

    for (const p of this.players) {
      if (!p.swing) continue;
      p.swing.t += dt;
      if (live && this.phase === 'rally' && !p.swing.done && p.swing.t < PLAYER.CONTACT_TO) this.lunge(p, dt);
      if (live && !p.swing.done && p.swing.t >= PLAYER.CONTACT_FROM && p.swing.t <= PLAYER.CONTACT_TO * (p.slot === 0 && this.mods ? this.mods.window : 1)) {
        if (this.phase === 'serve') {
          if (p.slot === this.serverSlot && this.serveWait <= 0) { this.doServe(p); p.swing.done = true; }
        } else {
          // the racket meets the ball at the sweet spot: wait for it unless it is already leaving or the window is closing
          const bb = this.ball;
          const d = Math.hypot(bb.x - p.x, bb.z - p.z);
          const approaching = d < (p.swing.lastD ?? Infinity) - 1e-6;
          p.swing.lastD = d;
          const ready = d <= 1.2 || !approaching || p.swing.t >= PLAYER.CONTACT_TO - 2 * dt;
          if (ready && this.contact(p)) p.swing.done = true;
        }
      }
      if (p.swing.t >= PLAYER.SWING_TIME) { p.swing = null; p.cd = PLAYER.SWING_COOLDOWN - PLAYER.SWING_TIME; }
    }

    if (this.phase === 'serve') {
      this.serveWait = Math.max(0, this.serveWait - dt);
      this.holdBall();
      this.serveIdle += dt;
      if (this.serveIdle > 20 && this.serveWait <= 0) {
        const p = this.players[this.serverSlot];
        if (!p.swing) this.startSwing(p, { ax: 0, az: (p.team === 0 ? 1 : -1) * 5, mod: 0, lob: false });
      }
    } else if (this.phase === 'rally') {
      const ev = [];
      stepBall(this.ball, dt, ev);
      for (const e of ev) {
        if (this.phase !== 'rally') break;
        this.onBallEvent(e);
      }
    } else if (this.phase === 'point' || this.phase === 'ended') {
      const ev = [];
      stepBall(this.ball, dt, ev); // let the ball coast (also after the last point of the match); events no longer matter
      for (const e of ev) if (e.type === 'floor' || e.type === 'wall') this.events.push({ e: 'ball', k: e.type, x: e.x, y: e.y ?? 0, z: e.z, s: e.speed, mesh: !!e.mesh });
      if (this.phase === 'point') {
        this.pauseT -= dt;
        if (this.pauseT <= 0) this.startPoint();
      } else if (this.ball.y <= 0.04 && Math.hypot(this.ball.vx, this.ball.vz) < 0.2) { this.ball.vx = this.ball.vz = 0; }
    }
  }

  /**
   * Where the shot goes is decided at the moment of contact (like a tennis game): with steering aim, the direction
   * held at that instant wins (left/right = that side, forward = deep, back = short). Otherwise the latest aim point.
   */
  aimFor(p) {
    const inp = p.input, os = p.team === 0 ? 1 : -1;
    if (inp.keep && p.swing) return { ax: p.swing.ax, az: p.swing.az };
    let ax = inp.ax, az = inp.az;
    if (inp.steer) {
      if (Math.abs(inp.mx) > 0.25) ax = Math.sign(inp.mx) * 3.4;
      const f = inp.mz * os;
      if (f > 0.25) az = os * 8.8; else if (f < -0.25) az = os * 3.0;
    }
    return { ax, az };
  }

  /** A last step toward the ball while swinging, so the racket arrives where the ball is (no hitting from across the court). */
  lunge(p, dt) {
    const b = this.ball, r = this.rally;
    if (r.lastTeam === p.team || r.serving) return;
    if (p.team === 0 ? b.z > 0.25 : b.z < -0.25) return;
    const dx = b.x - p.x, dz = b.z - p.z;
    const d = Math.hypot(dx, dz);
    if (d <= 1.1 || d > 2.7 || b.y > 3.2) return;
    const step = Math.min(d - 1.1, 5.5 * dt);
    p.swing.lunged = (p.swing.lunged || 0) + step;
    const nx = p.x + (dx / d) * step;
    p.x = p.pit && Math.abs(p.x) > COURT.HALF_W // out in the strip beside the court
      ? Math.sign(nx) * clamp(Math.abs(nx), COURT.HALF_W + 0.4, COURT.HALF_W + COURT.PIT.w - 0.4)
      : clamp(nx, -p.xLim, p.xLim);
    const nz = p.z + (dz / d) * step;
    p.z = p.team === 0 ? clamp(nz, -COURT.HALF_L + PLAYER.BACK_GAP, -PLAYER.NET_GAP) : clamp(nz, PLAYER.NET_GAP, COURT.HALF_L - PLAYER.BACK_GAP);
  }

  rest(p, dt) {
    p.stamina = Math.min(PLAYER.STAMINA_MAX, p.stamina + PLAYER.STAMINA_REGEN * (p.regenMul || 1) * dt);
  }

  separateTeammates() {
    if (this.singles) return;
    for (let t = 0; t < 2; t++) {
      const a = this.players[t * 2];
      const b = this.players[t * 2 + 1];
      const dx = b.x - a.x, dz = b.z - a.z;
      const d = Math.hypot(dx, dz);
      const min = 0.9;
      if (d < min) {
        const nx = d > 1e-4 ? dx / d : 1, nz = d > 1e-4 ? dz / d : 0;
        const push = (min - d) / 2;
        a.x -= nx * push; a.z -= nz * push;
        b.x += nx * push; b.z += nz * push;
      }
    }
  }

  // ---------------------------------------------------------------- shots

  classify(p, sw) {
    const b = this.ball;
    if (sw.lob) return 'lob';
    if (b.y > 2.1) return sw.mod === 2 ? 'bandeja' : sw.mod === 1 ? 'vibora' : 'smash';
    const nearNet = Math.abs(p.z) < 3.8;
    if (sw.mod === 3) return 'slice';
    if (sw.mod === 1) return nearNet ? 'chiquita' : 'drop';
    if (sw.mod === 2) return 'block';
    if (nearNet && this.rally.bounces === 0 && b.y > 0.35) return 'volley';
    const right = p.team === 0 ? b.x < p.x : b.x > p.x; // right-handed
    return right ? 'forehand' : 'backhand';
  }

  startSwing(p, sw) {
    if (this.phase === 'serve' && p.slot !== this.serverSlot) return;
    p.swing = { t: 0, done: false, ax: sw.ax, az: sw.az, mod: sw.mod, lob: sw.lob, pace: sw.pace || 0.9, slip: !!sw.slip };
    p.kind = SHOT_IDS.indexOf(this.phase === 'serve' ? 'serve' : this.classify(p, sw));
  }

  /**
   * Choose where the ball should land, how fast and with which spin, then solve the launch velocity
   * through the real ball physics (so drag and Magnus lift are compensated and the aim stays honest).
   */
  /**
   * ctx (optional) is the racket contact: {face, e, lateral, forward}
   *   face    -1 closed .. +1 open (from swing timing and ball height): an open face launches higher and adds backspin,
   *           a closed face is flatter with topspin and gets no net-clearance help when strongly closed
   *   e       distance of the strike from the sweet spot in metres (0 = centre of the face): edge hits lose pace and scatter
   *   lateral sideways running speed (m/s): costs accuracy;  forward: speed toward the net (m/s): adds a little pace
   */
  planShot(kind, b, os, aimX, aimZ, q, inSpeed = 0, spinOv = null, ctx = null) {
    if (ctx?.outside) return this.planOutside(b, os, q);
    const lim = this.singles ? 3.2 : 4.5;
    let tx = clamp(aimX, -lim, lim);
    let depth = clamp(Math.abs(aimZ), 1, 9.4);
    let speed = 19;
    let kill = false;
    let sb = 0, ss = 0; // backspin(+)/topspin(-), sidespin
    switch (kind) {
      case 'serve': speed = (9.5 + 5 * q) * (this._servePace || 1); depth = clamp(Math.abs(aimZ), 2.5, 9); sb = 4; break; // (a charged serve may overshoot the box, see doServe)
      case 'forehand': sb = -9; depth = clamp(depth, 3, 9.2); break; // topspin drive
      case 'backhand': sb = -6; depth = clamp(depth, 3, 9.2); break;
      case 'slice': speed = 13.5; sb = 17; depth = clamp(depth, 3, 9.2); break; // skidding backspin
      case 'volley': speed = 16.5; depth = clamp(depth, 3, 9); sb = 5; break;
      case 'smash': speed = 30; depth = clamp(depth, 2.5, 8.5); sb = -4;
        // "por 4": a clean smash aimed short and hit from the net comes down steeply with topspin, bounces very high and leaves the
        // court over the fence: a winner (needs a clean contact: a poor one just goes into the net or the glass)
        if (q >= 0.8 && depth <= 4.8 && Math.abs(b.z) < 5.5 && b.y >= 2.2) { speed = 36; sb = -12; kill = true; }
        break;
      case 'bandeja': speed = 13.5; depth = clamp(Math.max(depth, 6.5), 6.5, 9); sb = 15; break; // slow, backspin, stays low off the glass
      case 'vibora': // fast, sidespin: kicks sideways off the glass
        speed = 19; depth = clamp(depth, 5, 9); tx = clamp(tx * 1.2, -lim - 0.1, lim + 0.1); sb = 7;
        ss = (Math.sign((tx - b.x) * os) || 1) * 17;
        break;
      case 'lob': depth = clamp(Math.max(depth, 7.2), 7, 9.3); sb = -6; break; // globo
      case 'chiquita': speed = 8; depth = clamp(depth, 2.2, 4); sb = 9; break;
      case 'drop': speed = 6.5; depth = clamp(depth, 1.1, 2.4); sb = 21; break;
      case 'block': speed = 9.5; depth = clamp(depth, 4, 8); sb = 3; break;
      default: depth = clamp(depth, 3, 9.2);
    }
    if (kind !== 'serve') speed *= 0.8 + 0.2 * q; // a poorly struck ball carries less pace
    if (['forehand', 'backhand', 'slice', 'volley', 'block'].includes(kind)) depth = Math.max(2.5, depth - (1 - q) * 3.5); // and falls short
    if (spinOv) { sb = spinOv.sb; ss = spinOv.ss || 0; }
    if (ctx) {
      sb += ctx.face * 5; // spin transfer from the face angle
      sb *= ctx.spinMul || 1; ss *= ctx.spinMul || 1;
      speed *= 1 - 0.22 * clamp(ctx.e / 0.85, 0, 1); // energy lost off-centre
      speed *= 1 + clamp(ctx.forward, -3, 3) * 0.012; // moving into the shot adds pace
      speed *= ctx.powerMul || 1; // upgrades add pace, fatigue takes it away
    }
    const spinQ = 0.4 + 0.6 * q; // mishit balls carry less spin
    sb *= spinQ; ss *= spinQ;
    // A lob is only as good as the contact: a clean one climbs high and lands deep (hard to attack); a poor one is low and
    // short, an invitation to smash
    const lobQ = kind === 'lob' ? clamp(q, 0.3, 1) : 1;
    if (kind === 'lob') depth = clamp(depth - (1 - lobQ) * 5.0, 4.2, 9.3);
    let tz = os * depth;
    let err = (1 - q) * (kind === 'serve' ? 1.4 : 1.7);
    if (kind === 'serve') err *= 1 + 3 * Math.max(0, (this._servePace || 1) - 1); // all-out power costs accuracy
    if (ctx) err *= 1 + 0.8 * clamp((ctx.e - 0.4) / 0.45, 0, 1) + 0.05 * ctx.lateral; // edge hits and sideways running are less reliable
    tx += (this.rng() - 0.5) * 2 * err;
    tz += (this.rng() - 0.5) * 2 * err * 0.8;
    const dist = Math.hypot(tx - b.x, tz - b.z);
    let T = kind === 'lob'
      ? clamp(1.5 + dist * 0.05, 1.7, 2.4) * (0.7 + 0.3 * lobQ)
      : dist / (speed * (0.8 + 0.4 * q + Math.min(0.2, inSpeed * 0.007))); // returns carry some of the incoming pace
    if (ctx && kind !== 'lob' && kind !== 'serve') T *= 1 + 0.16 * ctx.face; // open face = higher, slower arc
    T = Math.max(T, kill ? 0.13 : 0.28);
    const spin = { sb, ss };
    // a mishit (bots only) ends in the net or long: 60% / 40%
    const slipNet = !!ctx?.slip && this.rng() < 0.6;
    if (ctx?.slip && !slipNet) tz = os * 11.2; // long: it hits the back wall before it bounces
    if (slipNet) T *= 0.74; // flat and low: into the net
    let aimX2 = tx, aimZ2 = tz;
    let v = solveLaunch(b, aimX2, aimZ2, T);
    // well-struck balls clear the net (poor contact does not get that help); then correct the launch so spin and drag
    // still land the ball on the aimed spot. Both are checked together: fixing one must not undo the other.
    const needClear = kind !== 'lob' && (!ctx || ctx.face > -0.6) && !slipNet;
    let corrections = 0;
    for (let it = 0; it < 24; it++) {
      v = solveLaunch(b, aimX2, aimZ2, T);
      const sim = simulateShot(b, v, spin);
      if (needClear && (sim.kind === 'net' || (sim.netH !== null && sim.netH < NET_CLEAR))) { T *= 1.06; continue; }
      if (sim.kind === 'floor' && corrections < 4) {
        const ex = tx - sim.x, ez = tz - sim.z;
        if (Math.hypot(ex, ez) < 0.08) break;
        aimX2 += ex; aimZ2 += ez; corrections++;
        continue;
      }
      break;
    }
    if (slipNet) v = { ...v, vy: Math.min(v.vy, 0.8) - 1.0 }; // a real mishit: it dives into the net or the floor in front of the hitter
    return { ...v, sb, ss };
  }

  /**
   * A ball played from the strip outside the court: it cannot go through the glass, so it travels along the strip, round the
   * net post and in through the opponents' door. Look for a flight that really does that (simulated with the real physics).
   */
  planOutside(b, os, q) {
    const s = Math.sign(b.x) || 1;
    const D = COURT.DOOR;
    const doorZ = os * (D.z0 + D.z1) / 2;
    const spin = { sb: 3, ss: 0 };
    const err = (1 - q) * 0.5;
    let best = null;
    for (const jit of [0, 0.3, -0.3]) {
      for (const T of [1.0, 1.15, 0.9, 1.3, 0.8, 1.5]) {
        for (const L of [3.5, 4.5, 2.8]) {
          const dx = COURT.HALF_W * s - b.x, dz = doorZ + jit - b.z;
          const dl = Math.hypot(dx, dz) || 1;
          const tx = COURT.HALF_W * s + (dx / dl) * L + (this.rng() - 0.5) * 2 * err;
          const tz = doorZ + jit + (dz / dl) * L + (this.rng() - 0.5) * 2 * err;
          if (Math.abs(tx) > 4.6 || os * tz < 1.2 || os * tz > 9.2) continue;
          const v = solveLaunch(b, tx, tz, T);
          const sim = simulateShot(b, v, spin);
          if (sim.kind === 'floor' && os * sim.z > 0.3 && Math.abs(sim.x) < 4.9) return { ...v, sb: spin.sb, ss: 0 };
          best = best || v;
        }
      }
    }
    const v = best || solveLaunch(b, 0, os * 6, 1.2);
    return { ...v, sb: spin.sb, ss: 0 };
  }

  doServe(p) {
    const os = p.team === 0 ? 1 : -1;
    const sw = p.swing;
    const b = this.ball;
    const boxSign = -this.rally.serveXSign;
    const aim = this.aimFor(p);
    const ax = aim.ax * boxSign > 0 ? aim.ax : boxSign * 2.5;
    const edge = this.singles ? 3.3 : 4.6;
    const lo = boxSign > 0 ? 0.3 : -edge;
    const hi = boxSign > 0 ? edge : -0.3;
    // contact height on the bounce decides quality: best around 0.6 m (waist height)
    const tiredK = clamp((PLAYER.TIRED_FROM - p.stamina) / PLAYER.TIRED_FROM, 0, 1);
    const q = clamp(1.02 - Math.abs(b.y - 0.62) / 0.3 - 0.2 * tiredK, 0.3, 0.98); // best at waist height; the window is narrow, and a tired server is less accurate
    const spinOv = sw.mod === 3 ? { sb: 15 } : sw.mod === 1 ? { sb: -9 } : null; // R = slice serve, Q = kick serve
    this._servePace = sw.pace || 0.9; // bots serve a little softer; humans choose by holding the key (charge) and releasing
    // Hitting it with everything (a full charge) costs control: it tends to fly long, past the service line. A clean contact
    // keeps it closer; a mistimed one sails.
    const over = clamp(((sw.pace || 1) - 0.9) / 0.22, 0, 1); // 0 for a tap, 1 for a full charge (bots serve at 0.68-0.8 and are not affected)
    const overshoot = over * (1.3 + 2.2 * (1 - q) + (this.rng() - 0.5) * 1.6);
    const v = this.planShot('serve', b, os, clamp(ax, lo, hi), os * (clamp(Math.abs(aim.az), 2.5, 6.3) + Math.max(0, overshoot)), q, 0, spinOv);
    b.vx = v.vx; b.vy = v.vy; b.vz = v.vz; b.sb = v.sb; b.ss = v.ss;
    this.phase = 'rally';
    const r = this.rally;
    r.lastTeam = p.team; r.lastSlot = p.slot; r.bounces = 0; r.hits = 1; r.netTouched = false; r.serving = true;
    this.stats.players[p.slot].hits++;
    this.events.push({ e: 'hit', slot: p.slot, kind: 'serve', q: +q.toFixed(2), label: q >= 0.85 ? 'perfect' : q >= 0.6 ? 'good' : 'poor', x: b.x, y: b.y, z: b.z, sb: v.sb, ss: v.ss });
  }

  contact(p) {
    const b = this.ball;
    const r = this.rally;
    if (r.lastTeam === p.team || r.serving) return false; // a serve must bounce in the box first
    const own = p.team === 0 ? b.z <= 0.25 : b.z >= -0.25;
    if (!own) return false;
    const maxH = p.jumpT > 0 ? 3.5 : 2.75;
    if (b.y < 0.08 || b.y > maxH) return false;
    const dx = b.x - p.x, dz = b.z - p.z;
    const d = Math.hypot(dx, dz);
    if (d > PLAYER.REACH) return false;

    const sw = p.swing;
    const outside = Math.abs(b.x) > COURT.HALF_W || Math.abs(p.x) > COURT.HALF_W; // playing the ball from outside the court
    const kind = outside ? 'forehand' : this.classify(p, sw);
    const os = p.team === 0 ? 1 : -1;

    // contact quality: sweet spot ~0.85 m from the body, comfortable height, not rushed, ball in front
    const qd = 1 - Math.abs(d - 0.95) / 1.7;
    const overhead = b.y > 2.1;
    const qh = overhead ? 1 - Math.min(0.5, Math.abs(b.y - 2.5) * 0.4) : 1 - Math.min(0.5, Math.max(0, Math.abs(b.y - 1.0) - 0.4) * 0.35);
    const fwdDist = dz * os; // >0 ball in front of the body
    let q = qd * 0.7 + qh * 0.3;
    if (fwdDist < -0.25) q -= 0.25;
    if (Math.hypot(p.vx, p.vz) > 6.2) q -= 0.08; // off balance at full sprint
    if ((p.vx * -dx + p.vz * -dz) / (d || 1) < -2.5) q -= 0.1; // running away from the ball
    q = clamp(q * 0.8 + 0.2, 0.3, 1); // forgiving: contact is never worse than "late"
    const tiredK = clamp((PLAYER.TIRED_FROM - p.stamina) / PLAYER.TIRED_FROM, 0, 1);
    q = clamp(q - 0.25 * tiredK, 0.3, 1); // exhausted players mistime and mishit
    // Pressure: a ball that was hard to reach (stretched to the limit, hit with pace, on the run) cannot be answered with a great shot.
    // This is what makes a good volley or a well-placed ball actually win the exchange. Same rule for bots, humans and online.
    const inSpeed0 = Math.hypot(b.vx, b.vy, b.vz);
    const stretch = clamp((d + 0.8 * (p.swing.lunged || 0) - 1.25) / 0.55, 0, 1); // reach plus the last-gasp lunge toward the ball
    const rush = clamp((inSpeed0 - 14) / 14, 0, 1);
    const onRun = clamp((Math.hypot(p.vx, p.vz) - 4) / 3, 0, 1);
    const pressure = 0.3 * stretch + 0.22 * rush + 0.08 * onRun;
    q = clamp(q - pressure - (sw.slip ? 0.4 : 0), 0.3, 1); // slip: a bot mishit
    if (p.slot === 0 && this.mods) { // development bonus for the matching skill, kept small
      const grp = { forehand: 'ground', backhand: 'ground', volley: 'volley', smash: 'smash', bandeja: 'smash', vibora: 'smash', lob: 'lob', slice: 'defense', block: 'defense', chiquita: 'defense', drop: 'defense' }[kind];
      q = clamp(q + (this.mods.q[grp] || 0), 0.3, 1);
    }

    // racket contact: timing sets the face angle, the distance from the sweet spot stands for the point on the face
    // timing > 0: the ball met the racket late in the swing (swing started early), < 0: early in the swing (started late).
    // Met before the swing peaked = behind the ball, face open (higher, slower, backspin); met after = out in front, face closed.
    const timing = clamp((sw.t - 0.17) / 0.12, -1, 1);
    const face = clamp(-timing * 0.8 + (b.y < 0.5 ? 0.4 : b.y > 1.6 && b.y <= 2.1 ? -0.2 : 0), -1, 1);
    const e = Math.abs(d - 0.95);
    const ctx = { face, e, lateral: Math.abs(p.vx), forward: p.vz * os, spinMul: p.slot === 0 && this.mods ? this.mods.spin : 1, powerMul: (p.slot === 0 && this.mods ? this.mods.power || 1 : 1) * (1 - 0.16 * tiredK), slip: !!sw.slip };

    let label;
    if (q < 0.4) label = 'poor';
    else if (pressure >= 0.28 && q < 0.75) label = 'stretched';
    else if (e > 0.55) label = 'off-centre';
    else if (q >= 0.82) label = 'perfect';
    else if (q >= 0.62) label = 'clean';
    else label = timing < 0 ? 'late' : 'early';

    const inSpeed = Math.hypot(b.vx, b.vy, b.vz);
    const aim = this.aimFor(p);
    if (outside) ctx.outside = true;
    const v = this.planShot(kind, b, os, aim.ax, aim.az, q, inSpeed, null, ctx);
    b.vx = v.vx; b.vy = v.vy; b.vz = v.vz; b.sb = v.sb; b.ss = v.ss;

    r.lastTeam = p.team; r.lastSlot = p.slot; r.bounces = 0; r.hits++; r.netTouched = false; r.serving = false; r.exited = false;
    this.lastKind = kind;
    const st = this.stats.players[p.slot];
    st.hits++;
    if (kind === 'smash') st.smashes++;
    if (kind === 'volley') st.volleys++;
    if (kind === 'bandeja') st.bandejas++;
    if (kind === 'vibora') st.viboras++;
    this.stats.longestRally = Math.max(this.stats.longestRally, r.hits);
    this.events.push({ e: 'hit', slot: p.slot, kind, q: +q.toFixed(2), label, face: +face.toFixed(2), off: +e.toFixed(2), x: b.x, y: b.y, z: b.z, sb: v.sb, ss: v.ss });
    return true;
  }

  // ---------------------------------------------------------------- rules

  inServiceBox(x, z) {
    const r = this.rally;
    const recvTeam = 1 - r.lastTeam;
    const sideOk = recvTeam === 0 ? z < 0 : z > 0;
    const boxSign = -r.serveXSign;
    return sideOk && Math.abs(z) <= COURT.SERVICE_LINE && x * boxSign >= -0.02 && Math.abs(x) <= (this.singles ? 3.5 : 5);
  }

  onBallEvent(e) {
    const r = this.rally;
    const hitterSide = r.lastTeam; // team 0 defends z<0 = side 0
    if (e.type === 'net') {
      this.events.push({ e: 'ball', k: 'net', x: e.x, y: e.y, z: 0, s: e.speed });
      r.netTouched = true;
      if (r.serving) this.fault('net');
      return;
    }
    if (e.type === 'cord') { this.events.push({ e: 'ball', k: 'net', x: e.x, y: e.y, z: 0, s: e.speed * 0.5 }); return; }
    if (e.type === 'wall') {
      this.events.push({ e: 'ball', k: 'wall', axis: e.axis, x: e.x, y: e.y, z: e.z, s: e.speed, mesh: !!e.mesh });
      if (r.bounces === 0) {
        if (r.serving) this.fault('out');
        else this.endPoint(1 - r.lastTeam, 'out');
      }
      return;
    }
    if (e.type === 'door') {
      this.events.push({ e: 'ball', k: 'door', x: e.x, y: e.y, z: e.z, s: 0 });
      if (r.bounces === 0) { // left through the door without bouncing first: out
        if (r.serving) this.fault('out');
        else this.endPoint(1 - r.lastTeam, 'out');
      } else { r.exited = true; r.exitBounce = false; }
      return;
    }
    if (e.type === 'out') {
      if (r.bounces === 0) {
        if (r.serving) this.fault('out');
        else this.endPoint(1 - r.lastTeam, 'out');
      } else {
        this.endPoint(r.lastTeam, 'out-after-bounce', { por: true });
      }
      return;
    }
    if (e.type === 'floor') {
      this.events.push({ e: 'ball', k: 'floor', x: e.x, y: 0, z: e.z, s: e.speed });
      const side = e.z < 0 ? 0 : 1;
      if (r.exited && r.bounces >= 1 && Math.abs(e.x) > COURT.HALF_W && !r.exitBounce) { // outside the court one bounce is allowed before the return
        r.exitBounce = true;
        return;
      }
      if (!r.serving && r.bounces === 0 && Math.abs(e.x) > COURT.HALF_W) { // a return from outside must land inside the court
        this.endPoint(1 - r.lastTeam, 'out');
        return;
      }
      if (r.serving) {
        if (!this.inServiceBox(e.x, e.z)) { this.fault(side === 1 - r.lastTeam ? 'long-or-wide' : 'short'); return; }
        r.serving = false;
        r.bounces = 1;
        return;
      }
      r.bounces++;
      if (r.bounces === 1) {
        if (side === hitterSide) this.endPoint(1 - r.lastTeam, r.netTouched ? 'net' : 'own-side');
      } else {
        this.endPoint(r.lastTeam, 'bounce');
      }
    }
  }

  fault(reason) {
    const r = this.rally;
    r.faults++;
    const srvPlayerSlot = this.serverSlot;
    if (r.faults >= 2) {
      this.stats.players[srvPlayerSlot].doubleFaults++;
      this.endPoint(1 - this.players[srvPlayerSlot].team, 'double-fault');
      return;
    }
    this.events.push({ e: 'fault', reason, n: r.faults, slot: srvPlayerSlot });
    r.serving = true; r.bounces = 0; r.hits = 0; r.netTouched = false; r.lastTeam = this.players[srvPlayerSlot].team;
    this.phase = 'serve';
    this.serveWait = 1.2;
    this.serveIdle = 0;
    for (const [i, p] of this.players.entries()) { // after a fault everybody goes back to their starting place for the second serve
      p.swing = null; p.cd = 0; p.vx = p.vz = 0;
      if (this.startPos) { p.x = this.startPos[i][0]; p.z = this.startPos[i][1]; }
    }
    this.holdBall();
  }

  endPoint(winner, reason, extra) {
    if (this.phase !== 'rally' && this.phase !== 'serve') return;
    const r = this.rally;
    const st = this.stats.players;
    const lastSlot = r.lastSlot;
    const hitterWon = winner === r.lastTeam;
    if (reason === 'bounce' || reason === 'out-after-bounce') {
      if (r.hits === 1) { st[lastSlot].aces++; }
      else st[lastSlot].winners++;
    } else if (reason === 'out' || reason === 'net' || reason === 'own-side') {
      if (!hitterWon) st[lastSlot].errors++;
    }
    this.stats.longestRally = Math.max(this.stats.longestRally, r.hits);
    this.stats.rallies++;
    this.phase = 'point';
    this.pauseT = POINT_PAUSE;
    for (const p of this.players) { p.swing = null; }
    const sc = pointWon(this.match, winner);
    const marks = sc.filter((s) => s.type !== 'point');
    const ev = {
      e: 'point', winner, reason, rally: r.hits, by: lastSlot, por: !!extra?.por && ['smash', 'volley', 'vibora', 'bandeja'].includes(this.lastKind),
      marks, score: scoreView(this.match),
      st: this.stats.players.map((s) => ({ ...s })), lr: this.stats.longestRally,
    };
    this.events.push(ev);
    if (this.match.winner !== null) {
      this.phase = 'ended';
      this.events.push({ e: 'match', winner: this.match.winner, results: this.results() });
    }
  }

  // ---------------------------------------------------------------- views

  results() {
    return {
      winner: this.match.winner,
      score: scoreView(this.match),
      duration: Math.round(this.time),
      longestRally: this.stats.longestRally,
      rallies: this.stats.rallies,
      players: this.stats.players.map((s) => ({ ...s })),
      teamPoints: [...this.match.totalPoints],
    };
  }

  snapshot() {
    const r3 = (v) => Math.round(v * 1000) / 1000;
    const b = this.ball;
    return {
      t: 'snap',
      n: this.tickNo,
      ph: this.phase,
      b: [r3(b.x), r3(b.y), r3(b.z), r3(b.vx), r3(b.vy), r3(b.vz), Math.round(b.sb * 10) / 10, Math.round(b.ss * 10) / 10],
      p: this.players.map((p) => [
        r3(p.x), r3(p.z), r3(p.vx), r3(p.vz), Math.round(p.stamina), p.kind,
        p.swing ? r3(p.swing.t) : -1, r3(p.jumpT), p.ack,
      ]),
      lt: this.rally.lastTeam,
    };
  }

  drainEvents() {
    const e = this.events;
    this.events = [];
    return e;
  }
}

// Match history kept in this browser: every finished match (practice, career, online) is remembered.
// Pure functions plus load/save against any Storage-like object, so they are unit-tested in Node.

export const HISTORY_KEY = 'padel.history';
export const HISTORY_MAX = 100;

/**
 * Build one history entry from a finished match.
 * @param r        the 'results' object of the match (winner, score, duration, longestRally, players, teamPoints)
 * @param o        {slot: my slot, names, mode, court, kind: 'practice'|'career'|'online', at}
 */
export function entryFrom(r, o) {
  const team = (o.slot ?? 0) >> 1;
  const me = r.players?.[o.slot ?? 0] || {};
  const sets = (r.score?.sets || []).map(([a, b]) => [a, b]);
  const mine = (s) => (team === 0 ? s : [s[1], s[0]]);
  const mates = o.mode === 'singles' ? [] : [o.names[team * 2 + ((o.slot ?? 0) & 1 ? -1 : 1)]];
  const opp = o.mode === 'singles' ? [o.names[(1 - team) * 2]] : [o.names[(1 - team) * 2], o.names[(1 - team) * 2 + 1]];
  return {
    at: o.at ?? Date.now(), kind: o.kind || 'practice', mode: o.mode || 'doubles', court: o.court || 'indoor',
    won: r.winner === team, sets: sets.map(mine), mates: mates.filter(Boolean), opponents: opp.filter(Boolean),
    duration: r.duration || 0, longestRally: r.longestRally || 0, rallies: r.rallies || 0,
    points: team === 0 ? r.teamPoints : [r.teamPoints?.[1], r.teamPoints?.[0]],
    stats: { hits: me.hits || 0, winners: me.winners || 0, errors: me.errors || 0, aces: me.aces || 0, smashes: me.smashes || 0, volleys: me.volleys || 0, doubleFaults: me.doubleFaults || 0 },
  };
}

export function addEntry(list, entry, max = HISTORY_MAX) {
  return [entry, ...list].slice(0, max);
}

export function summarize(list) {
  const s = { matches: list.length, wins: 0, losses: 0, winRate: 0, streak: 0, bestStreak: 0, longestRally: 0, aces: 0, winners: 0, errors: 0, minutes: 0, byKind: {} };
  let run = 0;
  for (const e of [...list].reverse()) { // oldest first for streaks
    if (e.won) { run++; s.bestStreak = Math.max(s.bestStreak, run); } else run = 0;
  }
  s.streak = list.length && list[0].won ? list.findIndex((e) => !e.won) < 0 ? list.length : list.findIndex((e) => !e.won) : 0;
  for (const e of list) {
    if (e.won) s.wins++; else s.losses++;
    s.longestRally = Math.max(s.longestRally, e.longestRally || 0);
    s.aces += e.stats?.aces || 0; s.winners += e.stats?.winners || 0; s.errors += e.stats?.errors || 0;
    s.minutes += (e.duration || 0) / 60;
    s.byKind[e.kind] = (s.byKind[e.kind] || 0) + 1;
  }
  s.winRate = s.matches ? Math.round((s.wins / s.matches) * 100) : 0;
  s.minutes = Math.round(s.minutes);
  return s;
}

const valid = (e) => e && typeof e === 'object' && Number.isFinite(e.at) && typeof e.won === 'boolean' && Array.isArray(e.sets);

export function loadHistory(storage) {
  try {
    const raw = JSON.parse(storage.getItem(HISTORY_KEY) || '[]');
    return Array.isArray(raw) ? raw.filter(valid).slice(0, HISTORY_MAX) : [];
  } catch { return []; }
}

export function saveHistory(storage, list) {
  try { storage.setItem(HISTORY_KEY, JSON.stringify(list.slice(0, HISTORY_MAX))); return true; } catch { return false; }
}

/** Clamp anything a client sends into a valid look; never trust the shape of the input. */
export function sanitizeLook(l, slot = 0) {
  const d = DEFAULT_LOOKS[slot & 3];
  if (!l || typeof l !== 'object') return { ...d };

  };
}

import { COURT, PHYS, PLAYER, clamp } from './constants.js';

const { HALF_W, HALF_L, NET_H, WALL_H, BALL_R, DOOR, PIT } = COURT;

/**
 * Player movement. Used by the server (authoritative) and by the client (prediction),
 * so both must stay bit-for-bit the same function.
 * @param p {x,z,vx,vz,stamina,team}
 * @param inp {mx,mz,sprint}  mx/mz are world-space axes in -1..1
 * @param limit optional {zMin,zMax} extra z bounds (used while serving)
 */
export function stepPlayer(p, inp, dt, limit, mul = 1) {
  let mx = inp.mx || 0;
  let mz = inp.mz || 0;
  const len = Math.hypot(mx, mz);
  if (len > 1) { mx /= len; mz /= len; }
  const moving = len > 0.05;
  const sprinting = !!inp.sprint && moving && p.stamina > 4 && mul >= 1;
  const tired = clamp((PLAYER.TIRED_FROM - p.stamina) / PLAYER.TIRED_FROM, 0, 1); // 0 fresh .. 1 exhausted
  const max = (sprinting ? PLAYER.SPRINT : PLAYER.RUN) * mul * (p.speedMul || 1) * (1 - 0.18 * tired); // speedMul: upgrades, local matches only
  const tvx = mx * max;
  const tvz = mz * max;
  const dvx = tvx - p.vx;
  const dvz = tvz - p.vz;
  const dl = Math.hypot(dvx, dvz);
  // reversing direction means braking first (real footwork): it costs a beat, like a split step
  const reversing = moving && p.vx * tvx + p.vz * tvz < 0;
  const maxChange = (moving && !reversing ? PLAYER.ACCEL : PLAYER.DECEL) * dt;
  if (dl <= maxChange || dl === 0) {
    p.vx = tvx; p.vz = tvz;
  } else {
    p.vx += (dvx / dl) * maxChange;
    p.vz += (dvz / dl) * maxChange;
  }
  const prevX = p.x;
  p.x += p.vx * dt;
  p.z += p.vz * dt;
  const drain = p.drainMul || 1;
  if (sprinting) p.stamina -= PLAYER.SPRINT_COST * drain * dt;
  else p.stamina += (p.inRally ? PLAYER.RALLY_REGEN : PLAYER.STAMINA_REGEN) * (p.regenMul || 1) * dt;
  if (p.inRally) p.stamina -= PLAYER.RALLY_DRAIN * drain * dt;
  p.stamina = clamp(p.stamina, 0, PLAYER.STAMINA_MAX);

  const xl = p.xLim || PLAYER.MAX_X;
  // players cannot cross the net
  if (p.team === 0) p.z = clamp(p.z, -HALF_L + PLAYER.BACK_GAP, -PLAYER.NET_GAP);
  else p.z = clamp(p.z, PLAYER.NET_GAP, HALF_L - PLAYER.BACK_GAP);
  if (p.pit) clampWithDoors(p, prevX);
  else p.x = clamp(p.x, -xl, xl);
  if (limit) p.z = clamp(p.z, limit.zMin, limit.zMax);
}

/**
 * Doubles with access doors: a player may walk out through a door in the side wall and move in the fenced strip outside,
 * but only through the door itself. Called on the server and in client prediction (same function).
 */
function clampWithDoors(p, prevX) {
  const az = Math.abs(p.z);
  const door = az >= DOOR.z0 + 0.15 && az <= DOOR.z1 - 0.15;
  const outer = HALF_W + PIT.w - 0.4;
  if (Math.abs(prevX) > HALF_W + 0.05) { // already outside: stay in the strip, or come back in through the door
    const s = Math.sign(p.x) || Math.sign(prevX) || 1;
    p.x = s * clamp(Math.abs(p.x), door ? PLAYER.MAX_X : HALF_W + 0.4, outer);
    p.z = Math.sign(p.z || 1) * clamp(az, PLAYER.NET_GAP, PIT.z1 - 0.3);
  } else {
    const lim = door ? outer : PLAYER.MAX_X;
    p.x = clamp(p.x, -lim, lim);
  }
}

/** Rules: until the serve is hit the server must stay behind the service line; everybody else stands still. */
export function serveLimit(team) {
  const line = COURT.SERVICE_LINE + 0.1;
  return team === 0 ? { zMin: -HALF_L + PLAYER.BACK_GAP, zMax: -line } : { zMin: line, zMax: HALF_L - PLAYER.BACK_GAP };
}

/** Height of the net top at lateral position x: 0.88 m at the centre strap, 0.92 m at the posts (it sags). */
export function netHeight(x) {
  const u = Math.min(1, Math.abs(x) / HALF_W);
  return COURT.NET_H + 0.04 * u * u;
}

/**
 * Wall restitution. Glass (back walls up to 3 m, and the side walls in the back 4 m) is hard and lively; the fence (verja:
 * the side walls through the middle, and the mesh above 3 m) is soft and dead. Faster balls lose a little more.
 */
export function wallE(speed, mesh) {
  const k = 1 - 0.01 * Math.min(speed, 20);
  return (mesh ? PHYS.MESH_E : PHYS.WALL_E) * k;
}

export const SERVE_BOUNCE_PERIOD = 1.1; // seconds per bounce of the ball in the server's hand (slower than before: easier to time)
/** Height of the ball the server bounces by hand at game time t. */
export function serveBallHeight(t) {
  const ph = (t % SERVE_BOUNCE_PERIOD) / SERVE_BOUNCE_PERIOD;
  return 0.1 + 0.86 * Math.abs(Math.cos(Math.PI * ph));
}

/**
 * Spin meets glass: topspin climbs the wall (the ball comes off it higher and faster), backspin drops it dead. The wall also
 * strips part of the spin. The fence barely grips.
 */
function wallSpin(b, normalSpeed, mesh) {
  const s = b.sb || 0;
  if (!s) return;
  const k = Math.min(1, normalSpeed / 12) * (mesh ? 0.15 : 1);
  b.vy += -s * PHYS.WALL_KICK * k;
  b.sb = s * (mesh ? 0.9 : 0.55);
}

export function makeBall() {
  return { x: 0, y: 1, z: 0, vx: 0, vy: 0, vz: 0, sb: 0, ss: 0 };
}

/**
 * Advance the ball one step. Returns a list of physical events:
 *  {type:'floor', x,z, speed} {type:'wall', axis:'x'|'z', x,y,z} {type:'net', x,y} {type:'out', x,y,z}
 */
export function stepBall(b, dt, events) {
  // Magnus effect: backspin (sb>0) lifts the ball, topspin (sb<0) dives; sidespin (ss) curves it left/right of travel.
  const hw = b.hw || HALF_W; // half width of the walls (narrower in 1v1)
  const sb = b.sb || 0, ss = b.ss || 0;
  const sh = Math.hypot(b.vx, b.vz);
  const hx0 = sh > 0.5 ? b.vx / sh : 0;
  const hz0 = sh > 0.5 ? b.vz / sh : 0;
  if (sh > 0.5 && (sb || ss)) {
    b.vy += PHYS.MAGNUS * sb * sh * dt;
    const lat = PHYS.MAGNUS * ss * sh * dt;
    b.vx += hz0 * lat; b.vz -= hx0 * lat;
    const d = Math.exp(-0.35 * dt);
    b.sb = sb * d; b.ss = ss * d;
  }
  const speed3 = Math.hypot(b.vx, b.vy, b.vz);
  const drag = 1 - (PHYS.DRAG * 0.6 + PHYS.DRAG2 * speed3) * dt; // linear plus a quadratic part: fast balls slow down more
  b.vx *= drag; b.vy *= drag; b.vz *= drag;
  b.vy -= PHYS.G * dt;
  const px = b.x, py = b.y, pz = b.z;
  let nx = px + b.vx * dt;
  let ny = py + b.vy * dt;
  let nz = pz + b.vz * dt;

  // net plane (z = 0)
  if ((pz < 0) !== (nz < 0) && pz !== nz) {
    const f = Math.abs(pz) / Math.abs(nz - pz);
    const cy = py + (ny - py) * f;
    const cx = px + (nx - px) * f;
    const top = netHeight(cx);
    if (cy - BALL_R < top && cy - BALL_R > top - 0.045 && b.vy < 3 && Math.abs(cx) <= hw && !b.cord) {
      // clips the tape: the ball loses pace, pops up and may still drop over
      events.push({ type: 'cord', x: cx, y: cy, speed: Math.hypot(b.vx, b.vz) });
      b.vz *= 0.5; b.vx *= 0.8; b.vy = Math.abs(b.vy) * 0.3 + 1.6; b.cord = true;
    } else if (cy - BALL_R < top && Math.abs(cx) <= hw) {
      events.push({ type: 'net', x: cx, y: cy, speed: Math.hypot(b.vx, b.vz) });
      nz = pz < 0 ? -0.02 : 0.02;
      b.vz = -b.vz * 0.22;
      b.vx *= 0.6;
      b.vy *= 0.5;
      nx = px; ny = cy;
    }
  }

  if (b.ex) {
    // the ball is in the strip outside a door
    const s = Math.sign(px) || 1;
    const ax = Math.abs(nx), az = Math.abs(nz);
    const xo = HALF_W + PIT.w;
    if (ax > xo - BALL_R) {
      if (ny > WALL_H) events.push({ type: 'out', x: nx, y: ny, z: nz });
      else { nx = s * (xo - BALL_R); events.push({ type: 'wall', axis: 'x', x: nx, y: ny, z: nz, speed: Math.abs(b.vx) }); b.vx = -b.vx * PHYS.WALL_E; b.vz *= PHYS.WALL_FRIC; }
    }
    if (az > PIT.z1 - BALL_R) {
      if (ny <= WALL_H) {
        const sz = Math.sign(nz) || 1;
        nz = sz * (PIT.z1 - BALL_R);
        events.push({ type: 'wall', axis: 'z', x: nx, y: ny, z: nz, speed: Math.abs(b.vz) });
        b.vz = -b.vz * PHYS.WALL_E; b.vx *= PHYS.WALL_FRIC;
      }
    }
    if (Math.abs(nx) < HALF_W + BALL_R && Math.abs(px) >= HALF_W) {
      const inDoor = Math.abs(nz) > DOOR.z0 && Math.abs(nz) < DOOR.z1 && ny < DOOR.h;
      if (!inDoor && ny <= WALL_H && Math.abs(b.vx) > 0 && Math.sign(b.vx) !== s) { // glass seen from outside
        nx = s * (HALF_W + BALL_R);
        events.push({ type: 'wall', axis: 'x', x: nx, y: ny, z: nz, speed: Math.abs(b.vx) });
        b.vx = -b.vx * PHYS.WALL_E; b.vz *= PHYS.WALL_FRIC;
      }
    }
    if (Math.abs(nx) < HALF_W - 0.3) b.ex = false;
  } else if (b.doors && Math.abs(nx) > hw - BALL_R && Math.abs(nz) > DOOR.z0 && Math.abs(nz) < DOOR.z1 && ny < DOOR.h) {
    // through the open door
    if (Math.abs(nx) > hw + 0.05) { b.ex = true; events.push({ type: 'door', x: nx, y: ny, z: nz }); }
  } else if (Math.abs(nx) > hw - BALL_R) {
    if (ny > WALL_H) {
      events.push({ type: 'out', x: nx, y: ny, z: nz });
    } else {
      const s = Math.sign(nx);
      nx = s * (hw - BALL_R);
      const mesh = ny > 3 || (hw >= HALF_W && Math.abs(nz) < 6); // 1v1 has glass all along; in doubles the middle of the side wall is fence
      events.push({ type: 'wall', axis: 'x', x: nx, y: ny, z: nz, speed: Math.abs(b.vx), mesh });
      b.vx = -b.vx * wallE(Math.abs(b.vx), mesh);
      b.vz += -hx0 * (b.ss || 0) * PHYS.WALL_SPIN * (mesh ? 0.3 : 1); // sidespin kicks the ball along the glass, much less off the fence
      b.vz *= mesh ? PHYS.MESH_FRIC : PHYS.WALL_FRIC;
      b.vy *= mesh ? PHYS.MESH_FRIC : PHYS.WALL_FRIC;
      wallSpin(b, Math.abs(b.vx), mesh);
    }
  }
  // back walls
  if (Math.abs(nz) > HALF_L - BALL_R) {
    if (ny > WALL_H) {
      events.push({ type: 'out', x: nx, y: ny, z: nz });
    } else {
      const s = Math.sign(nz);
      nz = s * (HALF_L - BALL_R);
      const mesh = ny > 3; // glass to 3 m, fence above
      events.push({ type: 'wall', axis: 'z', x: nx, y: ny, z: nz, speed: Math.abs(b.vz), mesh });
      b.vz = -b.vz * wallE(Math.abs(b.vz), mesh);
      b.vx += hz0 * (b.ss || 0) * PHYS.WALL_SPIN * (mesh ? 0.3 : 1);
      b.vx *= mesh ? PHYS.MESH_FRIC : PHYS.WALL_FRIC;
      b.vy *= mesh ? PHYS.MESH_FRIC : PHYS.WALL_FRIC;
      wallSpin(b, Math.abs(b.vz), mesh);
    }
  }

  // floor
  if (ny < BALL_R && b.vy < 0 && -b.vy < 0.9) {
    // resting on the floor: it rolls and slows gently (it used to be hit by the bounce friction every tick and stop dead)
    ny = BALL_R; b.vy = 0;
    const roll = Math.max(0, 1 - 0.9 * dt);
    b.vx *= roll; b.vz *= roll;
    b.sb = (b.sb || 0) * 0.9; b.ss = (b.ss || 0) * 0.9;
  } else if (ny < BALL_R && b.vy < 0) {
    ny = BALL_R;
    events.push({ type: 'floor', x: nx, z: nz, speed: Math.abs(b.vy) });
    // backspin (sb>0) bites: lower bounce, ball slows. Topspin (sb<0) kicks up and forward.
    const s = b.sb || 0;
    b.vy = -b.vy * clamp((b.fe ?? PHYS.FLOOR_E) * (1 - 0.014 * s) * (1 - 0.004 * Math.min(Math.abs(b.vy), 12)), 0.35, 0.95);
    if (b.vy < 0.5) b.vy = 0;
    const hf = clamp((b.ff ?? PHYS.FLOOR_FRIC) * (1 - 0.016 * s), 0.5, 1.02);
    b.vx *= hf; b.vz *= hf;
    b.sb = s * 0.5; b.ss = (b.ss || 0) * 0.75;
  }

  if (b.cord && Math.abs(nz) > 0.3) b.cord = false;
  b.x = nx; b.y = ny; b.z = nz;
}

/** Ballistic launch: velocity that takes the ball from (x,y,z) to the floor point (tx,tz) in T seconds. */
export function solveLaunch(b, tx, tz, T) {
  return {
    vx: (tx - b.x) / T,
    vz: (tz - b.z) / T,
    vy: (BALL_R - b.y + 0.5 * PHYS.G * T * T) / T,
  };
}

/** Height of the ball above the floor when it crosses the net plane for a given launch (or null). */
export function heightAtNet(b, v) {
  if (v.vz === 0) return null;
  const t = -b.z / v.vz;
  if (t <= 0) return null;
  return b.y + v.vy * t - 0.5 * PHYS.G * t * t;
}

/** Copy the ball and simulate ahead; returns samples [{t,x,y,z,vy}] */
export function predictBall(ball, seconds, step = 1 / 60) {
  const b = { ...ball };
  const out = [];
  const ev = [];
  for (let t = step; t <= seconds; t += step) {
    ev.length = 0;
    stepBall(b, step, ev);
    out.push({ t, x: b.x, y: b.y, z: b.z, vy: b.vy, floor: ev.some((e) => e.type === 'floor') });
  }
  return out;
}

/**
 * Fly a launched ball through the real physics (spin, drag, ...) until it first touches something.
 * Returns {kind:'floor'|'wall'|'net'|'out'|'none', x, z, t, netH} where netH is the ball height when it crosses the net plane.
 */
export function simulateShot(ball, v, spin, maxT = 4) {
  const b = { ...ball, vx: v.vx, vy: v.vy, vz: v.vz, sb: spin.sb, ss: spin.ss };
  const ev = [];
  const side0 = Math.sign(b.z) || 1;
  let netH = null;
  for (let t = 0; t < maxT; t += PHYS.DT) {
    const pz = b.z;
    ev.length = 0;
    stepBall(b, PHYS.DT, ev);
    if (netH === null && Math.sign(pz) === side0 && Math.sign(b.z) !== side0) netH = b.y;
    const e = ev.find((x) => x.type !== 'door' && x.type !== 'cord');
    if (e) return { kind: e.type, x: b.x, z: b.z, t, netH: e.type === 'net' ? e.y : netH };
  }
  return { kind: 'none', x: b.x, z: b.z, t: maxT, netH };
}

// Explicit padel scoring state machine. Teams are 0 and 1.
// Pure data in / data out so it can be tested exhaustively.

export function createMatch(cfg = {}) {
  const c = { sets: 3, gamesPerSet: 6, goldenPoint: false, singles: false, ...cfg };
  return {
    cfg: c,
    sets: [], // completed sets: [gamesTeam0, gamesTeam1]
    setsWon: [0, 0],
    games: [0, 0],
    points: [0, 0],
    tiebreak: false,
    tbOrder: null,
    tbFirstTeam: null,
    pointsInGame: 0, // points played in current game / tiebreak (drives serve side)
    servingTeam: 0,
    serverIdx: [0, 0], // which of the team's two players serves
    served: [true, false],
    totalPoints: [0, 0],
    winner: null,
  };
}

const other = (t) => 1 - t;

// Who serves the next point.
export function currentServer(m) {
  if (m.tiebreak) {
    const e = m.tbOrder[Math.floor((m.pointsInGame + 1) / 2) % 4];
    return { team: e.team, idx: m.cfg.singles ? 0 : e.idx };
  }
  return { team: m.servingTeam, idx: m.cfg.singles ? 0 : m.serverIdx[m.servingTeam] };
}

// 0 = serve from the "deuce" (right-hand) side, 1 = advantage side.
export function serveSide(m) {
  return m.pointsInGame % 2;
}

function advanceServer(m, fromTeam) {
  const next = other(fromTeam);
  if (m.served[next]) m.serverIdx[next] ^= 1;
  m.served[next] = true;
  m.servingTeam = next;
}

function startTiebreak(m) {
  m.tiebreak = true;
  m.points = [0, 0];
  m.pointsInGame = 0;
  const x = m.servingTeam;
  const y = other(x);
  const xi = m.serverIdx[x];
  const yi = m.served[y] ? m.serverIdx[y] ^ 1 : 0;
  m.tbFirstTeam = x;
  m.tbOrder = [
    { team: x, idx: xi },
    { team: y, idx: yi },
    { team: x, idx: xi ^ 1 },
    { team: y, idx: yi ^ 1 },
  ];
}

function gameWon(m, team, out) {
  m.games[team]++;
  m.points = [0, 0];
  m.pointsInGame = 0;
  out.push({ type: 'game', team });
  const g = m.cfg.gamesPerSet;
  const a = m.games[team];
  const b = m.games[other(team)];
  if ((a >= g && a - b >= 2) || (m.tiebreak && a > b)) {
    setWon(m, team, out);
  } else if (a === g && b === g) {
    startTiebreak(m);
    out.push({ type: 'tiebreak' });
  } else {
    advanceServer(m, m.servingTeam);
  }
}

function setWon(m, team, out) {
  m.sets.push([m.games[0], m.games[1]]);
  m.setsWon[team]++;
  out.push({ type: 'set', team });
  const need = Math.floor(m.cfg.sets / 2) + 1;
  const wasTiebreak = m.tiebreak;
  m.games = [0, 0];
  m.points = [0, 0];
  m.pointsInGame = 0;
  m.tiebreak = false;
  if (m.setsWon[team] >= need) {
    m.winner = team;
    out.push({ type: 'match', team });
    return;
  }
  // the team that received first in a tiebreak serves first in the next set
  advanceServer(m, wasTiebreak ? m.tbFirstTeam : m.servingTeam);
  m.tbOrder = null;
}

export function pointWon(m, team) {
  if (m.winner !== null) return [];
  const out = [{ type: 'point', team }];
  m.totalPoints[team]++;
  m.points[team]++;
  m.pointsInGame++;
  const p = m.points[team];
  const q = m.points[other(team)];
  if (m.tiebreak) {
    if (p >= 7 && p - q >= 2) gameWon(m, team, out);
  } else if (m.cfg.goldenPoint ? p >= 4 : p >= 4 && p - q >= 2) {
    gameWon(m, team, out); // golden point: the point after 40-40 decides the game
  }
  return out;
}

const LABELS = ['0', '15', '30', '40'];

export function displayPoints(m) {
  const [a, b] = m.points;
  if (m.tiebreak) return [String(a), String(b)];
  if (a >= 3 && b >= 3) {
    if (a === b) return ['40', '40'];
    return a > b ? ['AD', '40'] : ['40', 'AD'];
  }
  return [LABELS[Math.min(a, 3)], LABELS[Math.min(b, 3)]];
}

export function pointLabel(m) {
  const [a, b] = m.points;
  if (!m.tiebreak && a >= 3 && b >= 3 && a === b) return m.cfg.goldenPoint ? 'Golden point' : 'Deuce';
  return '';
}

// Public, serialisable view sent to clients.
export function scoreView(m) {
  const need = Math.floor(m.cfg.sets / 2) + 1;
  const g = m.cfg.gamesPerSet;
  let gamePoint = null;
  let setPoint = false;
  let matchPoint = false;
  if (m.winner === null) {
    for (const t of [0, 1]) {
      const copy = JSON.parse(JSON.stringify(m));
      const evs = pointWon(copy, t);
      if (evs.some((e) => e.type === 'game')) {

  }

    sets: m.sets,

    games: m.games,
    points: displayPoints(m),
    label: pointLabel(m),
    tiebreak: m.tiebreak,
    server: srv,
    serveSide: serveSide(m),
    gamePoint,
    setPoint,
    matchPoint,
    totalPoints: m.totalPoints,
    winner: m.winner,
    need,
    gamesPerSet: g,
  };
}

// HTTP static server + WebSocket game server.

import { QuickQueue } from './quick.js';
import http from 'node:http';
import zlib from 'node:zlib';
import fs from 'node:fs';
import path from 'node:path';
import { fileURLToPath } from 'node:url';
import { WebSocketServer } from 'ws';
import { Store } from './store.js';
import { RoomManager } from './rooms.js';
import { SERVER_TICK } from '../shared/constants.js';
import { CAREER } from '../shared/career.js';
import { sanitizeLook } from '../shared/looks.js';

const ROOT = path.resolve(path.dirname(fileURLToPath(import.meta.url)), '..');
const MIME = {
  '.html': 'text/html; charset=utf-8', '.js': 'text/javascript; charset=utf-8', '.css': 'text/css; charset=utf-8',
  '.json': 'application/json', '.svg': 'image/svg+xml', '.png': 'image/png', '.ico': 'image/x-icon', '.map': 'application/json',
};
const STATIC = [
  ['/vendor/three/', path.join(ROOT, 'node_modules', 'three')],
  ['/shared/', path.join(ROOT, 'shared')],
  ['/', path.join(ROOT, 'client')],
];

function serveStatic(req, res) {
  let pathname;
  try {
    // never trust the request target: a path like "//" must not be parsed as a URL authority
    pathname = decodeURIComponent(req.url.split('?')[0].replace(/^\/+/, '/'));
  } catch {
    res.writeHead(400); res.end('Bad request'); return;
  }
  if (pathname === '/health') {
    res.writeHead(200, { 'content-type': 'application/json' });
    res.end('{"ok":true}');
    return;
  }
  if (pathname.endsWith('/')) pathname += 'index.html';
  for (const [prefix, dir] of STATIC) {
    if (!pathname.startsWith(prefix)) continue;
    const file = path.resolve(dir, pathname.slice(prefix.length));
    if (!file.startsWith(dir + path.sep) && file !== dir) break; // path traversal guard
    try {
      const st = fs.statSync(file);
      if (!st.isFile()) continue;
      const type = MIME[path.extname(file)] || 'application/octet-stream';
      const gz = (req.headers['accept-encoding'] || '').includes('gzip') && (type.startsWith('text/') || type.startsWith('application/json') || type.startsWith('application/javascript'));
      // vendored libraries never change between deploys: let browsers cache them
      const cache = prefix === '/vendor/three/' ? 'public, max-age=86400' : 'no-cache';
      res.writeHead(200, { 'content-type': type, 'cache-control': cache, ...(gz ? { 'content-encoding': 'gzip', vary: 'accept-encoding' } : {}) });
      const stream = fs.createReadStream(file);
      stream.on('error', () => res.destroy());
      if (gz) stream.pipe(zlib.createGzip({ level: 6 })).pipe(res); else stream.pipe(res);
      return;
    } catch { /* try next mapping */ }
  }
  res.writeHead(404, { 'content-type': 'text/plain' });
  res.end('Not found');
}

export function createGameServer({ port = 0, dataDir = process.env.DATA_DIR || path.join(ROOT, 'data'), host } = {}) {
  const store = new Store(dataDir);
  const rooms = new RoomManager(store);
  const quick = new QuickQueue(rooms);
  const onlineCount = () => { let n = 0; for (const ws of wss.clients) if (ws.readyState === 1 && ws.ctx?.token) n++; return n; };
  const server = http.createServer((req, res) => {
    try { serveStatic(req, res); } catch (err) {
      console.error('[http]', err.message);
      if (!res.headersSent) res.writeHead(500);
      res.end();
    }
  });
  const wss = new WebSocketServer({ server, path: '/ws', maxPayload: 16 * 1024 });

  wss.on('connection', (ws) => {
    ws.ctx = { token: null, name: 'Guest', bucket: 200, bucketAt: Date.now() };
    ws.alive = true;
    ws.on('pong', () => { ws.alive = true; });
    ws.on('message', (data) => onMessage(ws, data));
    ws.on('close', () => onClose(ws));
    ws.on('error', () => {});
  });

  const send = (ws, msg) => { if (ws.readyState === 1) ws.send(JSON.stringify(msg)); };
  const fail = (ws, message, code = 'error') => send(ws, { t: 'error', code, message });

  function onClose(ws) {
    const { token } = ws.ctx;
    if (!token) return;
    quick.remove(token);
    const ms = rooms.membership(token);
    if (ms && ms.member.ws === ws) ms.room.disconnect(ms.member);
  }

  function onMessage(ws, data) {
    // rate limit: token bucket, ~300 msgs/s sustained
    const c = ws.ctx;
    const now = Date.now();
    c.bucket = Math.min(300, c.bucket + ((now - c.bucketAt) / 1000) * 300);
    c.bucketAt = now;
    if (--c.bucket < 0) { ws.close(1008, 'rate limit'); return; }

    let msg;
    try { msg = JSON.parse(data.toString()); } catch { return; }
    if (!msg || typeof msg.t !== 'string') return;

    if (msg.t === 'hello') {
      let token = typeof msg.token === 'string' && store.hasProfile(msg.token) ? msg.token : store.newToken();
      const prof = store.profile(token, String(msg.name || '').slice(0, 16) || undefined);
      c.token = token;
      c.name = prof.name;
      c.look = msg.look ? sanitizeLook(msg.look) : null;
      send(ws, { t: 'welcome', token, name: prof.name, profile: store.publicProfile(token), online: onlineCount() });
      const ms = rooms.membership(token);
      if (ms) {
        // reconnect: rebind the new socket to the old seat
        if (ms.member.ws && ms.member.ws !== ws) { const old = ms.member.ws; ms.member.ws = null; old.close(4000, 'replaced'); }
        ms.member.name = prof.name;
        ms.room.reconnect(ms.member, ws);
      }
      return;
    }
    if (!c.token) return fail(ws, 'Say hello first', 'no-session');

    if (msg.t === 'ping') {
      send(ws, { t: 'pong', ts: msg.ts });
      const ms = rooms.membership(c.token);
      if (ms && Number.isFinite(msg.rtt)) ms.member.rtt = Math.min(2000, Math.max(0, Math.round(msg.rtt)));
      return;
    }
    if (msg.t === 'profile') return send(ws, { t: 'profile', profile: store.publicProfile(c.token) });
    if (msg.t === 'rename') {
      const p = store.profile(c.token, String(msg.name || '').slice(0, 16));
      c.name = p.name;
      return send(ws, { t: 'profile', profile: store.publicProfile(c.token) });
    }

    if (msg.t === 'look') {
      c.look = sanitizeLook(msg.look);
      const lm = rooms.membership(c.token);
      if (lm) { lm.member.look = c.look; lm.room.broadcastRoom(); }
      return;
    }
    if (msg.t === 'quick') {
      quick.add({ token: c.token, name: msg.name || c.name, ws, look: c.look });
      return send(ws, { t: 'queue', ...quick.status(c.token), online: onlineCount() });
    }
    if (msg.t === 'quickCancel') { quick.remove(c.token); return send(ws, { t: 'queue', cancelled: true, online: onlineCount() }); }
    if (msg.t === 'rooms') return send(ws, { t: 'rooms', rooms: rooms.listPublic() });
    if (msg.t === 'career') return send(ws, { t: 'career', career: store.careerView(c.token) });
    if (msg.t === 'careerStart') {
      const stage = CAREER.find((s) => s.id === Number(msg.stage));
      const view = store.careerView(c.token);
      if (!stage || !view.stages.find((s) => s.id === stage.id)?.unlocked) return fail(ws, 'That stage is locked', 'rejected');
      if (rooms.membership(c.token)) rooms.leave(c.token);
      const { room, member } = rooms.create({ token: c.token, name: msg.name || c.name, ws, look: c.look });
      member.name = String(msg.name || c.name).slice(0, 16) || 'Guest';
      room.setupCareer(stage, member);
      return;
    }

    if (msg.t === 'create') {
      if (rooms.membership(c.token)) rooms.leave(c.token);
      const { room, member } = rooms.create({ token: c.token, name: msg.name || c.name, ws, look: c.look });
      member.name = String(msg.name || c.name).slice(0, 16) || 'Guest';
      room.broadcastRoom();
      return;
    }
    if (msg.t === 'join') {
      const cur = rooms.membership(c.token);
      if (cur && cur.room.code === String(msg.code || '').toUpperCase().trim()) { cur.room.reconnect(cur.member, ws); return; }
      if (cur) rooms.leave(c.token);
      const r = rooms.join(msg.code, { token: c.token, name: msg.name || c.name, ws, look: c.look });
      if (r.error) return fail(ws, r.error, 'join-failed');
      r.room.broadcastRoom();
      return;
    }

    const ms = rooms.membership(c.token);
    if (!ms) return fail(ws, 'You are not in a room', 'no-room');
    const { room, member } = ms;
    let err = null;
    switch (msg.t) {
      case 'leave': rooms.leave(c.token); send(ws, { t: 'left' }); return;
      case 'in': room.pushInputs(member, msg.inputs); return;
      case 'sit': err = room.sit(member, msg.slot); break;
      case 'assign': err = room.assign(member, msg.id, msg.slot); break;
      case 'ready':
        if (room.state === 'lobby') member.ready = !!msg.ready;
        break;
      case 'settings': err = room.setSettings(member, msg.settings || {}); break;
      case 'start': err = room.start(member); break;
      case 'rematch': err = room.rematch(member); return err ? fail(ws, err) : undefined;
      case 'lobby': err = room.toLobby(member); break;
      case 'pauseReq': case 'pauseAccept': case 'pauseDeny': case 'pauseResume':
        err = room.pauseCtl(member, msg.t.slice(5).toLowerCase()); if (err) return fail(ws, err, 'pause'); return;
      case 'chat': room.chat(member, msg.text); return;
      case 'emote': room.emote(member, msg.id); return;
      default: return; // unknown messages (including any attempt to submit scores) are ignored
    }
    if (err) fail(ws, err, 'rejected');
    room.broadcastRoom();
  }

  // fixed-step simulation loop shared by all rooms
  const STEP = 1 / SERVER_TICK;
  let last = performance.now();
  let acc = 0;
  const loop = setInterval(() => {
    const now = performance.now();
    acc += Math.min(0.25, (now - last) / 1000);
    last = now;
    while (acc >= STEP) { rooms.step(STEP); acc -= STEP; }
  }, 8);
  const sweeper = setInterval(() => rooms.sweep(), 30_000);
  // matchmaking and the live player count
  const matchmaker = setInterval(() => {
    quick.tick();
    const online = onlineCount();
    for (const ws of wss.clients) {
      if (ws.readyState !== 1 || !ws.ctx?.token) continue;
      const st = quick.status(ws.ctx.token);
      send(ws, st ? { t: 'queue', ...st, online } : { t: 'online', n: online });
    }
  }, 1000);
  const heartbeat = setInterval(() => {
    for (const ws of wss.clients) {
      if (!ws.alive) { ws.terminate(); continue; }
      ws.alive = false;
      ws.ping();
    }
  }, 15_000);

  return new Promise((resolve) => {
    server.listen(port, host, () => {
      const actual = server.address().port;
      resolve({
        port: actual, rooms, store, server, wss,
        async close() {
          clearInterval(loop); clearInterval(sweeper); clearInterval(matchmaker); clearInterval(heartbeat);
          for (const ws of wss.clients) ws.terminate();
          store.flush();
          await new Promise((r) => wss.close(() => server.close(() => r())));
        },
      });
    });
  });
}

if (process.argv[1] && path.resolve(process.argv[1]) === fileURLToPath(import.meta.url)) {
  const port = Number(process.env.PORT) || 3000;

  console.log(`PADEL CLUB server listening on http://localhost:${s.port}`);

  process.on('uncaughtException', (err) => console.error('[uncaught]', err));
  process.on('unhandledRejection', (err) => console.error('[unhandled]', err));
  const stop = () => { s.close().then(() => process.exit(0)); };
  process.on('SIGINT', stop);
  process.on('SIGTERM', stop);
}

// Quick match: players queue up and are put in a doubles match as soon as four are waiting. Nobody waits long: after
// WAIT_MS the people in the queue play together with bots filling the empty seats.

export const WAIT_MS = 10_000;

export class QuickQueue {
  /** @param rooms RoomManager  @param now () => ms (injectable for tests) */
  constructor(rooms, now = Date.now) {
    this.rooms = rooms;
    this.now = now;
    this.list = []; // {token, name, ws, look, at}
  }

  has(token) { return this.list.some((e) => e.token === token); }
  size() { return this.list.length; }

  add(client) {
    if (this.has(client.token)) return this.list.findIndex((e) => e.token === client.token) + 1;
    this.rooms.leave(client.token); // a quick match replaces whatever lobby you were in
    this.list.push({ ...client, at: this.now() });
    return this.list.length;
  }

  remove(token) {
    const n = this.list.length;
    this.list = this.list.filter((e) => e.token !== token);
    return this.list.length !== n;
  }

  /** Seconds the player has waited and seconds until bots fill the match. */
  status(token) {
    const e = this.list.find((x) => x.token === token);
    if (!e) return null;
    const waited = (this.now() - e.at) / 1000;
    return { waited: Math.floor(waited), botsIn: Math.max(0, Math.ceil(WAIT_MS / 1000 - waited)), waiting: this.list.length };
  }

  /** Form matches. Returns the rooms created. */
  tick() {
    this.list = this.list.filter((e) => e.ws && e.ws.readyState === 1);
    const made = [];
    while (this.list.length >= 4) made.push(this.make(this.list.splice(0, 4)));
    if (this.list.length && this.now() - this.list[0].at >= WAIT_MS) made.push(this.make(this.list.splice(0, this.list.length)));
    return made;
  }

  make(players) {
    const [first, ...rest] = players;
    const { room } = this.rooms.create(first);
    room.settings = { ...room.settings, mode: 'doubles', fillBots: true, public: false, difficulty: 'normal' };
    for (const p of rest) {
      const m = room.addMember(p);
      this.rooms.byToken.set(p.token, { room, id: m.id });
    }
    room.beginMatch();
    return room;
  }
}

    this.pausesUsed = new Map(); // member id -> pauses used this match
  }

  // ------------------------------------------------------------ membership

  humanCount() {
    return [...this.members.values()].length;
  }

  addMember({ token, name, ws, look }) {
    const id = crypto.randomBytes(3).toString('hex');
    const m = { id, token, name: cleanName(name), ws, connected: true, ready: false, rtt: 0, dropTimer: null, look: look ? sanitizeLook(look) : null };
    this.members.set(id, m);
    if (!this.hostId) this.hostId = id;
    // take the first free slot, otherwise replace a bot
    const act = this.activeSlots();
    let slot = act.find((i) => this.slots[i] === null);
    if (slot === undefined) slot = act.find((i) => this.slots[i]?.kind === 'bot');
    this.slots[slot] = { kind: 'human', id };
    this.emptySince = null;
    return m;
  }

  activeSlots(mode = this.settings.mode) { return mode === 'singles' ? [0, 2] : [0, 1, 2, 3]; }

  slotOf(id) {
    return this.slots.findIndex((s) => s?.kind === 'human' && s.id === id);
  }

  canJoin() {
    if (this.state !== 'lobby') return 'Match already in progress';
    const free = this.activeSlots().some((i) => this.slots[i] === null || this.slots[i].kind === 'bot');
    if (!free) return 'Room is full';
    return null;
  }

  removeMember(id) {
    const m = this.members.get(id);
    if (!m) return;
    clearTimeout(m.dropTimer);
    this.members.delete(id);
    const slot = this.slotOf(id);
    if (slot >= 0) this.slots[slot] = this.state === 'match' ? { kind: 'bot' } : null;
    if (this.hostId === id) {
      const next = [...this.members.values()].find((x) => x.connected) || [...this.members.values()][0];
      this.hostId = next ? next.id : null;
    }
    if (this.members.size === 0) this.emptySince = Date.now();
    this.broadcastRoom();
  }

  disconnect(member) {
    member.connected = false;
    member.ws = null;
    member.ready = this.state === 'lobby' ? false : member.ready;
    if (this.hostId === member.id) {
      const next = [...this.members.values()].find((x) => x.connected);
      if (next) this.hostId = next.id;
    }
    // In a match a bot covers the slot immediately (see step()); in the lobby the seat is held briefly.
    if (this.state !== 'match') {
      member.dropTimer = setTimeout(() => this.removeMember(member.id), LOBBY_GRACE_MS);
      member.dropTimer.unref?.();
    }
    if (![...this.members.values()].some((x) => x.connected)) this.emptySince = Date.now();
    this.broadcastRoom();
  }

  reconnect(member, ws) {
    clearTimeout(member.dropTimer);
    member.ws = ws;
    member.connected = true;
    this.emptySince = null;
    this.queues[this.slotOf(member.id)] = [];
    this.broadcastRoom();
    if (this.state === 'match' && this.game) { this.sendStart(member); if (this.pause) this.send(member, this.pauseView()); }
    if (this.state === 'results' && this.lastResultsMsg) this.send(member, this.lastResultsMsg);
  }

  // ------------------------------------------------------------ messaging

  send(member, msg) {
    if (member.ws && member.ws.readyState === 1) member.ws.send(typeof msg === 'string' ? msg : JSON.stringify(msg));
  }

  broadcast(msg) {
    const s = typeof msg === 'string' ? msg : JSON.stringify(msg);
    for (const m of this.members.values()) this.send(m, s);
  }

  roomView() {
    return {
      t: 'room',
      code: this.code,
      hostId: this.hostId,
      state: this.state,
      settings: this.settings,
      slots: this.slots.map((s) => {
        if (!s) return null;
        if (s.kind === 'bot') return { kind: 'bot', name: s.name || 'AI' };
        const m = this.members.get(s.id);
        return { kind: 'human', id: m.id, name: m.name, ready: m.ready || m.id === this.hostId, connected: m.connected, rtt: m.rtt, look: m.look };
      }),
    };
  }

  broadcastRoom() {
    const v = this.roomView();
    for (const m of this.members.values()) this.send(m, { ...v, you: m.id, youSlot: this.slotOf(m.id) });
  }

  // ------------------------------------------------------------ lobby actions

  isHost(m) { return m.id === this.hostId; }

  sit(m, slot) {
    if (this.state !== 'lobby') return 'Teams are locked during a match';
    if (!this.activeSlots().includes(slot)) return 'Bad slot';
    const cur = this.slotOf(m.id);
    if (cur === slot) return null;
    const target = this.slots[slot];
    if (target?.kind === 'human') return 'That seat is taken';
    this.slots[cur] = null;
    this.slots[slot] = { kind: 'human', id: m.id };
    m.ready = false;
    return null;
  }

  assign(host, id, slot) {
    if (!this.isHost(host)) return 'Only the host can move players';
    if (this.state !== 'lobby') return 'Teams are locked during a match';
    const m = this.members.get(id);
    if (!m || !this.activeSlots().includes(slot)) return 'Bad request';
    const cur = this.slotOf(id);
    const target = this.slots[slot];
    this.slots[cur] = target?.kind === 'human' ? target : null; // swap with whoever sits there
    this.slots[slot] = { kind: 'human', id };
    for (const x of this.members.values()) x.ready = false;
    return null;
  }

  setSettings(host, s) {
    if (!this.isHost(host)) return 'Only the host can change settings';
    if (this.state !== 'lobby') return 'Settings are locked during a match';
    const n = { ...this.settings };
    if ([1, 3, 5].includes(s.sets)) n.sets = s.sets;
    if ([2, 4, 6].includes(s.gamesPerSet)) n.gamesPerSet = s.gamesPerSet;
    if (typeof s.goldenPoint === 'boolean') n.goldenPoint = s.goldenPoint;
    if (['easy', 'normal', 'hard', 'expert'].includes(s.difficulty)) n.difficulty = s.difficulty;
    if (typeof s.fillBots === 'boolean') n.fillBots = s.fillBots;
    if (typeof s.public === 'boolean') n.public = s.public;
    if (COURT_IDS.includes(s.court)) n.court = s.court;
    if ((s.mode === 'singles' || s.mode === 'doubles') && s.mode !== n.mode) {
      const err = this.applyMode(s.mode);
      if (err) return err;
      n.mode = s.mode;
    }
    this.settings = n;
    return null;
  }

  /** Switching to 1v1 moves everybody into the two singles seats (or refuses if there are too many humans). */
  applyMode(mode) {
    if (mode === 'singles') {
      const humans = [1, 3].map((i) => this.slots[i]).filter((s) => s?.kind === 'human');
      const free = [0, 2].filter((i) => this.slots[i]?.kind !== 'human');
      if (humans.length > free.length) return 'Too many players for 1v1 (max 2)';
      for (const i of [1, 3]) {
        const s = this.slots[i];
        if (s?.kind === 'human') this.slots[free.shift()] = s;
        this.slots[i] = null;
      }
      for (const i of [0, 2]) if (this.slots[i]?.kind === 'bot') this.slots[i] = null;
    }
    for (const m of this.members.values()) m.ready = false;
    return null;
  }

  canStart() {
    if (this.state !== 'lobby') return 'Not in the lobby';
    const act = this.activeSlots();
    const filled = act.filter((i) => this.slots[i]).length;
    if (filled < act.length && !this.settings.fillBots) return 'Need four players (or enable AI fill)';
    const notReady = [...this.members.values()].filter((m) => !this.isHost(m) && !m.ready && m.connected);
    if (notReady.length) return `${notReady.map((m) => m.name).join(', ')} not ready`;
    // team balance: each team needs at least one human or a bot to fill
    return null;
  }

  start(host) {
    if (!this.isHost(host)) return 'Only the host can start';
    const err = this.canStart();
    if (err) return err;
    this.beginMatch();
    return null;
  }

  beginMatch() {
    const act = this.activeSlots();
    for (let i = 0; i < 4; i++) this.slots[i] = act.includes(i) ? this.slots[i] || { kind: 'bot' } : null;
    this.state = 'match';
    this.game = new PadelGame({ settings: this.settings });
    this.queues = [[], [], [], []];
    this.lastInput = [null, null, null, null];
    this.starved = [0, 0, 0, 0];
    this.botMem = [0, 1, 2, 3].map(makeBotMemory);
    this.persisted = false;
    this.pause = null; this.pausesUsed = new Map();
    this.resultAt = 0;
    this.lastResultsMsg = null;
    for (const m of this.members.values()) { m.ready = false; m.rematch = false; }
    this.broadcastRoom();
    for (const m of this.members.values()) this.sendStart(m);
  }

  sendStart(m) {
    const names = this.slots.map((s) => (s?.kind === 'human' ? this.members.get(s.id).name : s?.name || 'AI'));
    this.send(m, {
      t: 'start', slot: this.slotOf(m.id), names, settings: this.settings,
      looks: this.slots.map((s, i) => sanitizeLook(s?.kind === 'human' ? this.members.get(s.id)?.look : s?.look, i)),
      score: scoreView(this.game.match), tickRate: SERVER_TICK,
    });
  }

  rematch(m) {
    if (this.state !== 'results') return 'No finished match';
    m.rematch = true;
    const waiting = [...this.members.values()].filter((x) => x.connected && !x.rematch);
    this.broadcast({ t: 'rematchVotes', ready: [...this.members.values()].filter((x) => x.rematch).map((x) => x.id) });
    if (waiting.length === 0) this.beginMatch();
    return null;
  }

  /** Career: configure the room from a stage (named bots with their own levels) and start at once. */
  setupCareer(stage, member) {
    this.career = stage.id;
    this.settings = {
      ...DEFAULT_SETTINGS, fillBots: true, public: false, mode: stage.mode, difficulty: stage.difficulty, court: stage.court || 'indoor',
      sets: stage.sets, gamesPerSet: stage.gamesPerSet, goldenPoint: !!stage.golden,
    };
    const bot = (name, diff, look) => ({ kind: 'bot', name, diff, look });
    this.slots = [{ kind: 'human', id: member.id }, null, null, null];
    if (stage.mode === 'doubles') {
      this.slots[1] = bot(stage.partner, stage.partnerDiff || stage.difficulty, stage.looks?.[0]);
      this.slots[2] = bot(stage.opponents[0], stage.difficulty, stage.looks?.[1]);
      this.slots[3] = bot(stage.opponents[1], stage.difficulty, stage.looks?.[2]);
    } else {
      this.slots[2] = bot(stage.opponents[0], stage.difficulty, stage.looks?.[0]);
    }
    this.beginMatch();
  }

  toLobby(host) {
    if (this.career) return 'Career matches have no lobby';
    if (!this.isHost(host)) return 'Only the host can return to the lobby';
    if (this.state === 'match') return 'Match in progress';
    this.state = 'lobby';
    this.game = null;
    for (const m of this.members.values()) { m.ready = false; m.rematch = false; }
    this.broadcastRoom();
    return null;
  }

  chat(m, text) {
    const now = Date.now();
    const last = this.chatTimes.get(m.id) || 0;
    if (now - last < 400) return;
    this.chatTimes.set(m.id, now);
    const t = cleanText(text);
    if (t) this.broadcast({ t: 'chat', id: m.id, name: m.name, slot: this.slotOf(m.id), text: t });
  }

  emote(m, id) {
    if (!Number.isInteger(id) || id < 0 || id > 7) return;
    this.broadcast({ t: 'emote', slot: this.slotOf(m.id), id });
  }

  pushInputs(m, inputs) {
    if (this.state !== 'match' || !Array.isArray(inputs)) return;
    const slot = this.slotOf(m.id);
    if (slot < 0) return;
    const q = this.queues[slot];
    for (const inp of inputs.slice(0, 8)) {
      if (!inp || typeof inp !== 'object') continue;
      q.push(inp);
    }
    // never let lag build an unbounded backlog; keep swing/jump intents when trimming
    while (q.length > MAX_QUEUE) {
      const d = q.shift();
      if (d.swing) q[0].swing = true;
      if (d.jump) q[0].jump = true;
    }
  }

  // ------------------------------------------------------------ pause (online)
  // One player asks, the other humans accept. The game then stops for at most 30 s, or until every human presses Resume.

  connectedHumans() {
    return [...this.members.values()].filter((m) => m.connected && this.slotOf(m.id) >= 0);
  }

  pauseView(extra = {}) {
    const p = this.pause;
    if (!p) return { t: 'pause', phase: 'off', ...extra };
    const name = (id) => this.members.get(id)?.name || '?';
    return {
      t: 'pause', phase: p.phase, by: name(p.by), byId: p.by, expires: p.expires, until: p.until, now: Date.now(),
      accepted: [...p.accepts].map(name), resumed: [...(p.resumes || [])].map(name), resumedIds: [...(p.resumes || [])], humans: this.connectedHumans().map((m) => m.id), ...extra,
    };
  }

  /** kind: 'req' | 'accept' | 'deny' | 'resume'. Returns an error message or null. */
  pauseCtl(m, kind, now = Date.now()) {
    if (this.state !== 'match' || !this.game || this.game.phase === 'ended') return 'There is no match to pause';
    if (this.slotOf(m.id) < 0) return 'Only players can pause';
    const p = this.pause;
    if (kind === 'req') {
      if (p) return p.phase === 'active' ? 'Already paused' : 'A pause was already requested';
      if ((this.pausesUsed.get(m.id) || 0) >= PAUSES_PER_PLAYER) return 'You have used your pauses for this match';
      this.pause = { phase: 'request', by: m.id, accepts: new Set([m.id]), resumes: new Set(), expires: now + PAUSE_REQUEST_MS };
      this.pauseEvaluate(now);
      if (this.pause?.phase === 'request') this.broadcast(this.pauseView());
      return null;
    }
    if (!p) return null;
    if (kind === 'accept' && p.phase === 'request' && m.id !== p.by) { p.accepts.add(m.id); this.pauseEvaluate(now); if (this.pause?.phase === 'request') this.broadcast(this.pauseView()); return null; }
    if (kind === 'deny' && p.phase === 'request' && m.id !== p.by) { this.pause = null; this.broadcast({ t: 'pause', phase: 'denied', by: m.name }); return null; }
    if (kind === 'resume' && p.phase === 'active') { p.resumes.add(m.id); this.pauseEvaluate(now); if (this.pause) this.broadcast(this.pauseView()); return null; }
    return null;
  }

  /** Move the pause forward: accepted by everybody, resumed by everybody, or timed out. */
  pauseEvaluate(now = Date.now()) {
    const p = this.pause;
    if (!p) return;
    const humans = this.connectedHumans();
    if (p.phase === 'request') {
      if (now >= p.expires) { this.pause = null; this.broadcast({ t: 'pause', phase: 'denied', by: '', expired: true }); return; }
      if (humans.every((h) => p.accepts.has(h.id))) {
        p.phase = 'active'; p.until = now + PAUSE_MAX_MS; p.resumes = new Set();
        this.pausesUsed.set(p.by, (this.pausesUsed.get(p.by) || 0) + 1);
        this.broadcast(this.pauseView());
      }
      return;
    }
    if (now >= p.until || humans.every((h) => p.resumes.has(h.id))) {
      this.pause = null;
      for (let s = 0; s < 4; s++) { this.queues[s] = []; this.lastInput[s] = null; this.starved[s] = 0; } // nothing stale carries over
      this.broadcast({ t: 'pause', phase: 'off' });
    }
  }

  // ------------------------------------------------------------ simulation

  step(dt) {
    const g = this.game;
    if (!g) return;
    if (this.pause) { this.pauseEvaluate(); if (this.pause?.phase === 'active') return; } // the match is frozen while paused
    for (let s = 0; s < 4; s++) {
      if (!g.players[s].active) continue;
      const slot = this.slots[s];
      const m = slot?.kind === 'human' ? this.members.get(slot.id) : null;
      g.players[s].human = !!(m && m.connected); // bots read this to play sensibly with a person as partner
      if (m && m.connected) {
        const q = this.queues[s];
        let inp = q.shift();
        if (inp) {
          this.lastInput[s] = inp;
          this.starved[s] = 0;
          g.players[s].ack = Number.isInteger(inp.seq) ? inp.seq : g.players[s].ack;
        } else if (this.lastInput[s]) {
          // no fresh input (lag spike or hidden tab): repeat briefly, then stand still
          const stale = ++this.starved[s] > 15;
          inp = { ...this.lastInput[s], swing: false, jump: false, ...(stale ? { mx: 0, mz: 0, sprint: false } : {}) };
        }
        if (inp) g.applyInput(s, inp);
      } else {
        g.applyInput(s, botInput(g, s, this.botMem[s], slot?.diff || this.settings.difficulty, dt));
      }
    }
    g.tick(dt);
    const evs = g.drainEvents();
    if (evs.length) {
      this.broadcast({ t: 'ev', ev: evs });
      const done = evs.find((e) => e.e === 'match');
      if (done) this.finishMatch(done);
    }
    if (g.tickNo % SNAPSHOT_EVERY === 0) this.broadcast(g.snapshot());
    if (this.resultAt && g.time >= this.resultAt && this.state === 'match') {
      this.state = 'results';
      this.broadcastRoom();
      this.broadcast(this.lastResultsMsg);
    }
  }

  finishMatch(ev) {
    if (this.persisted) return;
    this.persisted = true;
    const humans = [];
    for (let s = 0; s < 4; s++) {
      const slot = this.slots[s];
      if (slot?.kind === 'human') {
        const m = this.members.get(slot.id);
        if (m) humans.push({ token: m.token, id: m.id, name: m.name, slot: s, team: s >> 1 });
      }
    }
    const gains = this.store.recordMatch({ code: this.code, humans, results: ev.results, settings: this.settings });
const names = this.slots.map((s) => (s?.kind === 'human' ? this.members.get(s.id)?.name : s?.name || 'AI'));
    const progress = {};
    for (const h of humans) progress[h.id] = gains[h.token];
    let career = null;
    const stage = this.career && CAREER.find((c) => c.id === this.career);
    if (stage && humans[0]) {
      const stars = starsFor(ev.results);
      const c = this.store.careerComplete(humans[0].token, stage.id, stars);
      career = { stage: stage.id, name: stage.name, won: stars > 0, stars, bonusXp: c.bonusXp, unlocked: c.unlocked, hasNext: stage.id < CAREER.length };
    }
    this.lastResultsMsg = JSON.stringify({ t: 'results', results: ev.results, names, progress, career });
    this.resultAt = this.game.time + RESULTS_DELAY;
  }

  expired(now) {
    return this.emptySince !== null && now - this.emptySince > EMPTY_ROOM_TTL_MS;
  }
}

export class RoomManager {
  constructor(store) {
    this.store = store;
    this.rooms = new Map();
    this.byToken = new Map(); // token -> {room, id}
  }

  newCode() {
    for (;;) {
      let c = '';
      for (let i = 0; i < 5; i++) c += CODE_CHARS[crypto.randomInt(CODE_CHARS.length)];
      if (!this.rooms.has(c)) return c;
    }
  }

  create({ token, name, ws, look }) {
    const room = new Room(this.newCode(), this.store);
    this.rooms.set(room.code, room);
    const m = room.addMember({ token, name, ws, look });
    this.byToken.set(token, { room, id: m.id });
    return { room, member: m };
  }

  join(code, { token, name, ws, look }) {
    const room = this.rooms.get(String(code || '').toUpperCase().trim());
    if (!room) return { error: 'Room not found. Check the code and try again.' };
    const err = room.canJoin();
    if (err) return { error: err };
    const m = room.addMember({ token, name, ws, look });
    this.byToken.set(token, { room, id: m.id });
    return { room, member: m };
  }

  /** Open lobbies that chose to be public and still have a free seat. */
  listPublic() {
    const out = [];
    for (const r of this.rooms.values()) {
      if (r.state !== 'lobby' || !r.settings.public || r.career || r.canJoin()) continue;
      const host = r.members.get(r.hostId);
      const act = r.activeSlots();
      out.push({
        code: r.code, host: host ? host.name : '?', mode: r.settings.mode, difficulty: r.settings.difficulty,
        players: act.filter((i) => r.slots[i]?.kind === 'human').length, max: act.length,
      });
    }
    return out.slice(0, 30);
  }

  /** The room/member this guest identity currently belongs to, if still alive. */
  membership(token) {
    const e = this.byToken.get(token);
    if (!e) return null;
    const member = e.room.members.get(e.id);
    if (!member || !this.rooms.has(e.room.code)) { this.byToken.delete(token); return null; }
    return { room: e.room, member };
  }

  leave(token) {
    const ms = this.membership(token);
    if (!ms) return;
    this.byToken.delete(token);
    ms.room.removeMember(ms.member.id);
  }

  step(dt) {
    for (const r of this.rooms.values()) if (r.state === 'match') r.step(dt);
  }

  sweep(now = Date.now()) {
    for (const [code, r] of this.rooms) {
      if (r.expired(now) || (r.members.size === 0 && r.emptySince !== null && now - r.emptySince > 30_000)) {
        for (const m of r.members.values()) this.byToken.delete(m.token);
        this.rooms.delete(code);
      }
    }
  }
}

// File-backed persistence (guest profiles + finished matches).
// This is a deliberately small stand-in for PostgreSQL: the Store interface
// (profile / recordMatch) is all the rest of the server touches, so a SQL
// implementation can replace this file without changing anything else.

import fs from 'node:fs';
import path from 'node:path';
import crypto from 'node:crypto';
import { CAREER } from '../shared/career.js';

const MAX_MATCHES = 500;
const MAX_HISTORY = 20;

export const levelFor = (xp) => Math.floor(Math.sqrt(xp / 100)) + 1;

export class Store {
  constructor(dir) {
    this.dir = dir;
    this.file = path.join(dir, 'store.json');
    this.data = { profiles: {}, matches: [] };
    this.timer = null;
    fs.mkdirSync(dir, { recursive: true });
    try {
      this.data = JSON.parse(fs.readFileSync(this.file, 'utf8'));
    } catch {
      /* first run or unreadable file: start empty */
    }
  }

  newToken() {
    return crypto.randomBytes(16).toString('hex');
  }

  /** Create the profile if needed and return it. */
  profile(token, name) {
    let p = this.data.profiles[token];
    if (!p) {
      p = { name: name || 'Guest', xp: 0, matches: 0, wins: 0, losses: 0, createdAt: Date.now(), history: [] };
      this.data.profiles[token] = p;
      this.scheduleSave();
    } else if (name && name !== p.name) {
      p.name = name;
      this.scheduleSave();
    }
    return p;
  }

  hasProfile(token) {
    return !!this.data.profiles[token];
  }

  publicProfile(token) {
    const p = this.data.profiles[token];
    if (!p) return null;
    return { name: p.name, xp: p.xp, level: levelFor(p.xp), matches: p.matches, wins: p.wins, losses: p.losses, history: p.history };
  }

  /** Career ladder for a profile: every stage with its stars and whether it is unlocked. */
  careerView(token) {
    const p = this.profile(token);
    const done = p.career?.done || {};
    const stages = CAREER.map((s) => ({ ...s, stars: done[s.id] || 0, unlocked: s.id === 1 || (done[s.id - 1] || 0) >= 1 }));
    return { stages, stars: stages.reduce((a, s) => a + s.stars, 0), max: CAREER.length * 3 };
  }

  /** Record a career result (stars 0 = lost). Bonus XP is paid only for improving your best stars on a stage. */
  careerComplete(token, stageId, stars) {
    const p = this.profile(token);
    const stage = CAREER.find((s) => s.id === stageId);
    p.career ||= { done: {} };
    const prev = p.career.done[stageId] || 0;
    let bonusXp = 0, unlocked = null;
    if (stage && stars > prev) {
      p.career.done[stageId] = stars;
      bonusXp = stage.xp * (stars - prev);
      p.xp += bonusXp;
      if (prev === 0 && CAREER.some((s) => s.id === stageId + 1)) unlocked = stageId + 1;
    }
    this.scheduleSave();
    return { stars, prev, bonusXp, unlocked, level: levelFor(p.xp) };
  }

  /**
   * Persist a finished match. `humans` = [{token, name, slot, team}].
   * Only the server calls this, from its own simulation's result.
   */
  recordMatch({ code, humans, results, settings }) {
    const entry = {
      at: Date.now(), code, settings,
      winner: results.winner, score: results.score.sets, duration: results.duration,
      players: humans.map((h) => ({ name: h.name, team: h.team })),
    };
    this.data.matches.push(entry);
    if (this.data.matches.length > MAX_MATCHES) this.data.matches.splice(0, this.data.matches.length - MAX_MATCHES);
    const gains = {};
    for (const h of humans) {
      const p = this.profile(h.token, h.name);
      const won = h.team === results.winner;
      const gain = 40 + (won ? 60 : 0);
      p.xp += gain;
      p.matches++;
      if (won) p.wins++; else p.losses++;
      p.history.unshift({
        at: entry.at, won, score: results.score.sets.map((s) => `${s[0]}-${s[1]}`).join(' '),
        team: h.team, duration: results.duration,
      });
      if (p.history.length > MAX_HISTORY) p.history.length = MAX_HISTORY;
      gains[h.token] = { xp: gain, level: levelFor(p.xp), totalXp: p.xp };
    }
    this.scheduleSave();
    return gains;
  }

  scheduleSave() {
    if (this.timer) return;
    this.timer = setTimeout(() => { this.timer = null; this.flush(); }, 400);
    this.timer.unref?.();
  }

  flush() {
    if (this.timer) { clearTimeout(this.timer); this.timer = null; }
    const tmp = `${this.file}.tmp`;
    try {
      fs.writeFileSync(tmp, JSON.stringify(this.data));
      fs.renameSync(tmp, this.file);
    } catch (err) {
      console.error('[store] write failed:', err.message);
    }
  }
}

// Training drills. They run on the SAME PadelGame as a match (same physics, shots, contact model, rules); this controller
// only feeds balls, resets the score after each point and counts what the player does with the real game events.
import { createMatch, scoreView } from '../../shared/scoring.js';
import { solveLaunch } from '../../shared/physics.js';
import { DRILLS } from '../../shared/career2.js';

// Where the player stands and how the ball is fed. Team 0 always attacks toward +z.
const FEEDS = {
  forehand: { stand: [1.5, -7], from: () => [rr(-2, 2), 1.6, 8.5], land: () => [rr(-1.2, 2.2), -6.2], T: 1.05 },
  lob: { stand: [0, -3.2], from: () => [rr(-2, 2), 1.5, 8.5], land: () => [rr(-1, 1), -3.6], T: 0.95 },
  volley: { stand: [0, -2.4], from: () => [rr(-1.5, 1.5), 1.5, 8.5], land: () => [rr(-1.5, 1.5), -5.2], T: 0.8 },
  smash: { stand: [0, -3.1], from: () => [rr(-1.5, 1.5), 1.5, 6.5], land: () => [rr(-0.8, 0.8), -2.2], T: 2.05 },
};

// Target zones on the opponents' side (x0..x1, z0..z1) and which shots count
const ZONES = {
  forehand: { x0: -4.6, x1: -1.6, z0: 6.0, z1: 9.7, kinds: null, label: 'Target: deep right-hand corner' },
  lob: { x0: -4.7, x1: 4.7, z0: 6.95, z1: 9.7, kinds: ['lob'], label: 'Target: behind the service line (use the globo)' },
  volley: { x0: -4.7, x1: 4.7, z0: 3, z1: 9.7, kinds: ['volley', 'block'], label: 'Target: the open court (volley it)' },
  smash: { x0: -4.7, x1: 4.7, z0: 1, z1: 9.7, kinds: ['smash', 'bandeja', 'vibora'], label: 'Target: the court (smash or bandeja)' },
};
const rr = (a, b) => a + Math.random() * (b - a);

export class DrillController {
  constructor(drillId) {
    this.drill = DRILLS.find((d) => d.id === drillId);
    this.zone = ZONES[drillId] || null;
    this.attempts = 0; this.score = 0;
    this.lastHit = null; this.evaluated = false; this.serveCounted = false;
    this.done = false;
  }

  status(lm) {
    const d = this.drill;
    lm.emit({
      t: 'drillStatus',
      text: `${d.name} · ${Math.min(this.attempts, d.n)}/${d.n} · score ${this.score}${this.zone ? ' · ' + this.zone.label : d.id === 'serve' ? ' · Space to serve' : ''}`,
      zone: this.zone,
    });
  }

  /** Called every tick before the game steps. */
  update(g, lm) {
    if (this.done) return;
    if (!this.started) { this.started = true; this.status(lm); }
    if (g.phase === 'serve' && this.drill.id !== 'serve') this.feed(g);
  }

  feed(g) {
    const f = FEEDS[this.drill.id];
    const p = g.players[0];
    p.x = f.stand[0]; p.z = f.stand[1]; p.vx = p.vz = 0; p.swing = null; p.cd = 0;
    g.phase = 'rally';
    g.rally = { serving: false, faults: 0, lastTeam: 1, lastSlot: 2, bounces: 0, hits: 1, netTouched: false, serveXSign: 1 };
    const [sx, sy, sz] = f.from();
    const [lx, lz] = f.land();
    const b = g.ball;
    Object.assign(b, { x: sx, y: sy, z: sz, sb: 0, ss: 0 });
    const v = solveLaunch(b, lx, lz, f.T);
    b.vx = v.vx; b.vy = v.vy; b.vz = v.vz;
    this.lastHit = null; this.evaluated = false;
    g.events.push({ e: 'serve', slot: 2, side: 0, score: scoreView(g.match) });
  }

  inZone(x, z) {
    const zn = this.zone;
    return x >= zn.x0 && x <= zn.x1 && z >= zn.z0 && z <= zn.z1;
  }

  /** Called with the game's events after every tick. */
  events(evs, g, lm) {
    if (this.done) return;
    const id = this.drill.id;
    for (const e of evs) {
      if (e.e === 'hit' && e.slot === 0) { this.lastHit = e; }
      if (id === 'serve') {
        if (e.e === 'fault') { this.attempts++; this.status(lm); }
        else if (e.e === 'ball' && e.k === 'floor' && !this.serveCounted && this.lastHit?.kind === 'serve' && e.z > 0) {
          this.serveCounted = true; this.attempts++;
          this.score += 1 + (e.z > 5.2 ? 1 : 0); // in the box, +1 more when it lands deep
          this.status(lm);
        }
        if (e.e === 'point') this.serveCounted = false;
      } else if (e.e === 'ball' && e.k === 'floor' && this.lastHit && !this.evaluated && e.z > 0) {
        this.evaluated = true;
        const kindOk = !this.zone.kinds || this.zone.kinds.includes(this.lastHit.kind);
        if (kindOk && this.inZone(e.x, e.z)) this.score++;
        this.status(lm);
      }
      if (e.e === 'point') {
        this.lastHit = null; this.evaluated = false; // each ball is judged on its own
        if (id !== 'serve') { this.attempts++; this.status(lm); }
        g.match = createMatch({ sets: 1, gamesPerSet: 6 }); // the score is irrelevant here: the server never changes
        g.pauseT = Math.min(g.pauseT, 0.9);
      }
    }
    if (this.attempts >= this.drill.n) {
      this.done = true;
      lm.finishDrill({ id, score: this.score, attempts: this.attempts });
    }
  }
}

  setPaused(p) { this.paused = p; if (p) this.input.clear(); }

  /** Movement relative to the camera, which always looks toward the opponents. */
  moveAxes() {
    const a = this.input.axes(); // x = right, y = forward
    // camera faces (0,0,os); screen-right is (-os, 0, 0)
    return { mx: -this.os * a.x, mz: this.os * a.y };

  /**
   * Where the shot is aimed. Three sources, chosen by the control settings:
   *  mouse  : the target follows the cursor (ray from the camera onto the court)
   *  stick  : the right stick places the shot
   *  steer  : the direction you hold as you hit (keyboard, or the left stick): left/right = that side, forward = deep, back = short
   */
  // ------------------------------------------------------------------ instant replay

  record(now, view) {
    const mine = this.me;
    this.rec.push({
      t: now, ball: { ...view.ball },
      players: view.players.map((v, k) => (k === this.slot ? { ...v, x: mine.x, z: mine.z, vx: mine.vx, vz: mine.vz, swingT: this.swingLocal ? this.swingLocal.t : v.swingT, kindName: this.swingLocal ? this.swingLocal.kind : v.kindName } : { ...v })),
    });
    while (this.rec.length && now - this.rec[0].t > 7000) this.rec.shift();
  }

  /** Called a moment after a point: replay the last seconds in slow motion from a side camera. */
  startReplay() {
    if (this.stopped || this.replay || !this.local || !settings.replays || this.rec.length < 60) return;
    const end = this.rec[this.rec.length - 1].t;
    const frames = this.rec.filter((f) => f.t >= end - 4500);
    if (frames.length < 40) return;
    this.replay = { frames, t: 0, dur: frames[frames.length - 1].t - frames[0].t, side: Math.random() < 0.5 ? -1 : 1 };
    this.onReplay?.(true);
    document.querySelector('.hud')?.classList.add('replaying');
    this.hud.banner('Replay', 'Space or Esc to skip', 0);
    this.world.setZone?.(null);
  }

  playReplay(dt) {
    const R = this.replay, w = this.world;
    R.t += dt * 1000 * 0.55; // slow motion
    if (R.t >= R.dur) { this.endReplay(); return; }
    const t0 = R.frames[0].t + R.t;
    let i = 0;
    while (i < R.frames.length - 1 && R.frames[i + 1].t <= t0) i++;
    const a = R.frames[i], b = R.frames[Math.min(i + 1, R.frames.length - 1)];
    const f = b.t > a.t ? clamp((t0 - a.t) / (b.t - a.t), 0, 1) : 0;
    const L = (p, q) => p + (q - p) * f;
    const ball = { x: L(a.ball.x, b.ball.x), y: L(a.ball.y, b.ball.y), z: L(a.ball.z, b.ball.z) };
    w.setBall(ball.x, ball.y, ball.z);
    w.ballVel = { x: a.ball.vx, y: a.ball.vy, z: a.ball.vz };
    const sp = Math.hypot(a.ball.vx, a.ball.vz);
    w.animateBall(dt * 0.55, Math.hypot(sp, a.ball.vy), sp > 0.1 ? a.ball.vx / sp : 0, sp > 0.1 ? a.ball.vz / sp : 1, a.ball.sb, a.ball.ss);
    a.players.forEach((pa, k) => {
      const pb = b.players[k];
      w.updatePlayer(k, { ...pa, x: L(pa.x, pb.x), z: L(pa.z, pb.z), serving: false }, dt * 0.55, false);
    });
    const cam = w.camera;
    // high television camera behind one end, drifting with the ball
    const tx = clamp(ball.x * 0.35, -3, 3), tz = R.side * 15.5;
    cam.position.x += (tx - cam.position.x) * Math.min(1, dt * 2);
    cam.position.y += (6.4 - cam.position.y) * Math.min(1, dt * 2);
    cam.position.z += (tz - cam.position.z) * Math.min(1, dt * 2);
    cam.lookAt(ball.x * 0.5, 0.9, ball.z * 0.8);
    w.reticle.visible = w.reticleDot.visible = false;
    w.reachRing.visible = false;
    this.hud.timing(null);
  }

  endReplay() {
    if (!this.replay) return;
    this.replay = null;
    this.hud.banner('', '', 1);
    document.querySelector('.hud')?.classList.remove('replaying');
    this.camPos = null; // the match camera takes over again from where it is
    this.onReplay?.(false);
  }

  updateAim(dt) {
    const os = this.os;
    const inp = this.input;
    const st = inp.aimStick();
    this.aimSource = inp.settings.mouseAim ? 'mouse' : st.active ? 'stick' : 'steer';
    if (this.aimSource === 'mouse') {
      const w = innerWidth, h = innerHeight;
      const ndc = new THREE.Vector2((inp.mouse.x / w) * 2 - 1, -(inp.mouse.y / h) * 2 + 1);
      if (!inp.mouse.moved) ndc.set(0, 0.1);
      this.ray.setFromCamera(ndc, this.world.camera);
      const o = this.ray.ray.origin, d = this.ray.ray.direction;
      let x = 0, z = os * 6;
      if (d.y < -0.001) {
        const t = -o.y / d.y;
        x = o.x + d.x * t; z = o.z + d.z * t;
      }
      this.kbAim.x = clamp(x, -4.6, 4.6);
      this.kbAim.z = os * clamp(Math.abs(z) * (z * os > 0 ? 1 : 0) || 1.2, 1.2, 9.4);
    } else {
      // opponents' positions decide the default: the open side, deep unless they are deep already
      const row = this.snaps.at(-1)?.p;
      let ox = 0, oz = 6;
      if (row) {
        const opp = [0, 1, 2, 3].filter((i) => i >> 1 !== this.team).map((i) => row[i]);
        ox = (opp[0][0] + opp[1][0]) / 2;
        oz = (Math.abs(opp[0][1]) + Math.abs(opp[1][1])) / 2;
      }
      const ax = inp.axes();
      const sx = this.aimSource === 'stick' ? st.x : ax.x;
      const sz = this.aimSource === 'stick' ? st.y : ax.y;
      const steerX = Math.abs(sx) > 0.25 ? clamp(sx, -1, 1) : 0;
      const steerZ = Math.abs(sz) > 0.25 ? Math.sign(sz) : 0;
      let tx, depth;
      if (steerX) tx = -os * steerX * 3.4; // screen-right is world (-os, 0, 0)
      else tx = (Math.abs(ox) < 0.6 ? (this.me.x > 0 ? -1 : 1) : -Math.sign(ox)) * 2.8;
      if (steerZ > 0) depth = 8.8;
      else if (steerZ < 0) depth = 3.0;
      else depth = oz < 4.5 ? 8.6 : 6.6; // opponents at the net: lob over them
      const k = this.aimSource === 'stick' ? 1 : Math.min(1, dt * 12);
      this.kbAim.x += (tx - this.kbAim.x) * k;
      this.kbAim.z += (os * depth - this.kbAim.z) * k;
    }
    this.aim.set(this.kbAim.x, 0.03, this.kbAim.z);
  }

  /** Serve power: hold to charge (0.9 s to full), release to hit. */
  updateCharge(dt) {
    const c = this.charge;
    if (!c) { this.hud.charge(null); return; }
    if (this.phase !== 'serve' || this.slot !== this.serverSlot) { this.charge = null; this.hud.charge(null); return; }
    c.t += dt;
    const f = clamp(c.t / 0.9, 0, 1);
    this.hud.charge(f);
    if (!this.input.actionDown(c.action)) {
      this.want.swing = true; this.want.lob = c.lob; if (c.mod) this.want.mod = c.mod;
      this.want.pace = 0.9 + 0.22 * f; // a tap is a normal serve, a full charge is +22% pace but less accurate
      this.charge = null; this.hud.charge(null);
    }
  }

  buildInput() {
    const { mx, mz } = this.moveAxes();
    const i = this.input;
    const held = i.actionDown('soft') ? 1 : i.actionDown('control') ? 2 : i.actionDown('slice') ? 3 : 0;
    const mod = this.want.swing && this.want.mod ? this.want.mod : held;
    const inp = {
      seq: ++this.seq, mx, mz, sprint: i.actionDown('sprint'),
      ax: +this.aim.x.toFixed(2), az: +this.aim.z.toFixed(2), mod,
      swing: this.want.swing, lob: this.want.lob, jump: this.want.jump, pace: this.want.swing ? this.want.pace : undefined,
      // keyboard steering is resolved by the server at contact; a mouse or right-stick target is sent as an explicit point
      steer: this.aimSource === 'steer',
    };
    if (this.want.swing && !this.swingLocal) this.swingLocal = { t: 0, kind: this.guessKind(inp) };
    this.want.swing = false; this.want.jump = false; this.want.mod = 0; this.want.pace = undefined;
    return inp;
  }

  guessKind(inp) {
    const b = this.ballView;
    if (this.phase === 'serve') return 'serve';
    if (inp.lob) return 'lob';
    if (inp.mod === 3 && b.y <= 2.1) return 'slice';
    if (b.y > 2.1) return inp.mod === 2 ? 'bandeja' : inp.mod === 1 ? 'vibora' : 'smash';
    const near = Math.abs(this.me.z) < 3.8;
    if (inp.mod === 1) return near ? 'chiquita' : 'drop';
    if (inp.mod === 2) return 'block';
    if (near && b.y > 0.35) return 'volley';
    const right = this.team === 0 ? b.x < this.me.x : b.x > this.me.x;
    return right ? 'forehand' : 'backhand';
  }

  /** Same movement rules as the server, including the serve restrictions. */
  stepMe(inp) {
    this.me.inRally = this.phase === 'rally';
    const mul = this.swingLocal ? PLAYER.SWING_MOVE : 1; // planted while swinging
    if (this.phase === 'serve') {
      this.me.vx = 0; this.me.vz = 0; // the server stays planted on the line until the serve is hit
    } else {
      stepPlayer(this.me, inp, TICK, undefined, mul);
    }
  }

  // ------------------------------------------------------------------ network in

  onSnap(m) {
    m.rt = performance.now();
    this.snaps.push(m);
    if (this.snaps.length > 40) this.snaps.shift();
    this.phase = m.ph;
    this.lastTeam = m.lt;
    const row = m.p[this.slot];
    const live = m.ph === 'serve' || m.ph === 'rally';
    Object.assign(this.me, { x: row[0], z: row[1], vx: row[2], vz: row[3], stamina: row[4] });
    const ack = row[8];
    this.pending = live ? this.pending.filter((i) => i.seq > ack) : [];
    for (const i of this.pending) this.stepMe(i);
    this.hud.setClock(m.n / 60);
  }

  onEvents(evs) {
    const later = (fn) => setTimeout(() => !this.stopped && fn(), this.interp * 900);
    for (const e of evs) {
      switch (e.e) {
        case 'serve': {
          this.hud.rally(0);
          this.serverSlot = e.slot;
          this.hud.setScore(e.score, this.names);
          if (e.score.matchPoint) this.sound.play('matchpoint');
          this.sound.announce(scoreCallout(e.score, e.score.server?.team));
          const mine = e.slot === this.slot;
          this.hud.banner(mine ? 'Your serve' : `${this.names[e.slot]} serves`, e.score.label || scoreCall(e.score), 2000);
          break;
        }
        case 'hit': {
          later(() => {
            this.sound.play('hit', { kind: e.kind, label: e.label, pan: e.x / 5, power: 0.75 + 0.25 * (e.q ?? 1) });
            this.world.spawnFx('hit', e.x, e.y, e.z, e.kind === 'smash' ? 1.6 : 1);
            this.world.punch(e.kind === 'smash' ? 2.4 : 0.9);
          });
          // the other team split-steps just before the ball arrives
          for (let s = 0; s < 4; s++) {
            if (s >> 1 === e.slot >> 1) continue;
            const pv = this.snaps.at(-1)?.p[s];
            const dist = pv ? Math.hypot(pv[0] - e.x, pv[1] - e.z) : 8;
            setTimeout(() => !this.stopped && this.world.splitStep(s), Math.max(0, (dist / 15 - 0.2) * 1000));
          }
          if (e.slot === this.slot) this.hud.feedback(e.label, e.kind);
          break;
        }
        case 'ball': {
          if (e.k === 'door') { later(() => this.hud.banner('Out the door!', 'Chase it outside', 1400)); break; }
          const pw = clamp((e.s || 4) / 9, 0.3, 1.4);
          later(() => {
            this.sound.play(e.k, { pan: e.x / 5, power: pw, mesh: e.k === 'wall' && (e.mesh ?? e.y > 3) });
            this.world.spawnFx(e.k, e.x, e.y, e.z, pw, e.axis);
          });
          break;
        }
        case 'fault':
          this.sound.play('fault');
          this.hud.banner('Fault', e.n === 1 ? 'Second serve' : '', 1800);
          break;
        case 'point': {
          this.hud.setScore(e.score, this.names);
          this.hud.setStats(e.st, e.lr);
          this.hud.rally(e.rally);
          if (e.winner === this.team) this.world.cheerCrowd();
          if (this.local && !e.marks.some((m) => m.type === 'match')) setTimeout(() => this.startReplay(), 1300);
          setTimeout(() => {
            if (this.stopped) return;
            for (let s = 0; s < 4; s++) if (this.world.players[s].root.visible) this.world.emote(s, (s >> 1) === e.winner ? 'win' : 'lose');
          }, 350);
          const top = e.marks.find((m) => m.type === 'match') || e.marks.find((m) => m.type === 'set') || e.marks.find((m) => m.type === 'game');
          const team = e.winner === this.team ? 'Your team' : 'Opponents';
          const why = e.por ? '¡Por 4!' : e.reason === 'bounce' && e.rally === 1 ? 'Ace' : REASONS[e.reason] || '';
          if (top) {
            const word = { match: 'Game, set & match', set: 'Set', game: 'Game' }[top.type];
            this.hud.banner(word, `${team} · ${why} · rally of ${e.rally}`, 2400);
            this.sound.play(top.type === 'match' ? 'match' : top.type === 'set' ? 'set' : 'game');
            this.sound.announce(top.type === 'match' ? 'Game, set and match' : top.type === 'set' ? 'Set' : 'Game');
          } else {
            this.hud.banner(why, `${e.winner === this.team ? 'Your team wins' : 'Opponents win'} the point · rally of ${e.rally} ${e.rally === 1 ? 'shot' : 'shots'}`, 2000);
            this.sound.play(e.winner === this.team ? 'point' : 'lose');
          }
          break;
        }
        case 'match':
          this.hud.banner(e.winner === this.team ? 'Victory' : 'Defeat', 'Match over', 4000);
          break;
        default:
      }
    }
  }

  // ------------------------------------------------------------------ frame

  interpolated(now) {
    const s = this.snaps;
    if (!s.length) return null;
    const t = now - this.interp * 1000;
    let i = s.length - 1;
    while (i > 0 && s[i - 1].rt > t) i--;
    const a = s[Math.max(0, i - 1)], b = s[i];
    let f = a === b ? 1 : (t - a.rt) / (b.rt - a.rt);
    let extra = 0;
    if (f > 1) { extra = Math.min(0.12, (t - b.rt) / 1000); f = 1; }
    f = clamp(f, 0, 1);
    const lerp = (p, q) => p + (q - p) * f;
    const ball = {
      x: lerp(a.b[0], b.b[0]) + b.b[3] * extra,
      y: Math.max(0.03, lerp(a.b[1], b.b[1]) + b.b[4] * extra - 4.9 * extra * extra),
      z: lerp(a.b[2], b.b[2]) + b.b[5] * extra,
      vy: b.b[4], vx: b.b[3], vz: b.b[5], sb: b.b[6] || 0, ss: b.b[7] || 0,
    };
    const players = b.p.map((rb, k) => {
      const ra = a.p[k];
      return {
        x: lerp(ra[0], rb[0]) + rb[2] * extra, z: lerp(ra[1], rb[1]) + rb[3] * extra,
        vx: rb[2], vz: rb[3], kindName: SHOT_IDS[rb[5]] || 'forehand', swingT: rb[6], jumpT: rb[7],
      };
    });
    return { ball, players };
  }

  frame(dt, now) {
    if (this.stopped) return;
    dt = Math.min(dt, 0.1);
    if (this.replay) { this.playReplay(dt); return; }
    if (this.paused && this.local) { this.updateCamera(dt); return; } // solo match paused: everything stands still, but the view follows the settings (camera, ball size…)
    this.updateAim(dt);

    this.updateCharge(dt);

    // fixed-step local input + prediction
    this.acc += dt;
    const out = [];
    const live = this.phase === 'serve' || this.phase === 'rally';
    while (this.acc >= TICK) {
      this.acc -= TICK;
      const inp = this.paused ? { seq: ++this.seq, mx: 0, mz: 0 } : this.buildInput();
      if (live) this.stepMe(inp);
      this.pending.push(inp);
      out.push(inp);
    }
    if (this.pending.length > 120) this.pending.splice(0, this.pending.length - 120);
    if (out.length) this.net.send({ t: 'in', inputs: out });

    const view = this.interpolated(now);
    const w = this.world;
    if (view) {
      this.ballView = view.ball;
      w.setBall(view.ball.x, view.ball.y, view.ball.z);
      w.ballVel = { x: view.ball.vx, y: view.ball.vy, z: view.ball.vz };
      const sp = Math.hypot(view.ball.vx, view.ball.vz);
      w.animateBall(dt, Math.hypot(sp, view.ball.vy), sp > 0.1 ? view.ball.vx / sp : 0, sp > 0.1 ? view.ball.vz / sp : 1, view.ball.sb, view.ball.ss);
      view.players.forEach((v, k) => {
        v.serving = this.phase === 'serve' && k === this.serverSlot;
        if (k === this.slot) {
          const sl = this.swingLocal;
          const mine = { ...v, x: this.me.x, z: this.me.z, vx: this.me.vx, vz: this.me.vz };
          if (sl) { mine.swingT = sl.t; mine.kindName = sl.kind; } else if (v.swingT >= 0) { mine.swingT = v.swingT; }
          w.updatePlayer(k, mine, dt, true);
        } else {
          w.updatePlayer(k, v, dt, false);
        }
      });
      if (this.swingLocal) { this.swingLocal.t += dt; if (this.swingLocal.t > 0.42) this.swingLocal = null; }
      if (this.local && settings.replays) this.record(now, view);
    }

    // reticle + reach ring (timing aid)
    w.reticle.position.set(this.aim.x, 0.04, this.aim.z);
    w.reticleDot.position.copy(w.reticle.position);
    // the ring is the target AREA, not a promise: it widens when the ball is far from the sweet spot (worse contact)
    const marker = this.input.settings.aimMarker;
    w.reticle.visible = w.reticleDot.visible = marker;
    {
      const bb = this.ballView;
      const dd = Math.hypot(bb.x - this.me.x, bb.z - this.me.z);
      const incoming = this.lastTeam !== this.team && this.phase === 'rally' && dd < 4;
      const radius = 0.3 + (incoming ? Math.min(1, Math.abs(dd - 0.95) / 1.7) * 0.9 : 0.15);
      w.reticle.scale.setScalar(radius / 0.3);
    }
    const b = this.ballView;
    const d = Math.hypot(b.x - this.me.x, b.z - this.me.z);
    const mine = this.lastTeam !== this.team && this.phase === 'rally';
    const inReach = mine && d < 2.0 && b.y < 2.8 && (this.team === 0 ? b.z < 0.3 : b.z > -0.3);
    w.reachRing.visible = settings.timing;
    w.reachRing.material.color.set(inReach ? 0xd4f23c : 0xffffff);
    w.reachRing.material.opacity = inReach ? 0.85 : mine && d < 3.5 ? 0.35 : 0.14;
    w.ballHalo.material.opacity = settings.ballScale > 2.4 ? 0.5 : 0;
    w.trailOn = settings.trail;

    this.updateCamera(dt);
    this.updateTimingRing(inReach);
    this.hud.setVitals(this.me.stamina, this.net.rtt);
  }

  /**
   * Closing-circle timing aid. The outer circle shrinks onto the ball as it nears the player;
   * pressing Space when it meets the inner ring (about 0.17 s before contact) is PERFECT.
   */
  updateTimingRing() {
    const b = this.ballView;
    if (this.phase === 'serve' && this.slot === this.serverSlot && settings.timing) { this.updateServeRing(b); return; }
    const mine = this.lastTeam !== this.team && this.phase === 'rally';
    const dx = this.me.x - b.x, dz = this.me.z - b.z;
    const d = Math.hypot(dx, dz);
    const bv = this.snaps.at(-1)?.b;
    const closing = bv && d > 0.01 ? (dx * bv[3] + dz * bv[5]) / d : 0;
    const onMySide = this.team === 0 ? b.z < 0.4 : b.z > -0.4;
    if (!settings.timing || !mine || !onMySide || closing < 1.5 || d > 14 || b.y > 3.2) { this.hud.timing(null); return; }
    const ttc = Math.max(0, d - 0.85) / closing; // seconds until the ball is at the sweet spot
    if (ttc > 1.1) { this.hud.timing(null); return; }
    const off = ttc - 0.17; // 0 = press now
    const v = new THREE.Vector3(b.x, b.y, b.z).project(this.world.camera);
    const x = (v.x * 0.5 + 0.5) * innerWidth, y = (-v.y * 0.5 + 0.5) * innerHeight;
    const inner = 26;
    const outer = inner + Math.max(0, off) * 200;
    let zone = 'far', text = '';
    if (off < -0.16) { zone = 'late'; text = 'TARDE'; }
    else if (Math.abs(off) <= 0.09) { zone = 'perfect'; text = 'PERFECTO'; }
    else if (off < 0) { zone = 'good'; text = 'BIEN'; }
    else if (off <= 0.22) { zone = 'good'; text = 'BIEN'; }
    this.hud.timing(x, y, Math.max(outer, inner * 0.8), zone, text);
  }

  /** Serve timing: the ring closes when the bounced ball is at waist height (the racket meets it ~0.05 s after the press). */
  updateServeRing(b) {
    const now = performance.now();
    const vy = this._sy !== undefined && now > this._st ? (b.y - this._sy) / ((now - this._st) / 1000) : 0;
    this._sy = b.y; this._st = now;
    const err = Math.abs(b.y + clamp(vy, -5, 5) * 0.05 - 0.62);
    const v = new THREE.Vector3(b.x, b.y, b.z).project(this.world.camera);
    const x = (v.x * 0.5 + 0.5) * innerWidth, y = (-v.y * 0.5 + 0.5) * innerHeight;
    const inner = 26;
    const zone = err <= 0.07 ? 'perfect' : err <= 0.17 ? 'good' : 'far';
    this.hud.timing(x, y, inner + Math.min(err, 0.5) * 220, zone, zone === 'perfect' ? 'PERFECTO' : zone === 'good' ? 'BIEN' : '');
  }

  /** Cameras with their own position (side, corner, wall): they stay out of the way and keep the ball in view. */
  updateFixedCamera(dt, c) {
    const cam = this.world.camera;
    const b = this.ballView, os = this.os;
    let want;
    if (c.mode === 'side') want = new THREE.Vector3(14.5, 8.8, clamp(b.z * 0.6, -6, 6)); // high enough to clear the stands and pergolas
    else if (c.mode === 'corner') want = new THREE.Vector3(8.5, 8.2, -os * 15.5);
    else want = new THREE.Vector3(clamp(b.x * 0.5, -3, 3) + this.me.x * 0.3, 2.1, -os * 12.4); // wall: low, behind your own glass
    if (!this.camPos) this.camPos = want.clone();
    this.camPos.lerp(want, 1 - Math.exp(-dt * c.smooth));
    const focus = new THREE.Vector3(b.x * 0.7, Math.min(b.y, 2.2) * 0.8 + 0.4, b.z * 0.85);
    this.camLook.lerp(focus, 1 - Math.exp(-dt * c.smooth * 1.4));
    this.world.baseFov = c.fov;
    cam.position.copy(this.camPos);
    cam.lookAt(this.camLook);
  }

  updateCamera(dt) {
    const cam = this.world.camera;
    const c = cameraConfig(settings);
    if (c.mode) { this.updateFixedCamera(dt, c); return; }
    const want = new THREE.Vector3(this.me.x * c.follow, c.height, this.me.z - this.os * c.dist);
    // stay inside the venue walls (the room backdrop is at 17 m)
    want.z = clamp(want.z, -15.5, 15.5);
    if (!this.camPos) this.camPos = want.clone();
    this.camPos.lerp(want, 1 - Math.exp(-dt * c.smooth));
    const ball = this.ballView;
    const focus = c.center
      ? new THREE.Vector3(this.me.x * 0.3, 0.8, 0)
      : new THREE.Vector3(this.me.x * 0.6, 0.6, this.me.z + this.os * c.lookAhead);
    // optionally drift toward the ball; this only moves the view, never the aim or the controls
    if (settings.ballTrack) focus.lerp(new THREE.Vector3(ball.x, Math.min(ball.y, 2), ball.z), c.ball);
    this.camLook.lerp(focus, 1 - Math.exp(-dt * c.smooth * 0.85));
    this.world.baseFov = c.fov;
    cam.position.copy(this.camPos);
    cam.lookAt(this.camLook);
  }
}

function scoreCall(s) {
  const [a, b] = s.points;
  return s.tiebreak ? `Tiebreak ${a}–${b}` : `${a}–${b}`;
}

// Input layer: keyboard, mouse and gamepad become normalised gameplay ACTIONS.
// Nothing here touches the character, the ball or the network: the match client asks this module

// conflict detection, persistence, pad reading) have no DOM dependency so they are unit-tested in Node.

// Standard-mapping gamepad: 0 A, 1 B, 2 X, 3 Y, 4 LB, 5 RB, 6 LT, 7 RT, 8 Back, 9 Start, 10 L3, 11 R3, 12-15 d-pad
const PAD = {
  up: [12], down: [13], left: [14], right: [15],

export const SCHEMES = {
  classic: { label: 'Classic keyboard', mouseAim: false, hint: 'WASD / arrows move. Hold a direction as you hit to place the shot.' },
  mouse: { label: 'Keyboard + mouse aim', mouseAim: true, hint: 'WASD moves, the mouse aims (target ring on the court), click to hit.' },

const clone = (o) => JSON.parse(JSON.stringify(o));
const num = (v, lo, hi, d) => (Number.isFinite(v) ? Math.min(hi, Math.max(lo, v)) : d);

export function defaultSettings() {
  return {
    v: 1, scheme: 'classic',
    bindings: { keyboard: clone(KEYBOARD), pad: clone(PAD) },
    mouseAim: false, deadzone: 0.18, curve: 1.4, toggleSprint: false, aimMarker: true, stickAim: true,
  };
}

/** Switch to a preset. 'custom' keeps whatever is currently bound. */
export function applyScheme(s, scheme) {
  if (!SCHEMES[scheme]) return s;
  s.scheme = scheme;
  s.mouseAim = SCHEMES[scheme].mouseAim;
  if (scheme !== 'custom') s.bindings = { keyboard: clone(KEYBOARD), pad: clone(PAD) };
  return s;
}

/** Validate anything read from storage: unknown shapes fall back to defaults, numbers are clamped. */
export function sanitizeSettings(raw) {
  const d = defaultSettings();
  if (!raw || typeof raw !== 'object') return d;
  const out = { ...d };
  if (SCHEMES[raw.scheme]) out.scheme = raw.scheme;
  for (const dev of ['keyboard', 'pad']) {
    for (const a of ACTIONS) {
      const v = raw.bindings?.[dev]?.[a];
      if (Array.isArray(v) && v.every((c) => (dev === 'pad' ? Number.isInteger(c) && c >= 0 && c < 32 : typeof c === 'string' && c.length < 24))) out.bindings[dev][a] = v.slice(0, 4);
    }
  }
  out.mouseAim = typeof raw.mouseAim === 'boolean' ? raw.mouseAim : SCHEMES[out.scheme].mouseAim;
  out.deadzone = num(raw.deadzone, 0, 0.6, d.deadzone);
  out.curve = num(raw.curve, 0.6, 3, d.curve);
  out.toggleSprint = !!raw.toggleSprint;
  out.aimMarker = raw.aimMarker !== false;
  out.stickAim = raw.stickAim !== false;
  return out;
}

const KEY = 'padel.input';
export function loadSettings(storage) {
  try { return sanitizeSettings(JSON.parse(storage.getItem(KEY))); } catch { return defaultSettings(); }
}
export function saveSettings(storage, s) {
  try { storage.setItem(KEY, JSON.stringify(s)); return true; } catch { return false; }
}

/** The other action already using `code` on this device, or null. */
export function findConflict(s, device, action, code) {
  for (const a of ACTIONS) if (a !== action && s.bindings[device][a].includes(code)) return a;
  return null;
}

/**
 * Bind `code` as the primary binding of `action`. If another action already uses it, the two swap:
 * the other action takes this action's previous primary binding. Returns {swappedWith} or {}.
 */
export function rebind(s, device, action, code) {
  const b = s.bindings[device];
  const old = b[action][0];
  const other = findConflict(s, device, action, code);
  let swappedWith = null;
  if (other) {
    b[other] = b[other].filter((c) => c !== code);
    if (old !== undefined && !b[other].includes(old)) b[other].unshift(old);
    swappedWith = other;
  }
  b[action] = [code, ...b[action].filter((c) => c !== code && c !== old)];
  s.scheme = 'custom';
  return swappedWith ? { swappedWith } : {};
}

export function resetBindings(s, device) {
  s.bindings[device] = clone(device === 'pad' ? PAD : KEYBOARD);
  s.scheme = 'custom';
  return s;
}

export const PAD_NAMES = ['A', 'B', 'X', 'Y', 'LB', 'RB', 'LT', 'RT', 'Back', 'Start', 'L3', 'R3', '↑', '↓', '←', '→', 'Home'];
export function codeLabel(device, code) {
  if (device === 'pad') return PAD_NAMES[code] ?? `Button ${code}`;
  if (code.startsWith('Mouse')) return ['Mouse L', 'Mouse M', 'Mouse R'][+code.slice(5)] ?? code;
  if (code.startsWith('Key')) return code.slice(3);
  if (code.startsWith('Digit')) return code.slice(5);
  return { ArrowUp: '↑', ArrowDown: '↓', ArrowLeft: '←', ArrowRight: '→', ShiftLeft: 'Shift L', ShiftRight: 'Shift R', ControlLeft: 'Ctrl L', Space: 'Space' }[code] || code;
}

/** Radial dead zone with a response curve: small stick movements stay precise, full tilt reaches 1. */
export function shapeStick(x, y, deadzone, curve) {
  const mag = Math.hypot(x, y);
  if (mag <= deadzone) return { x: 0, y: 0 };
  const m = Math.min(1, (mag - deadzone) / (1 - deadzone));
  const k = Math.pow(m, curve) / mag;
  return { x: x * k, y: y * k };
}

/**
 * Read a gamepad-like object ({axes, buttons}) into actions. Axis y is screen-down positive, so it is flipped:
 * the result uses x = right, y = up/forward.
 */
export function readPad(pad, s) {
  const axis = (i) => pad.axes?.[i] ?? 0;
  const L = shapeStick(axis(0), -axis(1), s.deadzone, s.curve);
  const R = shapeStick(axis(2), -axis(3), s.deadzone, s.curve);
  const down = new Set();
  const b = s.bindings.pad;
  for (const a of ACTIONS) {
    if (b[a].some((i) => pad.buttons?.[i] && (pad.buttons[i].pressed || pad.buttons[i].value > 0.5))) down.add(a);
  }
  const pressedButtons = new Set();
  (pad.buttons || []).forEach((btn, i) => { if (btn && (btn.pressed || btn.value > 0.5)) pressedButtons.add(i); });
  return { move: L, aim: R, down, pressedButtons };
}

const EDGE_ACTIONS = ['hit', 'lob', 'slice', 'soft', 'control', 'jump', 'stats', 'pause'];

export class InputManager {
  constructor(storage) {
    this.storage = storage;
    this.settings = loadSettings(storage);
    this.down = new Set(); // keyboard codes and Mouse0..2
    this.padDown = new Set(); // actions currently held on the gamepad
    this.padButtons = new Set();
    this.padStick = { move: { x: 0, y: 0 }, aim: { x: 0, y: 0 } };
    this.padName = null;
    this.mouse = { x: 0, y: 0, moved: false };
    this.handlers = new Map();
    this.sprintOn = false;
    this.gameActive = false;
    this.captureCb = null;
    this.lastDevice = 'keyboard';
  }

  save() { saveSettings(this.storage, this.settings); }

  on(event, fn) {
    if (!this.handlers.has(event)) this.handlers.set(event, new Set());
    this.handlers.get(event).add(fn);
    return () => this.handlers.get(event).delete(fn);
  }

  emit(event, arg) { for (const fn of this.handlers.get(event) || []) fn(arg); }

  actionsFor(device, code) {
    const out = [];
    for (const a of ACTIONS) if (this.settings.bindings[device][a].includes(code)) out.push(a);
    return out;
  }

  press(action) {
    if (action === 'sprint' && this.settings.toggleSprint) this.sprintOn = !this.sprintOn;
    if (EDGE_ACTIONS.includes(action)) this.emit(action);
  }

  attach(win = window) {
    const typing = () => /^(INPUT|TEXTAREA|SELECT)$/.test(document.activeElement?.tagName || '');
    this.onKeyDown = (e) => {
      if (this.captureCb) { e.preventDefault(); this.finishCapture('keyboard', e.code); return; }
      if (typing()) return;
      if (/^Digit[1-4]$/.test(e.code) && this.gameActive && !e.repeat) { this.emit('chat', +e.code.slice(5) - 1); return; }
      const acts = this.actionsFor('keyboard', e.code);
      if (acts.length && this.gameActive) e.preventDefault();
      if (e.repeat) return;
      this.lastDevice = 'keyboard';
      this.down.add(e.code);
      for (const a of acts) this.press(a);
    };
    this.onKeyUp = (e) => {
      this.down.delete(e.code);
      for (const a of this.actionsFor('keyboard', e.code)) if (a === 'stats') this.emit('statsUp');
    };
    this.onPointerDown = (e) => {
      const code = `Mouse${e.button}`;
      if (this.captureCb) { if (e.target.closest?.('#modal')) { e.preventDefault(); this.finishCapture('keyboard', code); } return; }
      if (e.target?.id !== 'gl') return;
      this.lastDevice = 'keyboard';
      this.down.add(code);
      for (const a of this.actionsFor('keyboard', code)) this.press(a);
    };
    this.onPointerUp = (e) => this.down.delete(`Mouse${e.button}`);
    this.onPointerMove = (e) => { this.mouse.x = e.clientX; this.mouse.y = e.clientY; this.mouse.moved = true; };
    this.onContext = (e) => { if (this.gameActive) e.preventDefault(); };
    this.onBlur = () => this.clear();
    win.addEventListener('keydown', this.onKeyDown);
    win.addEventListener('keyup', this.onKeyUp);
    win.addEventListener('pointerdown', this.onPointerDown);
    win.addEventListener('pointerup', this.onPointerUp);
    win.addEventListener('pointermove', this.onPointerMove);
    win.addEventListener('contextmenu', this.onContext);
    win.addEventListener('blur', this.onBlur);
  }

  clear() { this.down.clear(); this.padDown.clear(); this.sprintOn = false; }

  /** Ask for the next key / mouse button / pad button. Escape cancels. */
  capture(cb, device) {
    this.captureCb = cb; this.captureDevice = device;
  }

  cancelCapture() { this.captureCb = null; }

  finishCapture(device, code) {
    if (device === 'keyboard' && code === 'Escape') { this.captureCb = null; return; } // never bind the menu key by accident
    if (this.captureDevice && this.captureDevice !== device) return; // wrong device for this tab: keep waiting
    const cb = this.captureCb; this.captureCb = null;
    cb?.(device, code);
  }

  /** Poll the gamepad once per frame (button edges and sticks). */
  poll() {
    const pads = typeof navigator !== 'undefined' && navigator.getGamepads ? [...navigator.getGamepads()].filter(Boolean) : [];
    const pad = pads.find((p) => p.connected && p.mapping === 'standard') || pads.find((p) => p.connected);
    const name = pad ? pad.id.slice(0, 40) : null;
    if (name !== this.padName) { this.padName = name; this.emit('padchange', name); }
    if (!pad) { this.padDown = new Set(); this.padButtons = new Set(); this.padStick = { move: { x: 0, y: 0 }, aim: { x: 0, y: 0 } }; return; }
    const r = readPad(pad, this.settings);
    if (this.captureCb) {
      for (const i of r.pressedButtons) if (!this.padButtons.has(i)) { this.padButtons = r.pressedButtons; this.finishCapture('pad', i); return; }
    } else {
      for (const a of r.down) if (!this.padDown.has(a)) { this.lastDevice = 'pad'; this.press(a); }
      for (const a of this.padDown) if (!r.down.has(a) && a === 'stats') this.emit('statsUp');
    }
    this.padDown = r.down; this.padButtons = r.pressedButtons; this.padStick = { move: r.move, aim: r.aim };
    if (Math.hypot(r.move.x, r.move.y) > 0.3) this.lastDevice = 'pad';
  }

  actionDown(action) {
    if (action === 'sprint' && this.settings.toggleSprint) return this.sprintOn;
    return this.padDown.has(action) || this.settings.bindings.keyboard[action].some((c) => this.down.has(c));
  }

  /** Movement: x = right, y = forward, each in -1..1 (analog on a stick, digital on keys). */
  axes() {
    const k = (neg, pos) => (this.actionDown(pos) ? 1 : 0) - (this.actionDown(neg) ? 1 : 0);
    let x = this.padStick.move.x, y = this.padStick.move.y;
    // the d-pad actions also count as digital input
    x += k('left', 'right'); y += k('down', 'up');
    const m = Math.hypot(x, y);
    return m > 1 ? { x: x / m, y: y / m } : { x, y };
  }

  /** Right-stick shot placement (only when enabled in the settings). */
  aimStick() {
    const a = this.padStick.aim;
    const active = this.settings.stickAim && Math.hypot(a.x, a.y) > 0.3;
    return { x: a.x, y: a.y, active };
  }
}

// Solo matches (practice, 1v1, career) run entirely in the browser: the same PadelGame the server uses,
// with the same bots, but no network in the loop, so there is zero latency.
// It speaks the same messages as the server (start / snap / ev / results) so the rest of the client does not care.

import { PadelGame } from '/shared/game.js';
import { botInput, makeBotMemory } from '/shared/ai.js';
import { SERVER_TICK, SNAPSHOT_EVERY } from '/shared/constants.js';
import { scoreView } from '/shared/scoring.js';

const STEP = 1 / SERVER_TICK;
const MAX_QUEUE = 10;
const RESULTS_DELAY = 4; // seconds of celebration before the results screen

export class LocalMatch {
  /**
   * @param o.settings  match settings
   * @param o.names     four display names (slot 0 is the human)
   * @param o.diffs     bot level per slot
   * @param o.onMessage (msg) => void, receives start/snap/ev/results
   * @param o.onFinish  (results) => career info | null, called once when the match ends
   */
  constructor({ settings, names, diffs, looks, onMessage, onFinish, controller = null, passive = false }) {
    Object.assign(this, { settings, names, diffs, looks, emit: onMessage, onFinish, controller, passive });
    this.paused = false;
    this.timer = null;
  }

  start() {
    this.game = new PadelGame({ settings: this.settings });
    this.game.players[0].human = true; // the person at slot 0
    this.mem = [0, 1, 2, 3].map(makeBotMemory);
    this.queue = [];
    this.lastInput = null;
    this.starved = 0;
    this.acc = 0;
    this.lastT = performance.now();
    this.resultAt = 0;
    this.finished = false;
    this.emit({ t: 'start', slot: 0, names: this.names, looks: this.looks, settings: this.settings, score: scoreView(this.game.match), tickRate: SERVER_TICK, local: true, drill: !!this.controller });
    this.timer = setInterval(() => this.pump(), 8);
  }

  stop() { clearInterval(this.timer); this.timer = null; }

  /** A drill ended: tell the app and stop the loop. */
  finishDrill(result) {
    this.emit({ t: 'drillResults', result });
    this.stop();
  }

  setPaused(p) { this.paused = p; this.lastT = performance.now(); }

  pushInputs(inputs) {
    if (!Array.isArray(inputs)) return;
    for (const inp of inputs.slice(0, 8)) if (inp && typeof inp === 'object') this.queue.push(inp);
    while (this.queue.length > MAX_QUEUE) {
      const d = this.queue.shift();
      if (d.swing) this.queue[0].swing = true;
      if (d.jump) this.queue[0].jump = true;
    }
  }

  pump() {
    const now = performance.now();
    const dt = (now - this.lastT) / 1000;
    this.lastT = now;
    if (this.paused) return;
    this.acc += Math.min(0.1, dt);
    while (this.acc >= STEP) { this.step(STEP); this.acc -= STEP; }
  }

  step(dt) {
    const g = this.game;
    // human (slot 0): same input handling as the server
    let inp = this.queue.shift();
    if (inp) {
      this.lastInput = inp; this.starved = 0;
      g.players[0].ack = Number.isInteger(inp.seq) ? inp.seq : g.players[0].ack;
    } else if (this.lastInput) {
      const stale = ++this.starved > 15;
      inp = { ...this.lastInput, swing: false, jump: false, ...(stale ? { mx: 0, mz: 0, sprint: false } : {}) };
    }
    if (inp) g.applyInput(0, inp);
    this.controller?.update(g, this);
    for (let s = 1; s < 4; s++) {
      if (!g.players[s].active || this.passive) continue; // drills: the other players stand still
      g.applyInput(s, botInput(g, s, this.mem[s], this.diffs[s] || this.settings.difficulty, dt));
    }
    g.tick(dt);
    const evs = g.drainEvents();
    if (evs.length && this.controller) this.controller.events(evs, g, this);
    if (evs.length) {
      this.emit({ t: 'ev', ev: evs });
      const done = evs.find((e) => e.e === 'match');
      if (done && !this.finished) {
        this.finished = true;
        this.results = done.results;
        this.career = this.onFinish ? this.onFinish(done.results) : null;
        this.resultAt = g.time + RESULTS_DELAY;
      }
    }
    if (g.tickNo % SNAPSHOT_EVERY === 0) this.emit(g.snapshot());
    if (this.resultAt && g.time >= this.resultAt) {
      this.resultAt = 0;
      this.emit({ t: 'results', results: this.results, names: this.names, progress: {}, career: this.career });
      this.stop();
    }
  }
}
